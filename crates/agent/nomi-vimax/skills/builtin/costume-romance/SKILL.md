# 古装甜宠 Playbook

## When to apply
- 古装恋爱、宫廷/书院/江湖庭院里的暧昧与身份悬念
- 反差人设、高密度糖点、1–2 分钟竖屏短剧

## 结构
1. 关系钩子（撞见、契约、错认）
2. 反差人设各露一次
3. 糖点升温（距离收近，可被看见）
4. 身份线索轻轻翻一角
5. 未说完的靠近或误会，收束可连载

## 镜头语法
- 对视特写、过肩偷瞄、纱帘/花枝前景分层（推拉镜头只在揭示身份或关系变化时用，不作默认）
- 手与衣料、发饰比空镜更能写暧昧
- 双人站位写清距离：谁先退半步、谁先伸手

## 红线
- 当正剧史诗或武打片拍，糖点被刀光盖掉
- 空庭院、空廊桥没有微动作
- 现代物件穿帮；中途换脸换装
