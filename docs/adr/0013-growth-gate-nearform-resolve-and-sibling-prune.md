# ADR-0013: 生长结构门的宿主侧处置——近形归一 + 同批依赖剪枝

Status: Accepted

Date: 2026-10-19

## Context

生长结构门（`validate_batch` + `gate_batch`，ng.* 条款）此前是**纯拒绝器**：
任何条款违反 = 整批打回，条款报告回灌教练重裁。2026-10-16 首次带凭据真机
深批次冒烟（`learning-smoke grow --batches 4`，AIPC-deepseek-v4.1-flash）
暴露三类失败，全部卡在「打回→重裁」循环上：

1. **字级名漂移**：教练引用「十进位置值」，账内是「十进制位值」——一字之
   差触发 `ng.refs.resolvable` 整批打回；条款报告精准点名后模型连改 5 次
   仍写同一错名，轮次耗尽（2/2 复现）。
2. **同批依赖**：节点 assumes 引用「本课程内未教过、但本批兄弟正在 teach」
   的概念——全局已教账覆盖律放行（跨课程计数），课程内教学序却必被 AI 概
   念评审打回，且唯一修法是「移出本批」。
3. **点修循环越权**：多发现打回后，flash 的重裁多次改动/删除未被点名的节
   点，触发 `ng.redraft.scope` 守卫，3 轮耗尽（详 10-19 审计记录）。

learnhub 同以 flash 跑通全管线，靠的是两条结构性差异：别名由**系统侧核对**
（"挂接会记录你用的名字"/"系统会核对它属于哪个既有概念"），约束过滤是**纯
代码**（候选排序/就绪谓词，不折返模型）。allo 在 g3 已建近形机器
（`defnear`：归一化/包含式近形/定义归一化直定/近邻候选集），但只用于铸名
提名的复用裁决，未接入引用解析。

## Decision

结构门从纯拒绝器升级为**三处置**：打回（红条）、改写留痕（warn）、摘除留
痕（warn）。红条语义不变——歧义、无匹配、就绪未覆盖仍整批打回。

1. **近形归一（`ng.refs.nearform`）**：引用名不可解析时，对解域（登记表
   活跃名 ∪ 本批铸名）跑唯一近形判定——归一化相等 ∪ 包含式近形
   （`name_near_form`）∪ 受限编辑距离（`bounded_edit_close`：距离 ≤1 短边
   ≥3 字符、距离 2 短边 ≥5 字符，短名保护）。命中唯一宿主：就地改写引用
   名为宿主 canonical，落 warn 留痕，批照常落库；多宿主：红条并列候选名；
   零宿主：原打回不变。new_alias 提名不进近形解域（宿主评审未裁，只准精
   确引用）。
2. **同批依赖剪枝**：红条为空后，节点 assumes 引用「本课程内未教过 ∧ 本批
   兄弟在 teach」的概念时直接摘除该节点（tracing 留痕），其余照常落库。
   口径是**课程内**已教——全局账供覆盖律、不供本课教学序；摘除节点的需求
   下一批自然再长。
3. **评审提示词同步**：判据 3（命名与内涵一致）从「同名异指打回」改为
   「**近义铸名走 `reuse` 裁决不打回**」——评审在候选集内给出 concept_id，
   j04 既有机械通道（mints 撤销 + 名字落活跃别名 + 引用挂宿主）直接消
   化，不进重裁循环。reject 裁决丢弃 reuse 数组的既有语义不变（近义铸名
   因此必须走 pass + reuse）。

## Consequences

- **门有副作用**：`validate_batch` 会改写批内引用名、`gate_batch` 会摘除节
  点。审计面 = tracing warn（课程/节点/归一前后名）+ 批次出生档案记实；
  nearform warn 不进 `GateOutcome.errors`（不打回）。
- **误归一风险有界**：唯一宿主要求 + 短名保护（两字名一字差不归一，留给评
  审/模型）；最坏情形是把引用挂到近义概念上——这与此前「整批打回 5 轮后
  放弃」相比是严格更优的退化方向，且 red flag 通道完整保留。
- **与 learnhub 的口径差**：learnhub 依赖课内小图 + 结构化渲染让模型极少
  抄错名；allo 的已教账是跨课程全局账（概念表跨课程铁律），相似名密度更
  高，宿主侧核对从「锦上添花」变为「必需品」。
- **已验证**：`learning-smoke grow --batches 4` 真机从 round 2 必死（2/2
  复现）推进至 round 2 剪枝后一次过门（7 提 4 落，`attempts_used=1`）；
  `cargo test -p nomifun-learning` 328 全绿（含 4 个近形红绿样）。
- **未解**：round 3+ 评审多发现点修循环仍是 flash 合规上限；后续杠杆见审
  记录（批目标缩减 / 更多的机械裁决面），模型升级路线已排除。
