# 学习模块使用指南

## 描述

学习模块做的事很简单：**把笔记变成课程，让学过的东西记得住**。本指南按"你想做什么"来组织，跟着做就能上手：

- **想拥有一门课** → 用「创建课程」从知识库生成，或直接导入课程包
- **想开始学习** → 打开课程，读讲解、做练习，AI 会批改你的开放题答案
- **想查漏补缺** → 做一次「知识诊断」，系统告诉你先学哪一课
- **想记得牢** → 每天花几分钟在「今日复习」里过一遍到期卡片
- **想掌握全局** → 打开「问题管理」，所有题目的状态一目了然

几个基本概念：

- **课程**：一门课由模块、课时、概念组成。模块是主题分区，课时是具体的学习单元，概念是知识点标签
- **课时**：每个课时有一篇讲解和 3-5 道练习题，约 10-15 分钟学完
- **练习**：四种题型——单选、判断即时判分；填空、反思由 AI 批改并给出反馈
- **复习队列**：课时完成后，里面的客观题会自动进入复习队列，到期后在「今日复习」出现

## 例子

**例 1：创建你的第一门课**

1. 打开学习页面，在左侧知识库列表选中一个知识库（例如本教程知识库「Flowy 学习模块快速上手指南」）
2. 点击「创建课程」→「从知识库生成」，选择模块数和每模块课时数（每模块 1-6 个），点确认
3. 生成在后台运行，你可以在「生成任务」页签看进度：排队中 → 采样文档 → 设计大纲 → 写课时 → 导入，约 1-3 分钟
4. 如果任务显示「生成失败」，点任务行的「重试」重新生成；默认模型繁忙时，可以先在设置里换个会话模型再重试
5. 状态变成「已完成」后，回到「课程」页签，新课程已经在列表里了

**例 2：学完一个课时**

1. 点开课程，展开模块，点一个课时（比如「认识课程」）
2. 先读讲解文档，再逐题做练习：单选、判断提交后立刻看到对错和解析；填空由 AI 判断你的答案是否可接受；反思题用自己的话回答，AI 会给评价和建议
3. 学到一半关掉页面也没关系，进度自动保存，下次打开接着学
4. 答完所有练习，课时标记为完成，里面的客观题自动进入复习队列

**例 3：摸底、诊断、复习一条龙**

1. 进入课程后点「先做知识诊断」，答完约 10 道题，报告会显示各概念的掌握程度和「建议下一步」（比如「前往课时 1.2」或直接进入复习）
2. 按建议学完薄弱课时后，顶部会显示「今日复习」的到期卡片数，点「开始复习」进入复习会话
3. 每张卡片先作答，再按回忆难度评分：忘记 / 困难 / 记得 / 轻松。评分会决定这道题下次什么时候再出现
4. 答完一轮，复习会话结束；到期卡片多的可以分几次复习，不用一次刷完

**例 4：用问题管理追踪所有题目**

1. 打开「问题管理」页签，能看到所有课程客观题的状态：未入队（课时没学完）、待首复习（等第一次复习）、已到期（现在就能复习）、已排期（还没到时间）
2. 用状态筛选选「已到期」，把该复习的题一次性找出来
3. 题不够练？点「添加问题」自己出题，或到课程里用 AI 自动补题，新题会直接进入复习队列

## 迁移

- **把自己的笔记变成课程**：任何结构清晰的 Markdown 笔记都能生成课程。一个文件一个主题、每篇有描述/例子/验证三部分，效果最好
- **其他用途**：内部培训（把文档转成带练习的课程）、备考（笔记 + 自测 + 间隔复习）、团队新人 onboarding（按路径学习 + 诊断摸底）
- **配合 AI 使用**：写笔记时让 AI 按文档规范起草，生成出的课程质量更高

## 其他（常见问题）

- **生成失败**：先点「重试」；多次失败检查设置里有没有可用的模型，换一个再试
- **没有模型**：没有可用模型时不能创建课程，但可以导入课程包
- **「今日复习」数量**：显示的是本次会话加载的卡片数（默认 30），不是全部到期数；可以多次进入复习
- **什么时候产生复习卡片**：课时完成时，里面的客观题才进入复习队列；反思题不会
- **删除课程**：会一并删除该课程的复习记录和学习数据，删除前想清楚
- **填空被判错**：填空按意思批改，不逐字匹配；答得完全不沾边会被判错，先读讲解再做题通过率更高

## 验证

1. 判断题：课时完成后，其中的客观题会自动进入复习队列，到期在「今日复习」里复习。（正确）
2. 单选题：创建课程失败后正确的做法是？A. 放弃这门课 B. 点「重试」，必要时换会话模型 C. 删除知识库 D. 重启应用（答案：B）
3. 单选题：以下哪种练习由 AI 批改并给反馈？A. 单选 B. 判断 C. 填空 D. 都不需要（答案：C）
4. 判断题：反思题不会产生复习卡片，只有客观题会。（正确）
5. 操作验证：打开一门课程，先做一次知识诊断，再完成一轮「今日复习」，观察评分后下次复习时间的变化。
