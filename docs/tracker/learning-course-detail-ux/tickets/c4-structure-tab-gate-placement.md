# c4: 结构图 Tab 布局——过门自检移到图视图之后

**What to build:** `StructureGraphTab` 的纵向顺序从「视图切换器 → 挂载三态段 →
过门自检 → 图视图 → 页脚」改为「视图切换器 → 挂载三态段 → 图视图 → 过门自检 →
页脚」：四个视图（思维导图/关系图谱/学习路线/矩阵）的切换器与它控制的画布
相邻，过门自检作为独立的一组内容放到图之后。

## 法证证据（2026-11-09 实码核实）

- `StructureGraphTab.tsx`：切换器 :71-86 → 挂载三态段 :88-153 →
  **GateCoverage :155-165** → 图视图 :167-170 → 页脚 :172-174。过门自检
  （门口判据与声明）与视图切换不是一组内容，夹在切换器与画布之间，用户读
  作「切换器控制的是过门自检」（截图三）。
- GateCoverage 在结构图 Tab 的渲染条件 = `view.terrain` 存在；冻结态（c1）
  后此处为纯展示。

## 实施要点

- [ ] 把 `{view.terrain && <GateCoverage … />}` 块移到图视图四行之后、页脚
      之前；props 不变（c1/c3 改动面以合并后为准）。
- [ ] 挂载三态段位置不动（用户未点名；观察是否也属管理段，结论记 Resolution，
      需动则入后置清单）。

## 验收

- `bun run typecheck` 绿。
- 目验：切换器下方紧接画布；过门自检卡在画布下方，冻结态/未声明态都正常。

## 非目标

- GateCoverage 自身样式与交互（c1）；视图组件内部。

## Resolution（2026-11-09 施工收口）

**全验收过，闭票。** 施工 = `ee3fad798`（单文件 +12/−9）。

- **票内裁决：挂载三态段一并下移**。用户点名的原则是「不受切换器控制的内容
  不该夹在切换器与画布之间」——挂载三态段（j08 挂载/修补管理段）同属此类：
  零节点时 `mounts` 为空所以截图里没出现，一旦生长有节点它就会以同样方式插
  进切换器与画布之间、复现同一个误会。只挪过门自检是半修。
- **落地顺序**：切换器 → 图视图 → 图注（「投影非权威；层号 = 依赖深度」是图的
  说明，跟着图走）→ 挂载三态段 → 过门自检。props 与各段内部零改动。
- **验收**：typecheck 55 错持平存量（learning 零错）。目验留汇总门真机走查。
