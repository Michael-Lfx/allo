## Question

单轮生长 9-18 分钟的痛由**每批缺口大小**驱动（缺口 = READY_TARGET − 当前
就绪，本波实测缺口 3 → 5 调用 → 18 分钟）。弱模型的错误面随批大小**平方
级**收缩：①单批错误暴露率下降（1 节点有缺陷 3 节点批必打回）；②「批内兄
弟不供给」约束随批变小趋平凡满足（11-16 病历的预设未教概念类消失）；③评
审碎片清单变小 → 格式错位暴露面与思考量同降（97 片段=58.5k reasoning 实
测）。批内互不供给契约保证批大小**不是结构旋钮**（先后依赖从来跨批表达）
——唯一损失是"同批对照"教学形态（对照对变先后两批）。

## 已核验事实（2026-11-23 对码）

- 三常数：`READY_TARGET=5`（补货目标）、`READY_TRIGGER=3`（触发水位）、
  `MAX_BATCH_NODES=5`（单批上限）；数量契约段渲染 `{READY_TARGET}`（模板
  已参数化）。
- 全链路已参数化：verdict API 返回 `trigger`、图 API 返回 `ready_target`、
  前端 `graph.ready_target` 显示（零 UI 改动）。
- 常数先例：learnhub 同位数字=7，allo 吸收时已降至 5（代码注释在案）——
  本常数已存在被调先例，非神圣值。
- 上游教训适配：批变小不减弱质量门——门抓的是缺口与供给，批越小错误面
  越小、点修越轻（11-23 点修 25s 样本）。

## Resolution

已施工收口（2026-11-24）。**结论：缺省维持 5/3 不改；开关留作运维面。**

- **落地**（wave/rs7 3790ad149 → merge 0212246c1；评审修复批 28e974d29）：
  `NOMI_LEARNING_READY_TARGET` 单开关（switches.rs 单源），合法域 2-5，
  越界/非法回退缺省并 warn 一次；`READY_TARGET`/`READY_TRIGGER` 由 const
  改函数，ripple 收齐（`auto_refill_verdict`、数量契约段渲染、verdict/graph
  视图、`growth_batch_cap`）；`MAX_BATCH_NODES` 未动。未设 = 5/3 零变化。

**票面笔误留案**：R-a 公式 `TRIGGER = max(N−2, 1)` 与 Acceptance「设 3 →
trigger=2」互相矛盾（3−2=1）。实现按公式 **3/1**（5/3、4/2、3/1、2/1 规则
一致）；若改 3/2 则显式设 5 会得 5/4 ≠ 缺省 5/3，设计不自洽。用户知情，
未要求改。

AIPC-deepseek-v4-flash，同课程同起点就绪 2）**：

| 档 | 轮 | 补节点 | 起草 | 评审 | 评审思考 | 点名片段 | 结局 | 墙钟 |

- **批缩小 3 倍，评审未变快且不稳定**：小批两轮评审 335s / 145s，思考
  28.7k / 12.8k——同一缺口（1 个节点）差一倍多。评审耗时随**点名片段数**
  走（71→301s、45→335s、22→145s），不随批大小走。
- **原因**：评审输入的大头与批大小无关——结构块清单占 35.5%、花名册
  21.3%，待审批次本身仅 7.9%（见 learning-structure-boundary map）。批从 3

- **按回退条件判定**：无饿死（手动触发，未触及水位 1），但单轮时长无稳定
  改善（小批均值 323s vs 补 3 节点 565s，仅省约 100-240s 且方差大）。
  **未达 R-c「显著缩短」门槛 → 缺省不改**。打回率样本不足（小批 2/2 一次
  过、基线 1 轮打回 1 次），不足以判定「爆炸半径」假设。
- **真正打单轮时长的杠杆另有所在**：评审输入里无判定产出的结构清单 →
  ADR-0018 / learning-structure-boundary 波（sb1）。
