# 仙侠虐恋 Playbook

## When to apply
- 仙侠、师徒、仙魔、转世亏欠的情感短剧
- 要虐点和誓言，不要比武大会

## 结构
1. 旧物或誓言的当下裂缝
2. 两人被门规/天道/身份隔开
3. 一次靠近（被打断）
4. 代价兑现（牺牲、失忆、拔剑）
5. 信物落下或未说完的诀别，收束可连载

## 镜头语法
- 信物特写贯穿；云海只作过场不得占主戏
- 对峙用距离和剑尖，不靠全屏特效
- 虐点给反应脸，不给旁白诗句

## 红线
- 当武侠打戏拍，感情线被刀光盖掉
- 用字幕/旁白替代信物与站位
- 空镜仙气堆砌，没有时间伤口
