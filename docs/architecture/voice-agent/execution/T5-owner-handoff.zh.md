## 1. 本轮交付范围

本机流程现已连接：唤醒、真实 ASR、需求理解、短对话、真实任务创建与交付、本地工具、文字/语音结果、查询、取消和单次实际工具确认。所有文件和工作区均在本机；云账号只提供模型访问凭据。

- daemon 管理声学和播放；宿主管理配置、交付、持久化及产品快照；既有 Conversation/runtime 管理执行和唯一审批权威。
- 对话模型和任务执行模型独立配置，不复制 provider key；聊天不依赖任务 runtime 可用。
- 停止语音、关窗、关闭功能不自动取消已接受任务。取消仅由明确任务控制触发，且以真实终态为准。
- 同命令至多执行一次；恢复只读核对原回执。LLM 的接单、取消、确认文案都不能代替真实回执或审批。
- 异步通知等待实际输入静默；任务结果进入最多三轮短上下文，追问解释不重新执行任务。

## 4. Owner 顺序实测脚本

请使用本页最终产物，沿用你原来的本机数据目录和登录方式。不要把测试模型/随机音频回放进生产配置。建议逐项记录时间、看到/听到的反馈和结果，失败项附对应时段 voice 日志，不需要提供 token/key。

1. **启用与离屏唤醒**：模型就绪后开启语音，离开设置，最小化到托盘，说 “Hey Flowy”。预期单个窗口出现、响唤醒音、显示 Listening；保持静默，6 秒后有结束反馈并退出倾听。试用按钮再做一次。
2. **聊天文字与播报**：说“你好，简单介绍你能做什么”。预期识别原文、理解需求、助手回答分别可读；ASR 结束有提示，较长处理期间轻量提醒，实际扬声器播放回答。模型完整输出可展开查看。
3. **追问与停止**：听完后 4 秒内开始“把刚才的回答再简化一点”，可把完整句子说完。依次在识别、思考和播报阶段停止；预期无迟到声音/文字覆盖，再次唤醒正常。
4. **真实读取**：新建专用验收目录及 `acceptance.txt`，写入随机内容；不要在语音请求里说出答案。执行设置选择这个绝对工作区和已配置执行模型。说“读取工作区的 acceptance.txt，告诉我完整内容”。预期实际接单后才播 ACK，任务页可见真实 Read，结果文字和声音与文件一致。
5. **结果追问**：收到读取结果后追问“解释刚才的结果”。预期模型理解实际内容，任务页没有第二次创建/发送/读取。
6. **聊天与任务控制**：启动可观察的长任务，运行期间关窗/停止语音/关闭开关，任务仍在。重新启用后先聊天，再查询、显式取消。预期只有明确取消才进入“取消中”，真实执行终态到达后才结束。
7. **异步结果**：任务完成前重新唤醒并讲话。预期结果不会抢断这段话；声学空闲后通知，正文与详情一直可读，不重复播同一结果。
8. **实际工具确认**：仅在专用验收目录中另建一个可删除的临时文件，要求删除。工具派发前应挂起，面板展示真实完整参数。分别重新建文件测试口头“确认”、“取消”、静默；只有明确且未过期的本次确认删除，另外两种文件保留，不能设置永久允许。越出配置工作区的目标始终拒绝。
9. **恢复与故障**：关闭 Flowy 再启动，旧任务只读核对，不新执行。拔插设备并等待空闲重试；观察真实音量和就绪状态。断网造成 TTS 失败时保留文字，不能声称已经播放。若主动停止语音，恢复流程不应偷偷恢复会话。
10. **外观与安装**：明暗主题和中英文分别检查文字、按钮、任务/审批；在干净 Windows 安装后重复第 1/2/4/8 项，退出包括托盘，核对 ai-mate 子进程与监听端口均结束，安装目录无需开发源码或手工编译。

## 5. 未通过的门禁与风险

- 本轮不进行真人麦克风、物理扬声器、GUI 操作、干净机器安装或 Owner 签核；上述项目必须逐项补证。
- 语音任务当前开放已验证的工作区文件操作和受限字面量命令；越界或不支持的工具拒绝，不能据此宣称语音已开放 runtime 的所有能力。
- 现有全仓 TypeScript 基线有 60 项非语音错误，聚合质量门禁在此失败；不得表述为全仓检查全绿。历史格式配置和 dead CSS 限制见实施记录，新增失败另行记录。
- 自动恢复能重开默认设备，不能代替 OS 麦克风授权/设备选择；若当前设备继续产出 PCM 却已不是用户预期输入，需要在 OS 更改默认设备并重启语音再验收。
- 窗口冷/热 P95、四分类准确率、JSON 解析率、首音延迟与 72 小时挂机未签核。采样应记录硬件、模型、网络、样本量及阶段起止点，保持原 PRD 指标，不用“正常”代替数值。
- Mac/Linux 和无屏硬件未签核，不因共享接口或构建脚本含平台分支而宣称支持完成。
