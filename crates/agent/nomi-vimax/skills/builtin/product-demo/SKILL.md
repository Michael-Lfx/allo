# 产品演示片 Playbook

## When to apply
- Hardware / gadget launches and unboxings
- App / SaaS feature demos and explainer spots

## 结构
1. 痛点钩子（用户场景 1–2 镜）
2. 产品登场（hero beauty）
3. 关键功能演示（手部 / UI 可读）
4. 结果收益与情感落点
5. Logo / CTA 收束

## 镜头语法
- 功能镜保证手指/光标/界面可读
- 穿插材质微距与整机三分法构图
- 少用剧烈手持；运动服务于展示

## 资产规范
- 桌面干净；线材与杂物出画
- 屏幕内容真实、对比充足
