# 短剧导演 Playbook

## When to apply
- Idea-driven narrative shorts that must feel like a finished drama, not a mood reel
- Any 短剧 request without a more specific vertical (女频、悬疑等)

## 结构
1. 钩子开场（带电的动作或画面，抛出问题）
2. 欲望与阻力正面相撞（代价看得见）
3. 升级（每一步都更贵）
4. 反转（兑现前面埋的期待落差）
5. 收束（钩子在画面上兑现，主角处境已变）

## 表演语法
- 情绪一律外化：手部、眼神、走位、道具，不写情绪标签
- 关键道具/手势做成贯穿母题，替代台词解释
- 空持镜、缓慢环视、望向远方一律禁止

## 红线
- 不为密度加镜头：戏做进已有镜头内部
- 不堆二次反转：一个真反转好过三个假反转
