## Notes（法证关键事实）

- 复用机制本身是好的：声明铸「百分数改写为小数」后，生长批 defnear 复用之
  （登记表 8 条 = 声明 4 + 生长 4，**零重复**）；死的是**评审挂号锚定**。
- 降级语义按 m3 fail-open 设计工作（两次同死 → degraded pass 不阻断）——
  代价 = 本批评审锚定全废 + 一轮不可满足重试白烧。
- 课时循环 15 次调用零警告（无审计打回/非法 op）；SSE 零瞬断；数学零错误。
- 结构首轮违约指纹各异（count→one_name→one_name 别名）——早停未触发属正确。
