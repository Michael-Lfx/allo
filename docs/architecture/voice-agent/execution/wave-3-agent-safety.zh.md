# Wave 3：Agent 任务调度与安全闭环 (Agent Bridge & Safety State Machine)

> **对齐**：基线 Phase 3
> **前置**：Gate 2 通过（快轨闭环达标）
> **出口门禁（Gate 3）**：破坏性工具调用 100% 触发二次口头确认（提示词不可绕过）；确认超时 100% 熔断；长任务执行期间不阻塞后续唤醒与状态查询；任务 Accepted 后再播报接单回执

---

## 1. 目标与范围

交付“语音下达任务 → Agent 队列执行 → 状态查询/取消 → 高危确认 → 完工播报追问”的完整慢轨闭环。安全红线在本波落地：**拦截只能发生在 `nomifun-ai-agent` 工具调度层的结构化策略硬引擎**，不依赖大模型判决、不依赖自然语言正则。

## 3. 纵向测试集 VT-3（先写成失败测试）

| 编号 | 竖切 | 断言 | 通过标准 |
| :--- | :--- | :--- | :--- |
| VT-3-01 | 长任务执行中 → 唤醒 → 闲聊 | Acoustic FSM 正常迁移，Task FSM 不受扰 | 双 FSM 状态序列各自正确 |
| VT-3-02 | 任务执行中 → “刚才的任务跑完没？” | 路由 = `task_control: query_status`；口头播报进度；无新任务生成 | 任务队列长度不变 |
| VT-3-03 | 任务执行中 → “取消当前任务” | 路由 = `cancel_task`；Task FSM 中止；`error.wav` 确认 | 任务状态 = Cancelled |
| VT-3-04 | 破坏性指令集（含语义变形：“帮我清理上月文件”等）→ 工具派发点 | 策略硬引擎 100% 拦截；提示词注入变体亦拦截 | 拦截率 100%，误伤率 0（良性指令集对照） |
| VT-3-05 | 拦截后 → 用户 8 秒静音 | 超时熔断；`error.wav`；任务彻底销毁 | 队列无残留 |
| VT-3-06 | 拦截后 → 用户说“确认” → Token 消费后再说“确认” | 首次放行；第二次 Token 已失效不重复执行 | Token 单次性成立 |
| VT-3-07 | 任务下达 → Accepted 前后观测播报时序 | spoken_ack 只在 Accepted 之后 | 时序断言成立 |
| VT-3-08 | 任务完成（声学端 IDLE）→ 完工播报 | `done.wav` + 摘要播报 + 4 秒追问窗开启；追问免唤醒 | FSM 序列正确 |

## 6. 本波禁止事项（追加）

- 禁止在自然语言层加任何“安全正则兜底”（基线 D8 明文否决；拦截只许在工具调度层）。
- 禁止让确认 Token 可复用或可跨任务继承（单次、单任务、8 秒三约束不可协商）。
- 禁止为通过 VT-3-04 而放宽策略表默认拒绝方向（fail-safe 只能向更严演进，且须回写基线）。
