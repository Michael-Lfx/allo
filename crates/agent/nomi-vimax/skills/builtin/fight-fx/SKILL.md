# 影视打斗特效 Playbook

## When to apply
- Action / martial-arts / wuxia combat sequences
- Any scene where hit readability and impact matter more than chaos

## 结构
1. 对峙与距离建立
2. 试探性交锋
3. 升级（兵器/人数/环境障碍）
4. 致命一击或逆转
5. 余波与代价

## 镜头语法
- 轴线稳定；关键命中用中近景确认
- 冲击帧前后各留半拍可读性
- 特效层服务表演，不替代动作设计

## 资产规范
- 服装允许破损与尘土
- 场景提供可互动的道具与掩体
