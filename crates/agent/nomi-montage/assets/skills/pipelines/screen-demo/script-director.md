# Stage Director: script (screen-demo)

Write a schema-valid `script` that advances `proposal_packet.key_message`
within the estimated duration.

## Priorities
Map each script scene to one or more detected_scenes segments. Voiceover length must fit the real on-screen duration of those segments.

## Rules
- Scenes are ordered and numbered; each has a clear beat purpose.
- Narration/dialogue length must fit the target runtime.
- Do not invent a new concept that contradicts the locked proposal.
