## Question

匹配题生成出右列近重复候选（「栈区：随本次调用建立、调用结束即失效」
vs 「栈区：本次调用内建立、调用结束即失效」——语义等价、字面差两字），
配合逐位置精确串判分 = 学习者按正确教学理解作答仍被判错。这类题根本
不该产出。如何断根？

## 已核验事实（2026-11-18 对码 + 取证）

- 取证：matches[0]/[2] 字节级审计——两条串 len 18/18，字面差「随」「内」
  两字（968f vs 672c 6b21 5185），语义等价（学习者不可区分，选哪个变
  体都是「参数在栈区」的正确理解）。
- 生成契约（lesson_content_loop.rs:227/:1612）：右列「一一对应数组」
  无可区分性约束；审计门无候选查重。
- 判分：逐位置精确串比对（progress.rs Matching 臂）——近重复候选 ×
  精确判分 = 结构性误判（非用户错误）。
- 用户哲学（2026-11-18 R-b 裁决同源）：机械解决优先；机械覆盖不到才用
  契约（提示词约束 = 概率性，少加）。

## Terms（方案草案，施工前过裁决）

- **R-a（机械，主门）审计门候选查重**：确定性审计（activity 审计面）
  新 finding——matching 右列候选 normalize 后（去空白/标点差异）pairwise
  字面 distinct；重复 = finding（danger 或 warning 按既有审计分级风格）。
  本例字面本就 distinct——此门防的是「字面重复」这一层。
- **R-b（契约，兜机械盲区）右列候选可区分性条款**：契约
  （:227/:1612 matching 字段规则）追加「右列候选必须语义可区分——不得
  出现同义改写式近重复候选；优先短规范标签（如 栈区/堆区）而非长描述
  句」。机械查重管字面、契约管语义（本例 随/内 恰能过字面查重——语义
  近重复机械不可查，契约是剩余唯一杠杆，属「机械覆盖不到才用契约」的
  正当场景）。短标签偏好是结构性降险：候选越短，语义近重复空间越小、
  字面查重命中率越高。
- **R-c 存量处置**：已产出的坏题不迁移不重生成（用户可跳过继续；判错
  记录如实保留）——断根靠门 + 契约，向前不回头。
- **R-d 不做**：判分语义化（近同义容忍 = LLM 判分面，重且引入新的不可
  控）；不改本例的精确比对（候选可区分后精确比对即公平）。
