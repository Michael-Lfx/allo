## Question

learnhub #85 的文本面（17 提交的主体）分两类，逐项裁决采纳面：

**A. 三条教义条目 → CONTEXT.md 词条 + 提示词同步**（assets/r1 §1.1）：

- **道与术**：教学质量标尺对（道 = 本质理解 / 术 = 可执行）；跨三层共用——节点线分配
  道位（一条线只有操作台阶时补「为什么成立」位）、内容线给成色（先推后练）、题库/教练线
  检验（迁移/说理题判真懂）。实证来源：30 节点 80% 操作动词、零说理位。
- **概念不可学完**：同一概念反复学习合法且是常态（不同档位螺旋加深、同档位不同角度变式
  皆可）；allo 门侧现状已合法（无唯一性门）但**提示词无此明文**——learnhub 实证「门全开
  而行为缺失」（30 节点每概念恰教一次单一档位、零重访）。
- **概念投影**：一次学习行为只是概念的一个投影，完成节点 ≠ 学会概念；别名是投影的自然
  命名面（与 g3 别名闭环耦合）。

**B. 提示词修正波 → COACH_SYSTEM / 评审提示词文本**（assets/r1 §1.2/§1.4）：

- 弧线跨批投影（整体是多线弧线、每次只交付一片；先承接下来只发生在批与批之间）——对照
  allo 现版「螺旋重现、从易到难」较笼统，此项更锐利；
- 对照/对比型合装放宽 + 同轴收窄（两个不同概念的首次引入不是对照，是抱团）；
- 动词语法多样谱（同批与相邻批不全是同型——修「每修一偏差加一条规定」的僵化）；
- 首批地板（首批节点以单一概念或单一最小操作为度，teaches ≤2；allo 现版「1-2 个核心
  概念」已近似，是否收窄到 ≤2 与「新开族起步克制」）；
- 同批不重教（概念节点先行、直接应用下批挂接；allo 现版有「螺旋重现」但无此排布明文）；

- 定义文本前提闭包（零基础判据覆盖新概念文本引用或预设的每个课程内概念）；
- 评审免自造机械矛盾（评审判据显式写「批内兄弟教出的概念不算已教，不得建议挂 assumes」

## Resolution

> **裁决方式注记（2026-10-13）**：本票三问发出后未获用户回答，按三项推荐项默认裁决——
> 与用户本 effort 一贯取向（接受推荐、偏差时更全量）一致，且全部为可逆文本层决策。

**速览**：三项均采推荐——教义三条全采、提示词波全采（域中立）、内联保持 + 方法论进域文档。

1. **教义三条全采**：
   - **CONTEXT.md 新增三词条**：道与术（教学质量标尺对：道 = 本质理解 / 术 = 可执行；
     跨三层共用——节点线分配道位、内容线给成色、题库/教练线检验；含 learnhub 六批长样本
     实证注记）、概念不可学完（反复学习合法且是常态，不同档位螺旋加深、同档位不同角度
     变式皆可；门全开而行为缺失的实证注记）、概念投影（完成节点 ≠ 学会概念；别名是投影
     的自然命名面——与 g3 别名闭环互引）；
   - **COACH_SYSTEM 同步三条款**：道位条款（一条线只有操作台阶时补「为什么成立」位）+
     重访合法（已教概念可从新角度重访；同概念多节点反复教合法，只有同一角度同一深度的
     重复没有价值）+ 投影措辞（teaches 写本次到达的理解深度，assumes 按本次实际依赖的
     深度写档位）。
2. **提示词波全采（域中立改写，COACH_SYSTEM + 评审判据）**：
   - 弧线跨批投影：课程整体是多线弧线，每次生成只交付一片；先后承接只发生在批与批之间
     （相邻步骤分相邻两批，互不依赖的并进变体可同批）；
   - 对照限同轴：对照/对比 = 同一维度或同一手法的两个取值；两个不同概念的首次引入不是
     对照，是抱团；
   - 动词多样谱：动词按内容自然形态取，同批与相邻批不全是同型（不设形态要求——删预设
     不加规定）；
   - 首批特则：首批节点以单一概念或单一最小操作为度；常规批维持现有「1 个核心概念至多
     2 个」；
   - 同批不重教：概念节点先行，它的直接应用节点下批以 assumes 挂接；前置与后继不装同批；
   - 悬空技巧 + 真实需要三问：每批先问学习者此刻真正缺什么——技巧依赖的一般技能先立
     地基；只有操作没有理解补「为什么成立」台阶；门口点名未开线的能力尽早开线；
   - 定义文本前提闭包：零基础判据覆盖本批新概念文本（定义/操作/实例/易错）里引用或
     预设的每个课程内概念；
   - 评审判据②补禁则句：批内兄弟节点教出的概念不算已教，**不得建议挂 assumes**（免评审
     自造机械矛盾）。
3. **形态与方法论**：COACH_SYSTEM **保持内联常量**（一轮 g4 已裁「契约迁移与提示词资产化
   解耦」，复议无新理由）；三条方法论（放宽必配收窄判据 / 修偏差优先删预设少加规定 /
   判据只放在能看到信息的层）落 `docs/architecture/learning.zh.md` 新节「提示词纪律
   方法论」，各配 learnhub 病历出处。
