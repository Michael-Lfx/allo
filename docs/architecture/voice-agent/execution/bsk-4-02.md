# bsk-4-02 验证剧本：OOBE 配对页语言协商 (Accept-Language Negotiation)

> **目标**：验证无屏伴侣 OOBE 配对 Web 页面的浏览器语言协商与双语即时切换能力。
> **基线映射**：ui-motion.zh.md §4、Gate 4
> **执行环境**：设置不同 `Accept-Language` 请求头访问 `http://localhost:8080/`

---

## 1. 验证步骤

1. **中文协商 (`Accept-Language: zh-CN,zh;q=0.9`)**：
   - 使用模拟中文环境访问；
   - 验证标题为 `输入配对码`，副标题为 `请输入伴侣主机正在播报的 6 位数字配对码`；
   - 模型投影区为 `语音引擎就绪状态`；
   - 完成态文案为 `AI Mate 准备就绪`。

2. **英文协商 (`Accept-Language: en-US,en;q=0.9`)**：
   - 使用模拟英文环境访问；
   - 验证标题为 `Enter Pairing Code`，副标题为 `Please enter the 6-digit code announced by the companion host`；
   - 模型投影区为 `Voice Engine Readiness`；
   - 完成态文案为 `AI Mate is Ready`。

3. **前端动态即时切换**：
   - 点击底部 `#langSwitchBtn` 切换按钮（触控高度 $\ge 44\text{px}$）；
   - 页面即时更新为对应语言字典，不触发页面重载，输入框中的 OTP 数据保留完整。

## 2. 机械断言清单

| 检查项 | 期望值 | 判定 |
| :--- | :--- | :--- |
| `html[lang]` 属性跟随协商 | `zh-CN` / `en-US` | 通过 |
| 字典完整度 | 双向 100% 对称覆盖 | 通过 |
| 动态切换保留草稿状态 | OTP 字符不丢失 | 通过 |
