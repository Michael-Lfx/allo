# ADR-0009: 学习图重构为概念网驱动的跨课程生长模型

Status: Accepted

Date: 2026-09-28

## Context

学习图（`course_kind='learning_graph'`，Beta）现行形态是「一次性生成整棵先修
DAG」：描述一个学习目标 → agent 两轮循环构建 30+ 节点的网络（显式
`learning_graph_prerequisites` 先修边）→ 确定性审计 + LLM 终审 → 一次发布。
实践暴露的问题：

- **先修边是多余的模型负担**：依赖信息最终要落到「这门课假定你懂什么」，
  边只是它的投影；跨课程复用时（课程 B 的节点依赖课程 A 教过的概念）边
  无法表达这种关系。
- **一次成型与真实学习节奏冲突**：目标没变、图却不能生长；生成一次要等
  数分钟，失败重试成本高。
- **概念体系分裂**：传统课程有 per-course `learning_concepts`（从未开发
  完整），学习图课程完全没有概念绑定，两套口径互不相通。

同期 learnhub-plugin（同作者的实验性学习引擎）已验证了替代模型：全局概念
登记表 + teaches/assumes 概念网替代先修边 + 教练按批生长（每批 ≤7 节点，
把就绪补到 7）+ 多终点锚 + 罗盘。本项目按自身定位裁剪其重治理装置
（提案收件箱人审、草稿水位、账本断裂等），保留两根脊柱。

## Decision

1. **概念网替代先修边**：删除 `learning_graph_prerequisites` 与一切课时间
   依赖边；节点声明 teaches/assumes（概念 × 档位），依赖由概念网折叠。
   就绪 = 未开始 ∧ 每条 assumes(concept, tier) 被（跨课程的）某节点
   teaches(concept, tier′) 且 tier′ ≥ tier 覆盖。
2. **三级档位入模**：知道(know) ＜ 会用(apply) ＜ 能教(teach)，teaches 与
   assumes 均携带，就绪判定与结构门做档位比较；DB 存 locale 无关代码。
3. **发布即就绪**：结构门（批内自足、档位反查、铸名合法、终点保护、标题
   唯一、≤7 节点）+ 一次 AI 概念评审，全部确定性通过即自动落库；不满足的
   批次整批打回重裁。**界面没有锁定态**——「锁定/解锁」从产品语言中移除。
4. **全局概念登记表**：新表跨课程唯一（canonical+别名联合唯一，冲突由
   AI 铸名消歧、不做自动合并）；生长批次按需铸名。传统课程的
   per-course 概念体系（`learning_concepts`/`learning_concept_prerequisites`/
   `learning_lesson_concepts`/`learning_activity_concepts`/
   `learning_mastery_states` 及题目绑概念、概念掌握度 EMA）**整体下线**：
   代码、UI、数据全删，判卷退化为按题目本身判分。之后考虑并入登记表。
5. **生长取代一次成型**：触发 = 就绪 < 3（节点完成时自动检查）或手动按钮；
   每批 ≤7 个新节点，目标把就绪补到 7；批次落 `learning_growth_batches`
   作为出生档案。7（补货目标）与 3（触发水位）是仅有的两个调节数字。
6. **多终点锚**：终点 = 标题 + 一句程度声明 + 零正文标记课时行，一课任意
   多条；建课时 AI 提议、用户可编辑，课后可增删；终点变更触发罗盘重画；
   罗盘（逐终点剩余路线）默认收起、点击展开，作为生长方向上下文，永不进
   完成判据。
7. **图谱界面改为记录面**：DAG 画布（GraphDagView）删除；学习图工作区改为
   双 Tab「学习记录（批次时间线）+ 概念表（概念 × 教/假定 × 档位 × 跨课程
   来源）」+ 可学列表。**单个节点的完成标准不变**（手动申报、作答 ≥0.6、
   LLM 判卷、完成后种 FSRS 卡全部原样）。

数据处置沿用 048 的先例：破坏性更新，迁移 066 直接删除旧图课程与旧概念
体系数据，不做迁移。

## Consequences

- 跨课程就绪天然成立：多门学习图课程共享一张登记表、一本已教概念账。
- 生长失败的影响从「整门课不可用」降为「这批不落库、就绪保持现状」。
- 生成时长从分钟级整课降到单批次秒-分钟级，可后台静默执行。
- 旧图课程用户数据丢失（Beta 实验数据，已在决策中接受）。
- 题目级概念绑定入口消失；`learning_custom_questions.concept_id` 一并移除。
- 判卷 prompt 不再携带概念依据，按题面与课时上下文判分。
- 后续若要把传统课程接入统一概念体系，登记表是其唯一落点。
