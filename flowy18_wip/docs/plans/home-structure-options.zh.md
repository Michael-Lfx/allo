# 首页结构方案 · 三个候选

状态：2026-11-21。现状是「居中标语 + 一排 chip + 一排等大卡片」，与 `DESIGN.md` 自己反对的等大卡片墙只差一个排列。以下三个方向用于打破对称，均需人工选中后再实施。

## 方案 A · 焦点卡

第一张示例卡占两倍宽度，其余三张常规宽度，横向滚动。切换分类时焦点卡先入场，其余按 80ms 间隔跟随。

1. 成本：低。只改卡片宽度分配和动画延迟。
2. 收益：立刻打破等大节奏，形成主次。
3. 风险：每次只有一个「主推」，而模板之间本来没有主次之分，可能误导用户以为第一张被官方推荐。

## 方案 B · 非对称分栏

左栏占三分之二：标语、chips、输入框，左对齐。右栏占三分之一：示例卡纵向排列，可滚动。

1. 成本：中。需要重排 `studio()` 的容器结构，输入框位置也要动。
2. 收益：像工作台而不是落地页，与左侧任务列表形成连续感。
3. 风险：左对齐的大标语在超宽屏上会把右侧留成一条窄带，卡片被压缩得过窄。

## 方案 C · 卡片即舞台

卡片放大到占据视口主体，标语缩小并浮在卡片上方，chips 沉到底部。输入框变成浮层，聚焦时才展开。

1. 成本：高。输入框的常驻状态要改，键盘焦点和可达性都要重做。
2. 收益：视觉冲击最强，最不像模板。
3. 风险：把「输入」这个主操作藏起来，与 `PRODUCT.md` 里「Preserve spatial and causal continuity」冲突，用户找输入框的成本变高。
