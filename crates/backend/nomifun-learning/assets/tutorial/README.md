# Flowy 使用指南（教程知识库）

## 描述

这是 Flowy 自带的教程知识库，用来说明如何把「知识库 + 学习模块」组合起来使用：把知识库文档变成学习课程，再用课时练习、复习队列与问题管理巩固记忆。知识库里的每篇文档都按学习模块的文档规范书写——**描述、例子、验证三节必备，迁移、其他、关键词、推广等小节按主题取舍**——所以它既是使用手册，也是生成示例课程的优质语料。

学习模块的核心链路：**准备知识库 → 生成课程（任务化）→ 打开课程自动加入 → 课时学习（做题 + AI 批改）→ 完成课时 → 复习队列到期复习 → 问题管理追踪掌握**。打开课程即自动加入，无需单独的「加入课程」步骤。

## 文件结构

- `README.md` — 本文件：知识库总览与文档规范
- `LEARNING_GUIDE.md` — 学习模块使用指南：课程生成任务、课时学习、知识诊断、复习队列、问题管理的操作说明

## 例子

**例 1：把本知识库变成一门课程**

1. 打开学习页面，左侧知识库列表选中「Flowy 使用指南」
2. 点击「生成课程」，选择模块数与每模块课时数（每模块 1-6 个），确认后创建生成任务
3. 生成任务在「生成任务」页签中以表格展示：每个任务有进度、状态（进行中/成功/失败）与模型信息，可随时查看；任务成功前不影响页面其他操作
4. 任务失败时点击「重试」即可重新生成（必要时可换一个会话模型）；成功后课程出现在课程列表
5. 点开课程即可开始学习——打开课程详情就已经自动加入，无需手动报名

**例 2：用新文档规范写自己的知识库**

1. 每篇文档一个主题，文件名用「NN-主题.md」编号
2. 正文至少包含三节：`## 描述`（讲清是什么）、`## 例子`（1-3 个具体可操作的示例，带步骤、数字、流程）、`## 验证`（3-5 道自测题，至少 2 道客观题）
3. 按需补充可选小节：`## 迁移`（如何应用到新场景）、`## 其他`（常见错误、边界情况）、`## 关键词`、`## 推广`，也可以写「常见错误」「扩展阅读」等自定义小节
4. 内容越具体、结构化，生成出的课程质量越高

## 如何使用

1. **阅读**：打开学习页面左侧的知识库，即可浏览这两篇文档
2. **生成课程**：在学习页面选择本知识库，点击生成课程。AI 会先设计课程蓝图，再逐课时撰写深度文档（每课时约 1000-1500 字）与练习；生成过程以任务形式在「生成任务」页签中跟踪，约 1-3 分钟
3. **挂载给 agent**：在会话中把本知识库挂载为上下文，agent 就能检索这些指南来回答 Flowy 学习模块的使用问题
4. **作为写作模板**：编写自己的知识库文档时，参考 `LEARNING_GUIDE.md` 的章节结构，让文档具备完整的学习闭环

## 文档规范

最原子的文本单元（课时 summary 或知识库文档）必须包含以下三节，每节用 `## ` 标题引入；其余小节按主题取舍，不为凑数硬写：

1. **描述（Description）**：用平实的语言说明「是什么」，完整而精确
2. **例子（Examples）**：1-3 个具体可操作的工作示例，必须包含真实步骤、数字或流程
3. **验证（Verification）**：3-5 道自测题，至少 2 道客观题（单选/判断），与课程活动的题目对应

可选小节：**迁移（Transfer）** 说明可以应用到哪些新场景、什么变了什么不变；**其他（Other）** 写注意事项、常见错误、边界情况；**关键词（Keywords）** 是逗号分隔的关键词列表；**推广（Promotion）** 给出自然的下一步与更广的应用；也允许「常见错误」「扩展阅读」等自定义小节。

生成课程时，系统会先让模型产出课程蓝图（概念、先修、模块、课时骨架），再为每个课时单独调用模型撰写 1000-1500 字的深度文档和 3-5 个活动（至少 2 个客观题 + 1 个反思题；活动题型为单选题、判断题、填空题、反思题四种）。生成以任务形式运行：失败的任务可以一键重试，不必从零开始。

## 验证

1. 判断题：文档规范要求每篇文档必须包含描述、例子、验证三节。（正确）
2. 单选题：课时 summary 的推荐长度是？A. 100-200 字 B. 300-500 字 C. 1000-1500 字 D. 越长越好（答案：C）
3. 判断题：可选小节（迁移、其他、关键词、推广）每篇文档都必须写。（错误——按主题取舍）
4. 单选题：课程生成任务的失败处理方式是？A. 只能从头再来 B. 点击重试，必要时可换模型 C. 失败后自动消失 D. 需要重新建知识库（答案：B）
5. 操作验证：打开学习页面，从本知识库发起一个生成任务，观察「生成任务」页签中任务的状态变化与进度展示
