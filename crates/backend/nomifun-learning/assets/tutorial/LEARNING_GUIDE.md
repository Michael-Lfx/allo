# 学习模块使用指南

## 描述

学习模块把「知识库」变成「学习课程」，再驱动「复习队列」帮助记忆。它包含课程生成、课时学习、知识诊断、复习队列、问题管理五个部分，是一个完整的学习闭环：

**准备知识库 → 生成或导入课程 → 加入课程 → 学习课时（做活动）→ 完成课时 → 复习队列到期复习 → 问题管理追踪掌握**。

- **课程**：由模块、课时、概念组成。课程可以从知识库自动生成（以知识库 markdown 为语料），也可以导入课程包。
- **课时**：每个课时包含一篇原子学习文档（summary）和若干活动。文档按「描述、例子、验证」三要素书写，每课时约 1000-1500 字；活动有三种：单选题、判断题、反思题。
- **概念**：课程的粒度单位，课时和活动都会绑定概念；概念之间有先修关系，用于推荐学习路径。
- **知识诊断**：加入课程后可以做的摸底测试，按掌握度推荐个性化学习路径。
- **复习队列**：课时完成后，该课时涉及的概念自动创建复习卡片（按概念粒度），使用 FSRS 算法排期。到期卡片进入「今日复习」。
- **问题管理**：集中查看所有客观题与复习队列的关系：未入队、待首复习、已到期、已排期，也可以添加自定义问题。

### 课程生成的多阶段流程

自动生成课程采用多阶段深度生成管道，与单次生成相比，每课时都有完整的输出预算：

1. **课程蓝图**：模型先阅读采样到的知识库文档，输出课程蓝图——课程标题与描述、核心概念及先修关系、模块与课时骨架，每个课时引用一个具体的源文件。
2. **逐课时深度撰写**：按蓝图顺序逐个课时调用模型，每个课时单独生成 1000-1500 字的深度学习文档（描述/例子/验证三要素必备，迁移/其他/关键词/推广按需取舍）和 3-5 个活动（至少 2 个客观题 + 1 个反思题）。
3. **组装与校验**：所有课时完成后组装为课程，系统会校验结构完整性（概念无环、课时数量、活动答案格式等）后返回。

整个过程为同步生成，默认 3×3 课程约需 10 次模型调用，耗时约 1-3 分钟，请耐心等待。你可以在生成时选择模型（默认使用第一个启用的模型）。

## 例子

**例 1：从知识库生成一门课程**

1. 打开学习页面，左侧知识库列表选中一个知识库（比如本教程知识库「Flowy 使用指南」）。
2. 点击「生成课程」，选择模块数和每模块课时数（1-6 个），可选填课程领域，点击确认。
3. 等待生成（约 1-3 分钟）：AI 先设计课程蓝图，再逐课时撰写深度文档与练习。
4. 生成的课程出现在课程列表；点开课程查看模块、课时与活动。
5. 点击「加入课程」，开始学习。

**例 2：完成一个课时并进入复习队列**

1. 在课程详情里点击「开始课时」，阅读课时的原子文档（约 1000-1500 字，含描述、例子、验证三节）。
2. 逐题作答活动：单选题/判断题会得到对错反馈与解析；反思题记录你的思考。
3. 点击「完成课时」。系统为该课时涉及的概念创建复习卡片（立即可复习）。
4. 回到学习页首页，banner 上「今日复习」出现到期卡片，点击「开始复习」逐张作答并评分（忘记 / 困难 / 良好 / 轻松），评分后下次复习时间按 FSRS 重排。

**例 3：用知识诊断摸底**

1. 加入课程后，在课程页点击「先做知识诊断」。
2. 逐题作答（诊断只抽取客观题：单选题与判断题）。
3. 完成后页面按掌握度与先修顺序给出「建议下一步」，例如「前往课时」或「直接进入复习」。

**例 4：在问题管理中追踪状态**

1. 打开「问题管理」页签。
2. 状态列含义：未入队＝该题所在课时未完成；待首复习＝已入队等待首次复习；已到期＝可立即复习；已排期＝未到期。
3. 点击任意一行查看详情：复习队列区块显示「在队列中/未入队/自定义排期」与下次到期时间；复习指标显示复习次数、遗忘次数、稳定性、难度。
4. 用「添加问题」创建自定义问题，它立即进入复习队列。

## 迁移

- **把自己的笔记变成课程**：任何格式良好的 markdown 知识库都可以生成课程。笔记越结构化（一个主题一个文件、每篇包含描述/例子/验证三要素），生成的课程越可用。
- **不同学习场景**：工作技能（把内部文档转成培训课程）、语言学习（每课一个概念 + 自测题）、考试复习（用问题管理追踪薄弱概念）。
- **与 agent 结合**：把知识库挂载给 agent，让它在写笔记时按文档规范输出（三要素必备、示例具体可操作），课程生成质量随之提升。
- **原理不变、变的是语料**：生成、学习、复习、追踪这套闭环在任何领域都成立。

## 其他（常见错误）

- **生成课程失败**：确认已配置可用的模型（设置中的 provider 与模型需启用）；没有模型时仍可以直接导入课程包。生成是同步的，点击后请勿重复点击。
- **复习项按概念创建**：一个概念绑定多道题，完成任一包含该概念的课时即播种；但某道题所在课时未完成时，这道题在问题管理中显示「未入队」，复习队列也不会出它。
- **队列数量口径**：「今日复习」显示的是本次会话加载的卡片上限（默认 30，可在设置中调整），不是到期总数。
- **诊断与答题不创建复习卡片**：复习卡片只在课时完成时播种；复习次数只在复习会话中累计。
- **删除课程**：可以勾选「同时删除该课程的复习问题与学习数据」，或保留复习问题继续在队列中出现（课程名显示为「已删除课程」）。
- **FSRS 参数**：可在学习设置中自定义，适合从 Anki 迁移优化过的参数。
- **自定义问题**：用自己的排期独立进入复习队列，不受课时完成状态影响。

## 验证

1. 判断题：复习卡片只在课时完成时创建。（正确）
2. 单选题：某题所在课时未完成，但概念已被其他课时完成，这道题在问题管理中的状态是？A. 已到期 B. 待首复习 C. 未入队 D. 已排期（答案：C）
3. 单选题：自动生成课程时，模型先输出什么？A. 全部课时的完整文档 B. 课程蓝图（概念、先修、模块、课时骨架）C. 复习卡片 D. 知识诊断结果（答案：B）
4. 判断题：复习队列出题只来自已完成课时的客观题。（正确）
5. 操作验证：从本教程知识库生成一门课程并加入，完成一个课时后，检查复习队列是否出现对应卡片。

## 推广

掌握学习模块后，下一步可以：把文档规范（三要素必备 + 可选小节）用于日常笔记写作，让知识库成为可持续生成课程的语料；用自定义问题补充课程之外的练习题；结合技能与浏览器自动化，构建「自动采集 → 自动成课 → 定期复习」的完整学习流水线。后续模块教程会逐一展开这些能力。
