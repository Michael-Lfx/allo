## Question

learnhub #99 大波（#102 课程管理/#103 生成进度与取消/#109 复习页/#110 题目维护/
#111 教练页 v2/#112/#113 总览/#104 检测读面、契约 R9）各是什么；对 allo 什么是净增量、
什么已有等价物？

## Resolution

**速览**：**最重要的发现是行为缺陷实锤——allo 的生长取消是假取消**（`growth_body` 循环
零检查点，用户点取消后生长继续跑完并落库，仅 Err 分支把 failed 改标 cancelled）。其余按
净增量排序：

- **「现存且启用」口径（#102）**：`active_course_ids` 单源（目录在场 ∧ enabled；条目缺席
  = 滞后合法视为启用）；**安排面全收窄**（到期队列/教新候选/quiz 覆盖/进度尺分子分母/
  自由练习），**历史面全不收**（XP 日历/账本摘要如实保留——删课 XP 不消失）；注册表滞后
  补立（治理写面不因滞后拒绝）。
- **课程管理写面**：rename 只动显示名（宪章目标原句一个不动）；归档 = enabled 翻转
  （数据零删零改、读侧唯一排除依据）；删除 = 先目录后注册表、账目流保留；GUI 强确认 =
  **逐字输入显示名** + 三条如实后果（含「想暂停请用归档」）。
- **长任务注册表与协作取消（#103）**：任务状态机 running→done|failed|cancelled（终态
  幂等、同键并发 begin 拒绝）；取消哨兵 + **LLM 前后双检查**（enter_step 前检查内层零
  调用 / exit_step 后检查丢弃结果）；**取消 = 中性终态不报错误**；注册序（进程级单调）
  作排序判据（同秒时间戳不可靠）；步骤叙事映射（同任务名不同型叙事不同）；四类长操作
  接入（生长/教新备料/quiz 变式/单题重出）；前端共享 hook（事件缺席不碍流程——命令
  promise 是完成态唯一真相）。
- **coach_view（#111）**：只读投影五卡片（接下来含理由深链/检测进度 N/K/复习重点归因/
  学习节奏护栏话术/课程材料折叠）；**预览式解析**（与 resolve 同一条队列序代码的纯读
  形态：零档案写入、readonly 引擎任何意外 LLM 调用即报错的结构性保险）；**禁语围栏**
  （6 个绝对化禁词 + 遍历测试，零机制成本）。
- **重出流程（#110）**：替换语义 = 原题作废留档 + 新题追加（同一次原子写）；管理面详情
  揭示判分底（红线：绝不进学习者会话面）；作答历史按题 ULID 留原题（审计连续）。
- **复习中心聚合读数（#109）**：due 全景投影一次取齐（按节点分组 + 7 日分桶 + 逾期徽标）。
- **契约 v2.6 R9 叙述声部 + 跨课预告废除**：正文自称「本课/这一课」，开发面结构词
  （本点/学习点/节点/挂接/投影/骨架）不入正文；小结不写跨课预告——「无通道保证的承诺
  不发」（兄弟课读不到本课正文，实测承诺零兑现）。纯提示词资产级。
- **allo 已有等价物**：软删墓碑（但语义是 DB 墓碑非「现存且启用」读侧口径）、WS 事件
  （但不重放、无快照命令）、cancel 旗标（假取消）、复习直查 SQL（无聚合读）、自建题编辑
  （无作废留档/重出）、删除确认（无输入显示名强确认）、日历壳（打卡口径待换 XP）。
