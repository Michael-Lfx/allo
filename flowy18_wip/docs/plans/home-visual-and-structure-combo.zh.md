# 首页视觉与结构 · 组合评估

状态：2026-11-21。承接 `home-structure-options.zh.md` 的三个结构候选，补上视觉层次方案并合并评估。

## 一、视觉层次（前置，必做）

老爷爷的判断：画面普通的主因是视觉层次弱，不是布局。三条按优先级：

1. **封面底部渐变遮罩，标题浮在图上。** 卡片从「截图容器」变成「作品」。这是提升最大的一条。
2. **信号色归位。** 选中 chip 用 teal，焦点环用 teal。现在整屏没有一处 teal，没有色彩焦点。
3. **卡片底色与画布拉开学差。** 去边框的前提是有色差，现在只差 2%，边界靠猜。

## 二、结构候选评估（含视觉修复后的表现）

### 方案 A · 焦点卡

视觉修复后放大卡会更有冲击力，但语义问题不变：模板没有主次，放大第一张等于暗示官方推荐。

**评估：不做 2 倍焦点，改做弱化版。**

弱化版：卡片高度交替（150 / 170 / 150 / 170），用节奏感打破死板，不暗示推荐。代价低，风险低。

### 方案 B · 非对称分栏

视觉修复后右栏依然窄。2560 宽屏幕下右栏约 850，一张 3:2 封面高 567，纵向只容得下 1.5 张。左侧同时有侧栏和内容栏，两条左对齐竖线让页面左侧过重。

**评估：放弃。**

### 方案 C · 卡片即舞台

视觉修复后最惊艳，但把输入框藏进浮层违反 `PRODUCT.md`「保持动作与结果的空间因果连续」，且多一步点击。

**评估：放弃。**

## 三、推荐组合

1. 视觉三条全做。
2. 结构做 A 的弱化版：卡片高度交替，不做 2 倍焦点。
3. 卡片内部海报化：封面占满、标题浮图（由视觉第 1 条带来）。
4. 动画维持交错入场，位移从 8px 提到 12px，配合更高的封面更明显。

整体布局仍是「标语 + chips + 一行卡」，变的是每张卡的分量和节奏，以及整屏的色彩焦点。

## 四、预期效果

1. 卡片边界清晰，标题可读性提升。
2. 画面有 teal 焦点，不再全灰。
3. 卡片高低错落，不再是一排等大矩形。
4. 封面更大更亮眼，像作品展示而不是文件列表。
