### x01｜gd.no_schedule 主题词豁免（修功能性缺口）
真机病历：structure 臂压力目标「掌握项目进度管理的关键路径方法」三轮级联失败 EXIT=2——第 1 轮 `gd.no_schedule` 两处「进度」（模型定义「量化各活动的进度弹性」「安排进度压缩」，进度管理课的领域术语本身），第 2 轮 blocks.quota、第 3 轮 spines.count 级联。
**修法（沿 u09 方向收紧为词级）**：排期 marker 命中处，若该词本身是**课程目标原句的子串**（= 用户点名的课程主题词），不构成产物的排期语义，豁免；其余 marker（小时/每天/每周/时间表…）照扫——真正的排期承诺（第 X 天/时间表形态）仍被拦。风险：目标含「计划」时「学习计划表」可能漏网——残余由时间表/每天等词兜底，可接受（与 u09 goal 豁免同款取舍）。
落点：`structure_contract.rs` 扫描处（validate 内 goal 文本提取 + marker 双条件）；新测：目标含「进度」→定义含「进度弹性」过、定义含「时间表」仍拒、goal 不含的排期词仍拒。
