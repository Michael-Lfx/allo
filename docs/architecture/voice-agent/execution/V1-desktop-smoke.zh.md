# V1 Windows 唤醒承载验收

> 当前仅验收启用、真实就绪、唤醒窗口与静默退出。聊天/播报/任务完整闭环未交付，不据此签核后续切片。

## 前置条件

- 当前分支 `feat/xiaozhi-voice`，启动当前构建；不使用旧安装包作为本次代码证据。
- Windows 可用麦克风；已经安装并校验本地声学模型。模型下载完成本身不应启动录音。
- 本轮尚未自动启动桌面或打开麦克风；待用户提供真机验证条件后执行。

## 顺序和预期

1. 保持语音关闭，下载/校验模型。确认没有 ai-mate 进程因下载而自动启动。
2. 打开启用开关。先看到连接/初始化过程；声学引擎实际就绪之前“试用唤醒”不可用。进程 running 不能代替 acoustic_ready。
3. 点击“试用唤醒”，检查只有一个独立会话窗口。窗口显示 Listening；没有说话时约六秒变 Idle 并隐藏。不改变原本前台应用的键盘焦点。
4. 再次试用，确认复用同一窗口；关闭会话窗口停止当前声学轮次。新一轮窗口的身份变化后，旧作用域停止请求应返回 409。
5. 离开设置页，将主窗口隐藏到托盘。说出现有唤醒词，确认原生窗口仍出现；设置页 renderer 不是消费者前提。
6. 启动时没有可用麦克风，确认 acoustic_ready=false；唤醒返回不可用，不能弹出假 Listening。设备运行中失联/恢复属于 V4，暂不据此签核。
7. 启用后彻底退出 Flowy，确认整个 ai-mate 子进程树退出；重新启动时保留启用意愿。关闭开关后再次启动应保持关闭。
