# Flowy 使用指南（教程知识库）

## 描述

这是 Flowy 自带的教程知识库，用来说明如何把「知识库 + 学习模块」组合起来使用。知识库里的每篇文档都按学习模块的七要素规范书写——描述、例子、迁移、其他、关键词、验证、推广——所以它既是使用手册，也是生成示例课程的优质语料。

## 文件结构

- `README.md` — 本文件：知识库总览与文档规范。
- `LEARNING_GUIDE.md` — 学习模块使用指南：课程生成、课时学习、知识诊断、复习队列、问题管理的完整说明。

## 如何使用

1. **阅读**：打开学习页面左侧的知识库，即可浏览这两篇文档。
2. **生成课程**：在学习页面选择本知识库，点击生成课程。课程会以这些文档为语料，按同一套七要素结构产出课时与题目。
3. **挂载给 agent**：在会话中把本知识库挂载为上下文，agent 就能检索这些指南来回答 Flowy 学习模块的使用问题。
4. **作为写作模板**：编写自己的知识库文档时，参照 `LEARNING_GUIDE.md` 的章节结构，让文档具备完整的学习闭环。

## 文档规范（七要素）

最原子的文本单元必须按顺序包含以下七节，每节以 `## ` 标题引入，内容必须具体、可验证：

1. 描述（Description）— 用平实的语言说明「是什么」。
2. 例子（Examples）— 1-3 个具体可操作的工作示例。
3. 迁移（Transfer）— 说明可以应用到哪些新场景，什么变了、什么不变。
4. 其他（Other）— 注意事项、常见错误、边界情况。
5. 关键词（Keywords）— 逗号分隔的关键词列表。
6. 验证（Verification）— 读者可以自测的问题，至少一道客观题。
7. 推广（Promotion）— 自然的下一步与更广的应用。

## 关键词

## 验证

- 你能说出七要素是哪七节、顺序如何吗？
- 打开学习页面，从本知识库生成一门课程，观察生成的课时是否包含完整的七要素章节？

## 推广

把同样的文档规范应用到自己的领域知识库：笔记越结构化，生成的学习课程质量越高。后续版本会继续补充其他模块（如技能、浏览器、自动化）的指南文档。
