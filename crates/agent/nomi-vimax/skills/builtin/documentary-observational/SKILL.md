# 观察式纪录片 Playbook

## When to apply
- Nonfiction character portraits and reportage
- Slice-of-life stories that need credibility over gloss

## 结构
1. 人物/场域建立（环境肖像）
2. 日常流程与冲突出现
3. 关键行动或对话节点
4. 后果与反思
5. 开放式收束（留白）

## 镜头语法
- 先宽后近；给动作完整起落
- 访谈可用过肩，但别打断观察流
- 避免过度运镜炫技

## 资产规范
- 服装生活化；允许不完美
- 场景保留真实道具与环境声想象
