## Question

learnhub #102/#112 的课程管理裁决：「现存且启用」（`active_course_ids` 单源——目录在场
∧ enabled，条目缺席 = 滞后合法视为启用）作为读侧横切口径：**安排面全收窄**（到期队列/
教新候选/quiz 覆盖/进度尺分子分母/自由练习），**历史面全不收**（XP 日历/账本摘要如实
保留）；课程改名（只动显示名，宪章目标原句不动）；归档 = enabled 翻转（数据零删零改）；
删除 = 逐字输入显示名强确认 + 三条如实后果。

allo 现状：软删墓碑 deleted_at（069）+ 归档（044 课时归档，非课程级）+ deleteReviews
可选连带删卡 + 简单删除确认；**无课程级 enabled/改名/概况读数/强确认**。且 r3 报告指出
一个连带问题：allo 的删除可选连带删卡——若采纳 learnhub 的「学习记录保留」强确认文案，
必须先裁决连带删卡语义（不得虚诺）。

需要裁决：

1. **「现存且启用」口径**：allo 引入课程级 `enabled` 开关 + active 课程集单源函数，收束
   全部安排面查询？还是维持现状（deleted_at 即唯一口径，无归档暂停态）？**推荐采纳**
   （归档/删除二分的产品价值明确：删除不可逆、归档可逆暂停；allo 已有删除，缺暂停）。
2. **改名**：课程显示名可改（`UPDATE learning_courses` 一条）——目标原句/learning_goal
   不动。**推荐采纳**（成本近零）。
3. **删除语义与强确认**：(a) 维持 deleteReviews 可选 + 强确认升级为「输入显示名 + 后果
   按用户勾选如实动态告知」；(b) 对齐 learnhub：删除永远保留账本、不提供连带删卡（文案
   可如实承诺「学习记录保留」）。**推荐 (b)**（语义更干净；「复习卡要不要删」交给归档
   暂停解决，删除 = 罕见破坏性动作语义单一）。
4. **概况四读数**（节点数/已结算/今日到期/累计 XP）+ 列表行展示——随采纳面顺带。

约束：历史面不过筛（日历/统计聚合如实保留）要与二轮 g1 的「XP 日历不过课程筛」对齐
（同一条裁决的两处落点）；「现存且启用」集是二轮 t1 XP 结算读数的前置。

## Resolution

> **裁决方式注记（2026-10-14）**：用户指示「推进直到所有设计定案票结束」，按推荐项默认
> 裁决（连续第四轮未逐票盘问）；票面标注可复议。

**速览**：四项全采推荐——现存且启用口径采纳、改名采纳、**删除语义对齐 learnhub（账本
永远保留、连带删卡选项退役）**、概况四读数顺带。

1. **「现存且启用」口径采纳**：`learning_courses` 加 `enabled INTEGER NOT NULL DEFAULT 1`
   （迁移 071+ 段位）；`active_course_ids` 等价单源 = `deleted_at IS NULL AND enabled = 1`
   （条目语义：缺席列 = 启用，兼容回填）；**安排面全收窄**（到期队列/就绪推荐/教练上下文
   组装/自由练习抽取/XP 进度尺分子分母），**历史面全不收**（XP 日历/统计聚合/打卡历史
   如实保留）——与二轮 g1「日历不过课程筛」同一条裁决。
2. **改名采纳**：`PATCH /api/learning/courses/{id}`（新端点）只动 `title`（显示名）；
   `learning_goal`/结构快照/学习数据一个不动；标题唯一约束沿用（冲突 = 人面错误）。
   注意 allo 的「名称即标识」墓碑语义：rename 同步更新唯一性校验路径（service/course.rs
   的 title 查重），软删墓碑行不阻塞新名。
3. **删除语义对齐 learnhub：(b) 账本永远保留**——`deleteReviews` 连带删卡选项**退役**
   （端点参数与 UI 勾选删除）；删除 = 课程行墓碑 + 课时/概念网边照旧物理清理，**复习卡
   与作答记录保留**（安排面经现存且启用口径自然不再出现本课，历史面如实留账）。强确认
   升级 = **逐字输入课程显示名** + 三条如实后果（「课程与课时内容将永久移除」「学习记录
   保留：已计入的进度与 XP 不随之删除；此后各安排面不再出现本课」「此操作不能撤销；只是
   想暂停这门课，请改用归档」）。
4. **概况四读数顺带**：`CourseSummary` 扩 `enabled/total_lessons/settled_or_completed/
   due_today/total_xp`（total_xp 依赖二轮 t1 账本，先行可空）；列表行 + 详情头区展示
   （归档徽标 + 恢复按钮）。

**派生影响**（供合并切票）：迁移（enabled 列）；三个端点（rename/archive 切换/删除语义
变更）+ DTO；`active_course_ids` 单源函数收束的存量查询清单（实施时全量排查安排面 SQL）；
CourseDeleteDialog 重写（输入确认 + 后果三条）；列表/详情 UI（改名入口/归档徽标/恢复/
概况行）；i18n 双语。
