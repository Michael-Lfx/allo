**默认首页。** 保留左双入口、右侧会员、三张封面、独立视频快捷入口。768px 版心内给双入口标题 18／600，副标题 13／400，文案与图形保持至少 12px 间距。入口插画宽窗约 144px、紧凑约 104px，作为画面的一角裁切。构建保留网页布局和代码轨迹，创作保留斜向胶片与演示页。静止状态用清楚的主轮廓和最多两个色彩节点区分两项。悬浮只动 SVG 内部。会员用现有身份和勋章，保留悬浮翻面和主动固定，色彩强度低于三张封面。顶部独立视频快捷入口继续原跳转，可按现有 44px 高度验收。

**二级目录。** 继续用输入框上沿 8px 的底部抽屉。头部 32px，padding 12px，内容间距 8px。用可点封面项承接成果选择，标题区使用单行说明。宽窗可在抽屉上方显示当前能力的一张宽幅裁切预告，紧凑档把预告收到抽屉封面内，同一张资源不重复展示。目录只改变展示，当前草稿和输入模式留在原处。

| --- | --- |
| 构建 | 「制作交互网页」作为主项，复用阅读记录应用封面，说明产物是本地 HTML。旁边为「修改现有项目」，用低对比目录树轮廓与真实项目选择接线。前者进入开发准备，后者从现有选目录流程进入开发准备。浏览器小游戏可作为开发中的文本提示，试玩验证后再决定是否升为封面入口 |

| 能力 | 主画面、抽屉与输入 |
| --- | --- |
| 开发 | 上方用已有阅读应用封面示意交互 HTML。底部准备区展示一个可应用的起步提示和简短成果说明，明确输出到选定目录的 `index.html`。应用示例需保护已有草稿。输入框保留现有项目选择，网页、小游戏等提示共用开发路径。能否试玩或预览以实际生成后的证据为准 |

### 3. 密度、颜色与动效

- 默认态沿用 880×600、侧栏可见的同屏目标。完整卡片档沿用 518px 正文预算。准备态上方只渲染当前能力内容，底部从实际可用高度中先预留输入与发送，再给抽屉分配剩余空间。宽窗抽屉上限 232px，紧凑档 168px。窄内容区优先缩封面到 56×40px 缩略项或把次要参数折成一个摘要，保留完整标题和实际控件可达性。
- 首页靠真实封面建立色彩层次。抽屉用一个主题表面和一层边线。封面区域可用中性底加既有素材自身色彩，选中项使用主题强调色或 2px 描边。保留原幻灯片背景墙的独有视觉。单个按钮的用途、焦点和选中状态在亮暗与灰度下都可识别。
- 目录沿输入上沿淡入 160ms，能力切换仅淡入当前准备内容。入口沿用二轮 220ms 的局部图案反馈，会员悬浮预览和点击固定分开验收。切换能力时编辑器底边和发送位置尽可能稳定，输入法、Tab、Escape 和减少动态效果独立走查。

### 4. 新一轮指导与评审门槛

1. **先做一条能比较的视觉切片。** 固定同一侧栏状态和窗口尺寸，依次展示「默认首页 → 创建目录 → 幻灯片准备 → 关闭模板」。这条路径已有真实模板封面、主题建议和背景墙，适合评审层级。暂不扩展其他界面。交 1280×832 与精确 880×600 的四态全窗对照，以及同尺寸的参考图标注。对比是否看得出成果、是否一眼知道下一步、输入和发送是否可达。视觉负责人确认后再扩到构建和视频。
2. **以真实内容补齐其他层。** 构建用阅读应用与项目选择。视频使用已有短片示例和原入口真实控件。可选项都要能解释「点了发生什么」。无已验证成果的项标为提示词，预览素材需指出来源。现有依据为 `guid/components/assets/` 三张封面、`guid/presentation/covers/` 和 `slideGallery.ts` 中已有主题，二轮已有底部目录、背景墙与视频编辑器。
3. **与视觉改动同时保护发送契约。** 先解决已审查的附件跨能力、视频模型、示例确认和会员固定问题，复测逃逸键优先级。构建、幻灯片和视频分别核对真实提交字段，视频要证明模型与参考素材确实进入同一请求。接单 ID、任务页和侧栏仍用现有机制对账。首页之外的最小共享接缝另作范围裁决。
4. **验收证据必须能看出差异。** 提供同一窗口的静态四态与短录屏，标出输入框底边、抽屉间距、封面可见项和有效参数。补示例取消与确认前后、会员固定与退出、视频安全失败及草稿恢复。两份不同状态证据不得复用同一帧。Vite 紧凑样式能补证，桌面精确窗口和外部生成限制分别记录。

### 5. 可迁移原则

- 首页用少量真实成果说明能力。深入后展示用户此时可选择的内容。
- 目录让人选目标，准备区让人选样例与参数。输入始终承接用户下一步。
- 丰富度优先来自成果封面、可应用模板和状态变化。视口变小时先缩预览和次要控件。
- 每个入口、参数和标签都要有真实动作与可验证载荷。视觉完成与真实发送分别验收。

## 二轮修订 · 底部工作区与专属输入

本节优先于下方 §1–§3 中的旧交互和 SVG 规格。默认首页保留双入口、右侧会员、三张封面与独立视频入口。进入任务准备态后，把空间让给底部工作区。

```text
默认首页              打开「构建／创建」      进入幻灯片              进入视频
[双入口] [会员]       （上方留白）            [原幻灯片线框墙]        [有真实素材才展示示例]
[三张封面]           [返回 标题 关闭]         [模板、提示、导入]      [可选示例层]
                     [两项可点入口]
[普通输入]           [原普通输入]             [幻灯片输入与参数]      [现有视频专用输入]
                       ↑ 四种状态的输入框底部对齐，抽屉从输入框上沿向上展开
```

### 排版与面板

| 状态 | 可实现的规格 |
| --- | --- |
| 默认 | 两张入口仍用当前版心和网格。会员保留右侧位置，三张封面保留可点标题。独立「创建你的视频」仍进现有视频页 |
| 构建／创建目录 | 放到 `.guidFixedInputArea` 内部、输入框正上方，与输入框同宽，间距 8px。面板自然高度，内边距 12px，头部 32px，两张选项等宽，单项最小高 56px，gap 8px，桌面目录总高约 120px。每项一个可辨图标、标题、最多一行说明。上方卡片和画廊在目录态收起，关闭即恢复。只保留一个可见关闭按钮，子层使用返回。打开目录不切换运行能力或草稿 |
| 幻灯片 | 选中就恢复已有 `SlideCardWall`，铺在整个首页工作区后方。模板面板只挂一次，复用 `SlideCreatePanel`，不再包一层带重复标题和关闭按钮的卡。模板与提示行在输入框正上方，宽窗高上限 232px，紧凑档 168px，内容多时面板内部滚动。关闭模板面板仅收起模板，幻灯片背景和模式继续。退出幻灯片才回默认画面 |
| 视频 | 底部用视频模块的短片输入区域替换普通输入。上方有可用视频示例才展示列表。时长、清晰度、模型、参考图由现有视频控件负责，参数是否可选和能否发送以真实视频模式为准。首页仅显示实际接线的动作 |

宽度仍与 768px 版心对齐。目录与模板面板用主题表面色、1px 边线和 12px 圆角，选项不再套重边框。展开自输入框上沿起，`opacity` 加最多 8px 向上位移，160ms ease-out。输入框始终停在底部，输入长文只滚编辑区。验收以 880×600 真实窗口为准，同时记录宿主侧栏状态。默认首屏需看完，准备态允许目录或模板内部滚动。Escape 先交给原生选择器及当前已打开的浮层，之后才关闭首页抽屉。键盘打开目录后聚焦首个可用选项，关闭时回到入口或输入框。

### SVG 与会员动效

当前两张入口都是低对比的小矩形，静止时轮廓相似。开发组的 hover 还移动了整个窗口。二轮用两个不同轮廓构图，缩小到紧凑尺寸时也保留识别特征。

| 图案 | 静止态 | 动态与验收 |
| --- | --- | --- |
| 构建 · 代码变成页面 | 160×96 画框。左下两条代码轨迹汇入右上浏览器轮廓，窗口内用一根分栏线和两个布局块表现网页。主轮廓 1.75px，辅助线 1px，青蓝只给路径终点。宽窗插画宽 144px，紧凑 104px | 悬浮时沿固定路径点亮终点，一组页面块向上落位 4px。外框、文字和卡片保持固定。220ms ease-out，移开反向恢复。截取中间帧核对运动仅发生在图形内 |
| 创作 · 胶片展开 | 同一画框。以带三枚片孔的斜向胶片为主轮廓，露出一角演示页，播放三角保持清晰。主轮廓 1.75px，暖琥珀只用于片孔中的一枚与播放三角。避免与构建共用同一正视矩形剪影 | 悬浮时胶片沿自身方向伸展 5px，后页转开 4°。220ms ease-out，离开恢复。紧凑状态去掉次要装饰，保留片孔和播放三角 |
| 会员 · 双面名片 | 沿用环形勋章、计划和真实账户字段。两面尺寸一致，正面是身份，背面是现有会员信息，沿用已有语言文案 | 精细指针移入约 100ms 后预览背面，移出回正。点击可固定／解除预览，键盘与触屏保留显式翻转。以卡外框监听进入和离开，避免翻面触发抖动。复用受控 `FlipCard`，翻转目标约 300–360ms。减少动效时关闭自动翻转，手动直接切面 |

主轮廓先按亮色主文字 52%、暗色 48% 混合透明试作，辅助线约 18%。最终以可辨性和实际卡底对比微调。图案只在右侧槽内渲染，文字保留独立空间。静止图去掉颜色、文字后仍应能区分网页与胶片。入口无循环动画。减少动效时入口只改颜色。使用源码内联 SVG 和现有主题 token。

### 现状证据与最小接线

### 二轮验收顺序

1. **先做布局和状态。** 用同一张全窗口图对照默认、目录、幻灯片和视频四态，量出底部对齐、抽屉间距和 880×600 的可达性。幻灯片入口与既有模板按钮都指向同一块面板，切换不丢主题。
2. **再验图案。** 记录两张入口的静止、hover 中间、hover 完成和离开四帧，核对文字和卡片矩形不动。会员记录鼠标移入、离开、点击固定和键盘。逐项检查亮暗、紧凑、减少动效。
3. **最后跑真实输入。** 在开发草稿有文案与附件时点图片，验证取消保留、确认切换后只出现图片提示和正确工具上下文。视频对照独立视频页检查组件、素材、参数及键盘行为，从首页发送并核对任务 ID 和侧栏。核查幻灯片模板与页数确实进请求，再确认普通会话正常。渠道不可用时保留实际失败，单列成片验收。

默认布局采用已确认的「左侧双入口、右侧跨行会员卡、下方封面、底部输入框」。大入口打开目录，选细分能力后进入专属准备区。目录和准备区只替换上方区域，底部输入框沿同一条对齐线。

- **默认态。** 两张大按钮是「开发」「创作」，会员勋章卡占原本地文件卡的位置，项目选择集中到输入框。现有「创建你的视频」作为独立快捷入口保留，建议放在顶部右侧，仍打开现有视频页。「创作 → 视频」与视频示例留在首页准备草稿，两条路径均可用。默认直接写办公任务，输入框模式菜单也能一步切到开发、幻灯片或视频。

- **模板与示例。** 首页复用现有视频、阅读记录应用、产品宣传图三张封面。视频打开短片准备区，应用示例后填入可编辑提示词和该路径支持的参数。阅读应用切到开发，图片示例走具备生图工具的任务模式。只有提示词的条目标示「试用提示词」，不声称能打开成品。目标草稿已编辑时，先提供「保留草稿／应用示例」，保留时不写入任何字段。幻灯片模板只改模板参数，主题提示是独立动作。

### 1.2 尺寸、样式与小窗

以下是设计目标。桌面配置的基准最小窗口为 880×600 逻辑像素，系统可用工作区更小时还会收紧。实际排版按扣除侧栏、标题栏后的首页区域验收（`apps/desktop/src/main.rs:40–43、82–92`）。

| 项目 | 宽窗目标 | 矮窗或窄内容区 |
| --- | --- | --- |
| 正文与纵向间距 | 正文宽上限 768，左右留白各 24，顶底各 16，三个区块 gap 12 | 左右留白各 16。正文可用宽 ≤560 或高 ≤580 进入紧凑档，880×600 桌面窗口验收时强制检查紧凑档 |
| 独立视频入口 | 顶部右对齐，高 44，距卡片区 8。复用现有按钮标签、缩略图和跳转 | 同高，可省略副标题，保留图标、标题及可点击区域 |
| 顶部入口和会员 | 列间距 12，剩余宽度按 62:38 分列，左侧两行各 104、行间距 12，右卡跨两行高 220。圆角 12，入口 padding 16，标题 18／600／24，描述 13／400／18 | 左侧两行各 84、行间距 10，右卡跨两行高 178。padding 12，标题 16／600／22。正文宽 <420 时，会员移成紧凑条，入口保留文字和主体符号 |
| 封面 | 三等列，gap 12，封面高 116，标题距封面 6，高 18，封面圆角 10 | 封面高 76。完整内容放不下时改为三项横排缩略条，条目最小高 44。保留封面缩略图和标题，标题最多两行 |
| 二级目录／专属区 | 替换顶部网格，可以占满该区宽度。选项最小高 48，模板横排最多三张预览与「查看全部」 | 面板复用顶部高度预算，详细模板列表在区内滚动或打开限高弹层。封面行及输入框继续可见 |

- 保留独立视频入口后，紧凑档在会员跨行时的设计预算为 `(44+8) + 178 + (76+6+18) + 132 + 2×12 + 2×16 = 518px`。会员改为 44px 条时，预算增加 54px（含 10px 间距），按剩余空间选择封面或缩略条。这是扣掉宿主栏后的内容高预算，仍需用真实窗口确认。输入区在剩余空间下缘，避免 sticky 渐变覆盖封面。低于缩略档预算的极小工作区允许上方内容区滚动，输入区保持独立可达。
- 卡底用现有主题表面色和 1px 内描边。入口普通声明取 `--flowy-radius-lg`，按钮局部将 `--flowy-radius-control` 设为同值，让现有全局覆盖解析出 12px。保持亮暗主题和 2px 键盘焦点环。目录入场可淡入 120ms。返回和关闭将焦点交还可见的触发按钮或输入框模式按钮。

### 1.3 原创 SVG、悬浮与会员翻转

截图里旧「构建」像一只拆开的盒子，「创建」像一张浮起的纸，两个物件的轮廓不足以传达能力。新方案以**正视的浏览器和播放框**做主体，以一个小节点作为共同细节。先画黑白剪影，再加主题色和悬浮。

| 卡片 | 静态构图规格 | 悬浮或主动操作 |
| --- | --- | --- |
| 开发 | `viewBox 0 0 160 96`。主体为正视浏览器轮廓，建议 `x=30 y=18 w=108 h=62 rx=7`，加顶栏横线、三个小点和居中的 `</>`。一根折线从左下接到底边，末端用青蓝小点。宽窗右侧画框 144×86，紧凑档 92×55，优先保留窗口和代码符号 | 只让代码符号组沿 X 正向移动 3px，节点提亮，窗口轮廓固定。进出均 180ms |
| 创作 | 同一画框。主体为正视的 16:9 播放框，建议 `x=44 y=22 w=96 h=54 rx=7`，中心留播放三角。后方错位露出一角演示页，页内两根短线。左下用一条断开的暖紫弧线接共同节点。紧凑档保留播放框和三角 | 前景框沿 Y 上移 3px，后方页转动约 2°。进出均 180ms，图案不侵入文字区 |
| 会员 | `viewBox 0 0 96 96`，正面用两道同心环、现有 Flowy 标志或单字母 `F`、一个偏心节点。宽窗徽章 88×88，紧凑档 64×64，底部保留已有会员身份。背面沿用会员计划、访客状态和双语引言。44px 条优先展示计划或访客状态，引言仅在完整卡面展示 | 悬浮只提亮外环。点击、Enter 或 Space 翻面，第二次回正。复用 `GuidHomeBrand` 的 `FlipCard`、键盘和读屏契约，关闭首页卡片的拖拽、倾斜、放大和眩光。翻面不带动外框尺寸 |

主体线 1.5px、次线 1.25px，圆端与圆连接，用 `vector-effect="non-scaling-stroke"` 保持线宽。以主题主文字色混合透明得到主体线（亮色 32%、暗色 28%）和辅助线（亮色 12%、暗色 10%），品牌色只用于节点或短路径。主图形采用 `fill="none"`，保留至少 4px 动效安全区。图形是装饰，`aria-hidden` 且不拦截指针。切图以右侧插画槽为边界。

入口只在支持 hover 的指针上播放 SVG 组变换，过渡采用 `ease-out`。Tab 聚焦以描边和颜色反馈。开启减少动态效果后只切换颜色，会员沿用 `FlipCard` 的无旋转切面。当前 `FeatureCards.tsx:87–153` 的等距填充插画与 `FeatureCards.module.css:117–169` 的循环浮动由新规格替代。会员复用依据见 `GuidHomeBrand.tsx:115–136` 和 `FlipCard.tsx:263–294`。

## 2. 开发方案

实现范围限 `ui/src/renderer/pages/guid/` 内「新建任务」首页及其专用组件、样式和接线。现有视频页、任务页、侧栏和执行链路作为复用对象。文案优先复用既有 key，需要新增时先在本方案列中英建议值。

### 2.1 状态和提交边界

| 状态 | 归属与规则 |
| --- | --- |
| 展示状态 | 首页维护 `home / category / capability` 与当前目录。返回、关闭、ESC 只改展示和焦点 |
| 草稿状态 | 首页维护当前选择及各模式的草稿。工作区、附件和模板留在对应模式。未发送的修改在首页会话内可来回切换，不调用全局任务偏好 setter |
| 提交状态 | 沿用现有发送与输入法确认边界。发送时锁定当前能力、提示词及实际支持的参数。校验失败定位到对应字段。提交中阻止重复发送，失败保留草稿。对接单状态不明的失败，不自动重发 |
| 已接单 | 沿用已有任务 ID 和任务路由。普通任务进入对应会话。短片进入其结果／进度页，写入视频任务历史。侧栏按同一 ID 选中。只清理本次成功发送的草稿版本 |

首页模式只是发起端的选择。下游保留各自的输入类型与提交方式，项目选择属于任务输入。视频只上传用户显式添加的素材，切换模式和浏览样例时均不触发上传或创建任务。

### 2.2 拆分与复用位置

| 顺序 | 工作包 | 复用和落点 | 可验收输出 |
| --- | --- | --- | --- |

两个现有契约需要特别注意。

- `GuidPage.tsx:317–324` 当前点应用示例会写全局 `coding`。首页新流程只更新本地草稿，发送沿用 `useGuidSend.ts:462` 的逐次任务参数。取消或关闭面板不会更改其他入口使用的全局默认值。

### 2.3 文案与素材

优先复用现有中英 key 与视频／幻灯片素材。若「开发」「创作」需要新的入口名称，建议 `guid.home.developTitle`（开发／Develop）、`guid.home.creationTitle`（创作／Create），由实现时对照现有字典确认是否复用。新增的二级名称、占位提示、关闭和返回的无障碍文案也按中英成对核对。本方案的文案属于视觉规格。

### 2.3 主题自适应线稿

- 三图共用圆端和圆连接、外轮廓 1.5、次线 1 CSS px，用 `vector-effect: non-scaling-stroke` 保持缩放后笔画。构建是两层错位的窗口轮廓加两根对齐辅助线。创建是两张错位页面加两条短内容线。本地文件是一个文件夹外轮廓加一张露出上缘的页。每图最多三个闭合轮廓、三根辅助线，图形离 SVG 画框至少 4，SVG `aria-hidden` 且无指针事件。
- **暗色白块的处理**是重画三幅现有内联图案，闭合轮廓统一 `fill="none"`，用 `stroke="currentColor"` 接收首页 CSS 模块的主题色。构建、创建的小图标也使用 `currentColor`，保留各自形状。没有白色填充层需要在亮色补救。
- 颜色比例为实现参数。正文标题、描述分别取 `--color-text-1`、`--color-text-2`。低对比插画使用主题文字色与透明混合，背景用已随主题变化的表面 token。首页展示组件内按下表计算，取样验收时读取 computed style。

| 用途 | 亮色 | 暗色 |
| --- | --- | --- |
| 入口和视频底色 | `--flowy-raised` 88% + `--guid-canvas` 12% | `--flowy-raised` 72% + `--guid-canvas` 28% |
| 外轮廓 | `--color-text-1` 24% + 透明 | `--color-text-1` 20% + 透明 |
| 辅助线 | `--color-text-1` 14% + 透明 | `--color-text-1` 12% + 透明 |
| 图标和操作箭头 | `--color-text-2` | `--color-text-2` |
| 可点卡 hover 与焦点 | 卡底混入 `--color-text-1` 4%，焦点 `--flowy-focus` | 卡底混入 `--color-text-1` 6%，焦点 `--flowy-focus` |

入口与视频仅用 1px 内描边 `--flowy-border-subtle`，去掉入口软投影和视频星点。会员卡保留双面渐变与既有印章，点阵另乘 0.55 不透明度。背面两句引言统一用 `--color-text-1`，元信息用 `--color-text-2`，避免浅色主题下原来的浅蓝和浅橙被背景吃掉。案例照片保留，badge 沿用照片上的暗底和浅字。主题检查以文字对比 ≥4.5:1、图案在正常观看距离可辨且弱于文字为验收目标。

## 3. 备选方案

**横排三个入口。** 仅在 >860 时把入口改为与画廊同轨的三列，768 正文时各 248、gap 12、单行最小高 112。本地文件改左文右图，三图统一右侧，宽上限 64，文案空间不足时自然增高。≤860 复用主方案的纵排。会员、视频、案例、原 DOM 与交互均沿用主方案。

这个备选适用于评审要求首屏看完三张案例的场景。按同一宽屏锚点及单行网格 112 估算，案例含标题约在 `y=336→504`。代价是 861 宽算例中构建与创建各仅约 201 宽，英文更容易换行，静态构建也会与两个可点入口看起来同等重要。主方案给左侧文字更多空间，保留一眼可分的「两个任务介绍／入口 + 一个本地入口」构图。
