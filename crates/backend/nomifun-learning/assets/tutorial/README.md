# Flowy 学习模块快速上手指南

## 这是什么

Flowy 的学习模块能把你的笔记变成一门真正学得进去的课程：每篇文档配上讲解、练习和复习计划，让你学过的东西不会转头就忘。

这份知识库是 Flowy 自带的教程，包含两篇文档：

- **本文件**：介绍学习模块能做什么、怎么在 3 步内拥有第一门课，以及怎样写知识库才能生成出更好的课程
- **学习模块使用指南**：完整的操作手册，从创建课程到复习管理，按任务一步步讲

## 例子

**例 1：三分钟创建一门课**

1. 打开学习页面，左边是知识库列表，选中一个知识库（比如本教程知识库）
2. 点击「创建课程」，选择「从知识库生成」，再选好模块数和每模块课时数
3. 生成会在后台进行，你在「生成任务」页签能看到进度；完成以后，课程出现在课程列表里，点开就能学

整个过程约 1-3 分钟。生成失败也没关系，任务行上有「重试」按钮，点一下重新生成。

**例 2：一条完整的学习闭环**

创建课程 → 打开课程读讲解、做练习（单选、判断即时判分，填空、反思由 AI 批改）→ 用「知识诊断」摸个底，按建议去学薄弱课时 → 完成的课时会自动进入复习队列，到期在「今日复习」里过一遍 → 用「问题管理」查看所有题目的状态，随时补练。

**例 3：把日常笔记变成学习资料**

任何结构清晰的 Markdown 笔记都可以生成课程，不需要额外准备。想让生成效果更好，写笔记时按下面的「文档规范」来：一个文件一个主题，每篇都有描述、例子、验证三部分。

## 文档规范

这份规范决定了一篇笔记转成课程后好不好学。核心只有一条：**一篇文档 = 一个主题 = 三个部分**。

每篇文档必须包含三个部分（用 `## ` 标题引入）：

1. **描述**：用大白话讲清楚"它是什么"，完整、准确
2. **例子**：1-3 个能照着做的示例，带真实步骤、数字或流程
3. **验证**：3-5 道自测题，至少 2 道选择题或判断题

可选的部分：**迁移**（还能用在哪些场景）、**其他**（常见错误、注意事项）、**关键词**、**推广**（下一步学什么）。按主题取舍，不为凑数硬写。

生成课程时，AI 会先读你的知识库设计课程大纲，再逐篇文档撰写讲解（每课时约 1000-1500 字）和练习题。文档越具体、结构越规整，生成的课程越像样。

## 验证

1. 判断题：创建课程后，生成在后台进行，可以同时使用页面的其他功能，不需要一直等待。（正确）
2. 单选题：生成任务失败后应该怎么办？A. 放弃这门课 B. 在任务行点击「重试」，必要时可换模型 C. 重建知识库 D. 重启应用（答案：B）
3. 判断题：知识库文档必须包含描述、例子、验证三个部分。（正确）
4. 操作验证：打开学习页面，从本知识库发起一次创建课程，观察「生成任务」页签里任务的进度变化，直到成功。
