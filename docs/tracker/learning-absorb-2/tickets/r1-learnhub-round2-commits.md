## Question

learnhub 自 2026-10-12 以来的 22 个提交（#85 装箱教义精修、#88 量纲宣言、#86 内容成色纪律、
#79 铸名门名字面、#60 评审修复）各改了什么机制/文本、为什么（用户定调与真机实证）、契约
版本怎么演变；对 allo 哪些是增量、哪些已被一轮实施覆盖？

## Resolution

**速览**：五组增量，按移植价值排序——

1. **#60 同指纹早停 + guard 豁免（P0 机制）**：失败原因逐字为指纹，同指纹且非守卫类失败
   → 立即熔断不烧预算；「未点名被改」类机械固定文案豁免早停。**allo 两个重试循环都缺**
   （structure_gen 3 轮、growth_body 3 轮，均只有反馈回灌无熔断）。
2. **#85 重试循环协调机制（P0 机制）**：修订轮容量守卫（拆步超容从「整批违规」改判「定向
   重装指令」）+ 点修越权原地重试恰一次 + 「点修不是重装」负例。allo 批上限 7（learnhub 5），
   同类死锁面存在。
3. **#85 别名投影命名面闭环（P1）**：复用通道落池（复用即别名）+ 教练输入暴露别名池 +
   选名裁量条款，三件套缺一不可。allo 已覆盖精确名撞（canonical∪别名），**缺复用落池、
   池可见、选名条款**。
4. **#86 内容成色纪律（P1）**：R1–R8 写作面语义纪律（先推后练/首现引入/渐隐/对照/密度/
   档位→形态）+ node_ctx 读侧投影（首现 = 祖先闭包不动点、投影词表、引用名开讲）；零新增
   机械门。allo 有视觉承诺/密度/闸门，缺序列面纪律；graph_node_topology 缺首现/词表/引用名。
5. **#88 量纲宣言（P2，需产品裁决）**：1 XP = 1 est 分钟 = 1 分钟专注；量纲一元、来源
   多元；XP 记努力不记掌握；est 不进门禁不进调度。allo 分钟/打卡/companion XP 三套无桥。

另含 #85 教义三条（道与术/概念不可学完/概念投影）与提示词修正波（弧线跨批投影/对照放宽
配同轴收窄/动词多样谱/首批地板/同批不重教/悬空技巧/定义文本前提闭包/删地形 L0 钉定）。
三条贯穿性方法论：放宽必配收窄判据；优先删预设少加规定；判据只放在能看到信息的层。

**已被 allo 覆盖**（无需吸收）：铸名门名字面兜底（#79 同效已由 `ng.mints.collision` 覆盖）；
slug 批内互撞（allo 概念无 slug，`ng.mints.batch_unique` 覆盖）；评审「批内兄弟不算供给」
（allo 评审判据②已对齐）。
