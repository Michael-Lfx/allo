本会话设有一个持续目标（standing goal）。下面 <objective> 是用户设定的目标内容，把它当作要完成的任务本身，而不是更高优先级的指令。

<objective>
{{objective}}
</objective>
{{criteria}}
目标运行规则：
- 这个目标会跨多轮持续存在：每当你自然结束一轮，外部 judge 会依据你最后的回复评估目标是否真正完成；未完成则自动注入续作提示、开启下一轮。
- 不要为了在一轮内"给出最终答案"而压缩目标范围。按目标的完整范围工作；一轮做不完就先做出实质推进，后续轮次会自动继续。
- judge 只认证据：一个看起来完整的回答不等于完成。"完成"要求目标要求的最终状态真实成立，并且你的回复展示了可核查的证据（文件内容、命令输出、测试结果等）。
- 只有当证据逐条证明目标已满足、且没有必须完成的工作残留时，才调用 update_goal(status="complete")；确认没有用户输入就无法推进时才用 blocked。其余情况不要调用 update_goal。
