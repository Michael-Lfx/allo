# ADR-0010: 终点锚体系与罗盘整体退役

Status: Accepted

Date: 2026-10-12

## Context

学习模块启动「吸收 learnhub 成果」 efforts（wayfinder 地图
`docs/tracker/learning-absorb/`）：放弃多终点选择，先生成知识结构并可视化。
learnhub 终态的完整推理链（其 ADR 0010→0012→0013→0015）表明：结构一次生成、
仅作参考地图，对生长不供内容、不做判定、不与概念建立任何连接；学习顺序权威
归教练 + 已教概念账；生长永无终态。

allo 的对应物是终点锚一等公民：建课向导第 2 步让用户增删改终点（AI 提议，
数量不封顶）、`learning_course_endpoints` 表（每条终点兼一行零正文标记课时）、
罗盘按终点分节（`compass_md`）、教练双向完成裁决（`EndpointVerdict`，基于
覆盖读数，永不自动置位）、停摆臂之二（全部终点完成 → 停摆）、
`validate_batch` 终点保护条款、终点提议端点 `POST /graph/propose-endpoints`。

终点体系与「结构 = 参考地图」的新模型存在直接的判定耦合：终点裁决把覆盖读
数变成判定依据（结构语义渗入判定面）、罗盘把终点差距分解固化为排期式文本、
停摆臂把「方向完成」当作生长终态。保留任何一层判定语义，都会复活 learnhub
用真机代价否决过的「结构→判定」耦合（其普查废止的理由：长得像判定面的数据
迟早被当成判定面）。

## Decision

经 grilling 四问裁决（票 g1，用户逐项确认）：

1. **终点锚体系完全删除**：`learning_course_endpoints` 表、终点提议端点、
   建课向导第 2 步（向导退化为单步：输入目标 → 生成知识结构）、
   `EndpointVerdict` 裁决与教练上下文终点块、停摆臂第二臂、
   `validate_batch` 终点保护条款、终点相关 WS 事件与 UI（chips、编辑弹窗）、
   i18n 键，全部移除。
2. **存量数据破坏性 DROP**：新迁移删除终点表与终点课时行；课程行与
   `learning_goal` 原样保留（终点只是目标语句的派生，原始目标仍在）。
   迁移注意 09-29 教训：存量失败批次不得误判。066 已有破坏性迁移先例。
3. **生长无自动终态**：停摆臂只留空图臂；自动触发只看就绪水位（< 3），
   加手动「补充节点」；课程收尾交给现有归档能力。覆盖读数降为纯展示徽章，
   永不作判定（「结构不做判定」铁律的推论：覆盖满格也不能当停机条件）。
4. **罗盘跟随终点退役**：`compass_md` 字段、`regen_compass`、
   `compass_updated` 事件、罗盘卡 UI 一并删除，与终点同一支破坏性迁移处理。
   「人读概览」语义交给结构产物的读侧投影（可视化承担，learnhub 同位产物是
   knowledge-system 文档形态）；教练参考改由结构全量块摊开取代（边界细化见
   票 g3）。

### 被否决的替代

- **降级为展示标记**：终点保留为可选方向标签但退出判定面——中间态养一套
  半死体系，且 learnhub 教训是「长得像判定面的数据迟早被接回判定面」。
- **只砍选择步、保留完成裁决**：改动最小，但终点由「结构/生长涌现」后来源
  模糊，裁决对象失去用户确认环节。
- **存量数据封存**：死数据留库，未来易被误当活体系接回去。
- **覆盖满格自动停摆**：省 LLM 调用但属「结构进判定」，直接违反本次吸收
  的铁律。
- **罗盘保留改形 / 一次性导语**：与结构投影语义重叠或很快过时，多养一套
  LLM 产物。

## Consequences

- 建课向导从两步退化为单步；`propose-endpoints` 的两次 LLM 调用消失，
  建课路径少一次 AI 依赖。
- 教练上下文失去终点锚、罗盘、终点裁决三块；覆盖读数保留为展示徽章，
  是否保留在教练上下文由票 g3 裁决。
- 生长停摆只剩空图一种自动情形；「课程长完了」不再有机器语义，用户以
  归档收尾。
- 方向感由后续的结构读侧投影承担：路线图（按主干子图 + 传递闭包自动补
  前导）、结构可视化（票 p1）、覆盖徽章。
- 破坏性迁移：存量课程的终点语句与罗盘文本不可恢复（用户已在裁决中接受；
  课程本体、节点、概念网、批次档案不受影响）。
- ADR-0009 决策 6（多终点锚）与 Amendment 1 第 3 条（终点裁决权）、第 5 条
  （罗盘陈旧治理）自本 ADR 起废止。
