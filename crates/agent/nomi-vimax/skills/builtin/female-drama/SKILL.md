# 女频短剧 Playbook

## 结构
1. 关系钩子（误会/重逢/契约）
2. 魅力展示与张力升温
3. 反转或秘密揭露
4. 情绪爆发
5. 悬念收束（可连载）

## 镜头语法
- 大量眼神与微表情特写
- 双人对手戏用过肩与正反打
- 关键转折用音乐/沉默留白

## 资产规范
- 角色造型辨识度高
- 场景服务情绪（咖啡厅、天台、雨夜街道等）
