# 逆袭打脸 Playbook

## When to apply
- 男频/女频短剧里被当众羞辱后身份或实力揭晓
- 战神归来、真千金、合同反转、当众打脸

## 结构
1. 当众受辱（证人在场，侮辱具体）
2. 把侮辱咬成可兑现的地位事实
3. 证据或旧部现身，压力升级
4. 同一社交空间揭晓（打脸必须被看见）
5. 证人改口或权力易位，收束可连载

## 镜头语法
- 证人视线是打脸的量尺：先给围观者，再给主角
- 关键道具特写（合同、令牌、戒指）必须在揭晓镜兑现
- 打脸后留半拍给对手的脸，不要立刻空镜抒情

## 红线
- 只打不叙事，或把高潮搬到无人空地
- 二次反转堆砌；主角处境没有真正改变
- 用旁白宣布身份，画面上没有证人
