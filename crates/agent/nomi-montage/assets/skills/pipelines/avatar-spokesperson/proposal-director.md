# Stage Director: proposal (avatar-spokesperson)

Produce `proposal_packet`: concept, audience, key message, delivery
promise, style playbook, duration/shot estimates, and budget framing.

## Priorities
Define the avatar persona and tone for the audience. Set delivery_promise to motion. Prefer clean-professional or premium-minimal style playbooks.

## Rules
- Set `delivery_promise` explicitly and justify it in `decision_log`.
- Choose a style playbook that exists under `assets/styles/`.
- Estimates must be plausible for the stated budget.
- This stage usually requires human approval — write for a reviewer, not
  for yourself.
