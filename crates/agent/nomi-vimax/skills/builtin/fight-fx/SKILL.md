# 动作战神 Playbook

## When to apply
- 男频动作短剧、战神归来、当众一打多
- 和「逆袭打脸」叠用：逆袭管侮辱与证人，本手册管这一场怎么打

## 结构
1. 对峙与距离（谁围观）
2. 试探
3. 升级（兵器 / 人数 / 环境）
4. 致命一击或身份揭晓的那一击
5. 余波与代价

## 镜头语法
- 轴线稳定；命中用中近景确认
- 冲击帧前后各留半拍
- 特效服务受力，不替代动作

## 红线
- 飘、看不清谁打谁
- 只打不叙事，证人看不见结果
- 喜剧乱打（除非用户要）
