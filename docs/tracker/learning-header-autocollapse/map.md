## 背景

f3 已落手动折叠（per-course 持久化 + processing 强制展开 + 一行摘要条），
但真实使用发现：用户不会主动找折叠钮——钮小且位置不显眼，头部仍长期占
屏。滚动是「进入阅读」的自然信号，应以滚动深度驱动折叠；同时把钮本身做
显性。与 f3 机制的关系：**自动折叠是临时层，不写持久存储**。

## 已核验事实（2026-11-17 对码）

- 阅读滚动容器 = 学习 Tab 右栏正文 pane（LearningGraphWorkspace.tsx:1107
  `h-full overflow-y-auto`）；TabPane 级 d1 高链（:1011）自滚在其上。头部
  本身 shrink-0 **永不滚出视口**——所以「滚下去后头部让位」只能靠折叠，
  不能靠原生滚走。
- 折叠状态机（:722-729）：`headerForceExpanded`（processing/growth）>
  `headerCollapsed`（持久层 headerCollapse.ts，per-course 只记 true，损坏/
  写失败降级展开）；手动 chevron 双向写持久层。
- 收起钮：展开态标题左 `IconDown text-12px !px-2px`（:766-776）；展开钮：
  折叠摘要条最左 `IconRight text-12px`（:955-970）。均无 Tooltip、无文字。

  正文阅读容器；processing 否决行由 a3 修订合并。
