## Question

learnhub #86 立了内容成色纪律（契约 v2.0，用户定调「留足灵活空间、零新增校验条款」）：
R1–R8 写作面语义纪律 + node_ctx 读侧投影（首现/词表/引用名开讲）。对照 allo 现状
（assets/r2 §4）：写作面有视觉承诺兑现制 + 密度纪律 + 篇幅/闸门，**无序列面纪律**；
`graph_node_topology`（definition+档位停讲+供给节点摘要+防超纲）较完整，**缺 node_ctx 三
投影**。

需要裁决：

1. **写作纪律采纳面**（可多选或全采）：
   - R1 先推后练（方法/公式型结论先从已教前提推出再进例题；断言式违规）
   - R4 档位 → 内容形态（know 认识辨认 / use 应用为主 / teach 完整推导+反例；all o 已注入
     档位标尺，差提示词落点）
   - R5 首现带引入（首现概念给情境引出再定义；非首现一句回收）
   - R6 汇合节点渐隐（assumes ≥4 的节点例题渐加要素）
   - R7 对照要真对照 / R8 例题密度（3–6 个递进例题/15-30 分钟）
   - R2 名字以骨架行为准（引用名开讲、正名仅首现括注——与 g3 命名面交叉）
2. **读侧投影采纳**（零件层，零门）：
   - **首现判定**（祖先闭包不动点：沿 assumes 闭包扫已教节点，本节点 teaches 中未出现过的
     = 首现；并行分支与 archived 不夺首现）——注入节点内容生成上下文；
   - **引用名开讲**（本点挂接实际用名，正名首现括注）；
   - **投影词表**（活跃别名池）——依赖 g3 别名闭环，交叉引用。
3. **落点**：allo 学习图节点内容走 `lesson_content_loop`（ai-agent）+ `graph_node_topology`
   注入；传统课程走三阶段生成。纪律文本进哪套提示词（graph 分支 / 两者皆进 / 传统课程
   是否同享）。
4. **验收形态**：learnhub 全部走「评审观察面抽查 + 生成报告留痕」，零机械条款——allo 是否
   照抄（不新增机械门），还是挑一两条轻机械代理（如 demo 承诺已有类似先例）。

约束：R1 与 allo「正文内不布置练习」纪律兼容（R1 管序列，不冲突）；若采纳 R6，渐隐形态是
写作面指导不是格式模板；多语言/多学科中立性（learnhub 教训：提示词不得写与具体测试内容
直接相关的东西——cb4a38f）。

## Resolution

**速览**：四问全采推荐——八条全采、首现+引用名两投影、通用双管线/概念面单管线、零新门
+ content 冒烟。

1. **写作纪律全采八条**（域中立改写，去咖啡域例）：R1 先推后练 / R2 引用名开讲 /
   R3 投影词表 / R4 档位→内容形态 / R5 首现带引入 / R6 汇合节点渐隐 / R7 真对照 /
   R8 例题密度（3–6 个递进例题/15-30 分钟）。**零新增机械条款**（learnhub 立场：写作面
   语义纪律走写作面指导 + 评审观察面抽查，生成报告留痕）。**R3 条款先立、词表行为随
   g3 别名闭环实施**（词表与别名层同生共死，两票不打架）。
2. **读侧投影：首现 + 引用名**（词表随 g3）：
   - **首现判定** = 祖先闭包不动点（起点 = assumes 概念集；循环扫非 archived 节点，凡教了
     任一 assumed 概念即纳入、并入其 assumes、teaches 计入 ancestor_taught 直到不动；
     本节点 teaches 中不在 ancestor_taught 的 = 首现；并行分支与 archived 不夺首现），
     **零新存储**；
   - **引用名开讲** = `learning_lesson_concepts` 加 `ref_name` 列（小迁移；apply_batch
     引用解析时记录模型实际用名；现行只有 canonical@档位 注入）；正文用引用名开讲、
     正名仅首现括注；
   - 投影词表 = g3 别名闭环的一部分（g3 ①③ 决定池生长与选名裁量）。
3. **落点**：**通用纪律（R1/R4/R6/R7/R8）进两条管线**——图节点内容
   （`lesson_content_loop` graph 分支）+ 传统课程写作提示词（节大纲/节正文）；
   **概念面条款（R2/R5）+ 两投影只进图节点路径**（概念挂接仅图路径存在）；R3 随词表。
4. **验收与冒烟**：**零新机械门**（写作纪律不机械化，走评审观察面 + 留痕）；
   **learning-smoke 增 content 子命令**——为一个节点生成正文落观测面 + 读数（字数/承诺
   兑现/小节数/首现标注），**读数面非门禁**（json 子命令同款）；对齐常设偏好（每条生成
   管线配冒烟入口）。

**派生影响**（供实施切票）：graph_node_topology 扩两投影（首现行 + 引用名）并注入
`lesson_user_text`；三套写作提示词（图节点正文 / 节大纲 / 节正文）补域中立纪律条款；
`ref_name` 列迁移 + apply_batch 写入；learning-smoke content 子命令；传统课程写作提示词
（section_outline_system / section_body_*）补通用五条。
