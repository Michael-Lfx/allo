# 女频短剧 Playbook

## When to apply
- 甜宠、虐恋、重生误会、关系驱动的竖屏短剧
- 魅力展示必须服务关系，而不是时尚片

## 结构
1. 关系钩子（误会 / 重逢 / 契约 / 当众）
2. 魅力与张力升温
3. 反转或秘密揭露
4. 情绪爆发（外化，不写标签）
5. 悬念收束（可连载）

## 镜头语法
- 眼神、微表情、过肩正反打
- 关键道具（信、戒指、钥匙、旧照片）贯穿
- 转折用一句短反应落地，不用空持镜拉时长

## 红线
- 内心独白替代站位
- 空街空咖啡馆没有关系动作
- 用凝视身体代替凝视关系
