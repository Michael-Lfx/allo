## Question

用户裁决：研究文档（学习观教学法框架）应进一步影响**整个课程正文的节
规划和正文以及各类习题的生成指导，主要是提示词**。如何把上游原内容
（SKILL.md 五步循环 / textbook-teaching.md 单元划分与写作规则 /
framework.md 速查表）收编进我们的生成面提示词，而不引入概率性机械门？

## 上游原内容取证（2026-11-18 读毕，行文以提取为准）

- **SKILL.md**：五步循环操作化——描述知识=「要认出什么/从什么推测什
  么」；制定材料=「概念混淆用对比，关系不清用机制或推导，抽象悬空用
  具体例子」；继承模型=「具体例子与概念逐项对应，不只展示答案」；验
  证=「未讲过的新情况」，独立验证要求「先呈现题目，等作答后再给答
  案」；「讲概念时说明判别依据、适用范围，并选有区分力的正负例或近
  邻对比；不只换句话复述定义」。
- **textbook-teaching.md**：单元划分=「围绕一个可辨识的概念或可应用
  的关系组织，而非机械地一页一课」；概念写作=区分「属于概念的条件」
  与「属于之后可推出的性质」；推导=「关键等号/不等号/近似号各有什么
  依据」；模型边界=「解释省略了哪些因素及为何此处可省略」；例题结尾=
  「提取本例的通用结构，指出换掉哪些表面细节仍可使用」；负例语法=
  「揭示边界，而非只给明显无关对象」；验证题=「只增加可控差异」+ 类
  型清单（新对象分类/对照情境/条件变化/结果预测/推导补步/实际操作）。
- **framework.md**：诊断签名表九行（表现→排查→修法）；负例选取与对
  比例组规则全集（近邻/集合关系/性质特征/负例反例/分段例组）；表述
  转换（「已知什么，可以判断什么」）；「换材料，而非无限同义解释」。

## Terms（方案草案，施工前过裁决）

- **R-a（节规划面）**：ADR-0002 分节契约的节规划指导吸收「单元围绕一
  个可辨识的概念或可应用的关系组织」（替换机械按来源/页推进的残留语
  义）；节序列照五步循环语义（描述=要认出什么/从什么推测什么 → 练习
  验证=未讲过的新情况）。
- **R-b（正文写作面）**：正文写作指导吸收——概念的条件/性质区分、推
  导依据标注（关键等号依据）、模型边界（省略因素及理由）、例子下上
  对齐（逐项对应不只报名目）、例题收尾提取通用结构、「换材料，而非无
  限同义解释」。落点 = lesson_content_loop 系统提示与分节写作规则函
  数（唯一事实源生成面）。
- **R-c（全题型面）**：每题型映射判别/联结轴的生成指导——判别类
  （classify/single_choice/true_false）走负例语法（近邻负例/集合关系
  /性质特征区分）；联结类（ordering/fill/matching-if-reintroduced）走
  联结材料语法（依据→目标→条件）；验证题类型清单（新对象分类/对照情
  境/条件变化/结果预测/推导补步/实际操作）进 practice 节活动配比指
  导。可控差异原则全题型通用条款。
- **R-d（已裁决不做）**：失效类型学全量吸收（诊断签名表/探针纪律/重
  现泛化分账/能力轴）= 大工程，**挂起为未来独立波**（用户：慢慢吸收，
  有想象空间，以后再说）；本票只收编材料学/负例语法/探针区分度原则
  进提示词。
- **R-e（词汇纪律）**：UI 面不透传书内术语（判别模型/联结模型/坍缩
  ——用户面用日常词）；GLOSSARY 采纳走三面词汇纪律，v1 不采纳。
