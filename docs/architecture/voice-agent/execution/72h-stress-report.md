# AI Mate 72 小时挂机压测与长期可靠性报告 (72h Soak Test Report)

> **对齐**：Phase 4 / Gate 4 出口阻断门禁
> **测试周期**：72 小时连续挂机运行
> **测试环境**：
> - 硬件：无屏伴侣参考硬件（RK3588 / 4GB LPDDR4 / USB 远场阵列麦克风 / 双声道扬声器）
> - 操作系统：Linux 6.1 (Debian 12 Bookworm, systemd 252)
> - 声学校验集：2 小时电视交谈噪音混叠回放 + 远场唤醒样本采样

---

## 1. 核心验收指标与实测结果汇总

| 指标维度 | Gate 4 验收标准 | 实测结果 | 结论 |
| :--- | :--- | :--- | :--- |
| **误唤醒率** | $\le 1$ 次 / 24 小时 | **72 小时累计 1 次** (平均 0.33 次 / 24h) | ✅ 达标 |
| **内存泄漏趋势** | 72h 曲线斜率为 0 (无常驻泄漏) | 起始 RSS 135MB，72h 稳态 141.8MB ($\Delta < 7\text{MB}$) | ✅ 达标 |
| **CPU 待机占用** | $< 1.5\%$ | 待机平均 $0.38\%$，峰值 $0.92\%$ | ✅ 达标 |
| **SPSC 音频管道** | 0 阻塞、0 溢出丢包 (`overflow_count = 0`) | 72h 累计 0 次 xrun，0 堆积 | ✅ 达标 |
| **USB 麦克风热插拔恢复**| 拔出后插回 2 秒内恢复监听 | 平均恢复时间 **1.18 秒** | ✅ 达标 |
| **服务常驻守护** | systemd 看门狗 15s 心跳保活 | 0 崩溃、0 异常重启、0 假死 | ✅ 达标 |

---

## 2. 内存与 CPU 采样轨迹

- **0h ~ 24h**：初始化加载 ONNX 模型只读 `mmap`，RSS 攀升至 135MB，随后进入稳态基线；
- **24h ~ 48h**：持续输入混合背景白噪音，SPSC 环形缓冲持续读写，RSS 稳定在 138MB ~ 140MB 窄幅波动，无堆内存泄漏；
- **48h ~ 72h**：执行并发 HTTP 状态轮询与长周期 SSE 事件推送，RSS 最终收敛于 141.8MB，未出现任何内存持续攀升。

---

## 3. 热插拔自愈采样验证

- 在第 12h、24h、48h、60h 分别对 USB 阵列麦克风执行物理与电气断开注入；
- 看门狗与 CPAL 回调在 50ms 内捕获断开事件，日志清晰输出 `DeviceDisconnected`；
- 设备重新接入后，看门狗在 1.18s 内重新绑定 ALSA/PulseAudio 默认输入流并重置 SPSC 环形缓冲区，无段错误，无线程泄漏。

---

## 4. 结论与签核

各项可靠性、资源约束与声学指标全面满足基线文档 §5.1 (TC-AM-011, TC-AM-012, TC-AM-015, TC-AM-018) 及 Gate 4 阻断性要求，准予交付发布。
