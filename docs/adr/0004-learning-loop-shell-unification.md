# ADR-0004: 学习三条生成流的循环外壳统一（learning_loop）

Status: Accepted

Date: 2026-09-09

## Context

学习图 / 课程大纲 / 课时内容三条生成流各自携带一份近乎逐字复制的「循环外壳」：
`run_loops`（生成循环 → finish 门 → 审计驱动的修复循环，约 120 行 ×3）、
`LoopContext` 四件套（published 槽 + 轮次日志 + 事件下沉）、超时外壳、provider
解析、脚本化测试假件。`loop_core.rs` 只吸收了内层单圈机制（重试 / 退避 /
损坏反馈降级），外壳层完整保留三份。

复制已经产生可观察的漂移（盘点于 2026-09-09 评审）：

- **取消不对称**：`CancellableProvider` + `generation_registry` 只包了学习图与
  大纲；课时内容生成（可达 600s）对 `/generate/status` 与 `/cancel` 不可见。
- **事件翻译不对称**：`round_feedback` 只有学习图翻译上线，大纲与课时在
  `_other` 分支丢弃；学习图的 `kind: "learning_graph"` 帧标记是前端的非法值。
- **预算遮蔽**：学习图本地 `GENERATE_MAX_ROUNDS = 100` 遮蔽 loop_core 共享的
  50，另有 1800s 超时与 32768 token 预算（按模型 output 上限再钳制）；共享常量
  名相同值不同，读代码必须逐文件确认生效值。
- **发布优先级不对称**：学习图在两轮循环结束后**先**检查 published 再映射循环
  错误（末轮发布可存活）；大纲与课时先 `?` 传播错误——同样的末轮发布会被吞掉。
  这是潜伏 bug，本 ADR 刻意**不**在合并中顺手修（见 Decision）。
- **resume 三协议**：学习图显式路由 + 全图 dump + scope + 轮次日志；课时经
  lesson_id→draft 映射 + 草稿状态 + 轮次日志；大纲无续建语义。
- 39 个循环测试的脚本假件三份复制，且各自有独有断言（lg 的 `seen_effort`、
  co 的 `open_failures`、lg 独有的发布存活/取消/终审等）。

第四条生成流若照现状加入，需复制约 400–500 行外壳与假件。

## Decision

**统一外壳，落地 `nomifun-ai-agent/src/learning_loop.rs`，学习专用，不做引擎级
泛化**（无第二个真实使用者，不制造假想 seam）。三条流收敛为五个插头：系统提示
词、工具集（生成面/修复面）、finish 门、发布类型、预算与翻译配置。

**差异全部显式化为配置，合并 PR 零行为变化。** 上表全部漂移项转成 per-flow 显
式值：`LoopBudgets`（100/1800/32768+钳制 vs 50/600/8192）、事件翻译开关
（kind 标记、round_feedback、audit 帧、轮次日志、流选择、「构建/生成」标签）、
发布优先于报错开关（lg true / co·ls false 保持现状）、失败诊断钩子（lg 附加
草稿审计，co 归一取消，ls 透传）、resume 各按原协议留在 service 层。任何后续
想把某个差异统一掉的人，必须显式改配置并解释——不存在无声归并的通道。

**行为矩阵由测试钉死**：各流既有 22/7/10 个测试在移植后必须原样通过（它们就
是行为不变的金标准），另加翻译器单测锁定每条流的线上帧形状差异。

**已知不对称刻意不修，列为独立后续**（每个可独立回滚）：课时流接入取消、
round_feedback 补齐两流、co/ls 采纳发布优先于报错、kind 标记与前端联合类型对
齐、`phase:"degraded"` 帧无前端消费者。

**迁移顺序：学习图先行**（22 个测试是最硬的安全网，由最苛刻客户塑形接口），
随后大纲、课时。`loop_core.rs` 保持内层单圈机制纯粹，不膨胀。

## Consequences

- 删除约 500 行逐字复制外壳与三份测试假件；第四条生成流的成本降为插头声明。
- 取消、事件翻译、预算从「读三个文件才知道」变为「读一张配置表」；三个已知漂
  移 bug 显式化后各自成为一行配置的后续修复。
- service 层三座草稿内核（inspect/patch/audit/finish 脊柱 + 各自扩展面）不动；
  引擎接缝 trait（`LearningGraphAgentEngine` 等）签名不动。
- 外壳差异的存续依赖矩阵测试持续运行；删除某流的独有测试前必须先确认对应配置
  项是否有消费者。
