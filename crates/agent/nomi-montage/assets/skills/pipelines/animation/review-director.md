# Stage Director: review (animation)

Produce `final_review` using the seven-dimension rubric
(concept, script_story, visual_craft, motion_continuity, sound,
pacing_delivery, technical_robustness).

## Focus for this pipeline
Score visual consistency across the whole runtime, not only individual shot quality. Character drift is a hard fail on visual_craft.

Score from the composed cut, not from earlier stage optimism. Set
`pass` from the weighted total against the publish quality gate.
