# 都市霸总 Playbook

## When to apply
- 契约婚姻、职场身份差、豪门都市情感短剧
- 公众冷淡 / 私下失守的反差

## 结构
1. 权力空间里的第一面（谁进来、谁起身）
2. 契约或秘密把两人绑在同一局
3. 公开场合克制，私下漏一次人
4. 第三者或家族规则加压
5. 靠近或翻脸，收束可连载

## 镜头语法
- 电梯、落地窗、长桌、车后门写地位
- 正反打里用谁先开口、谁先低头
- 合同、戒指、门禁卡当贯穿道具

## 红线
- 拍成高奢广告：只有材质没有关系
- 用旁白宣布“他其实很爱她”
- 羞辱作为唯一性格，没有私下漏出的人
