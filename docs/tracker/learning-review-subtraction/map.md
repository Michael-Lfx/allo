## 灵活纪律（2026-11-23 用户裁决：改动多/风险多，必须逐票闸门按实测转向）

1. **逐票闸门**：每票完工读数进 Resolution，**下一票开工前对照门条件重审**——
   读数不达标或病灶已消失，停线换法或降级留观，不承诺全做。
2. **每票独立可回退**：全部走开关/常数/golden 可关形态（rs7 env 开关、
   rs8 预算常数、rs6 纯校验器行为），无跨票耦合；任一票回退不牵动前序。
3. **读数先行**：rs1 live 档案 + rs5 回放臂 + normalized/findings 查询是
   每票共同读数面（已在，不新建）。
4. **rs9 不预设计**：开工前按当时读数重新裁剪范围（上游五票规格是参考
   不是承诺），并重读上游最新实现（#253/#257 修订后形态）。
5. **通用规则（本波方法论沉淀）**：实质守恒执法——执法前先消解机器自己
   的读法；可归一（机器可证改写且实质不变）就地改写+留痕；实质矛盾才
   作废重试；归一不允许把"有指名的打回"变成"无指名的放行"（方向守恒）。

## 演进线（留案，不开票——数据闸候选）

- **v3c 清单瘦身逐类开闸**：机械可证噪声/已知面覆盖类从机械点名清单里
  滤除（上游 #213 单字预滤先例，清单是机器生成的输入、滤它不是契约改
  动）；每类凭误滤率样本开闸。数据源=回放臂 + live 档案 fragments 读数。
  触发条件：单类误滤率样本 ≥3 例且零反向病例。
- **重试 surgery**：死因重试时机器已核行照抄、只重裁被点名行（上游重试
  也是整份重发，无先例；单对象契约内、零 rubber-stamp）。触发条件：死因
  重试再现 ≥2 次且有留存回包样本（11-23 call2/call3 原文已在
  calls.jsonl 可作首例）。
- v3a 输出确认制维持 park（rubber-stamp 风险 + 上游无先例 + 誊写只占调
  用成本小头）；上游教训三铁律（检测/处置分离、动作空间优先于执法强
  度、严格加法）为本波一切新机制的开闸前置。

1. 顺序：rs1 → rs2 → rs3 → rs4 → rs5（rs5 的 Scripted 部分随 rs2/rs3
   同票落地，live 回放臂殿后）。无硬 blocked_by。

   出现 reject 方向翻转/该打不打的放行。命中即回退该票、换法再立票。
3. 契约改动（rs2/rs3）验收必含：`cargo test -p nomifun-learning` 全量绿
