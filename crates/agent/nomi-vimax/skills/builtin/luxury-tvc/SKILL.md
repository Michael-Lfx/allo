# 高奢版 TVC Playbook

## 结构
1. Cold open 材质/氛围钩子（1–2 镜）
2. 人物与品牌世界建立
3. 产品或主张的高潮揭示
4. 静默收束 + 品牌印记

## 镜头语法
- 多用微距材质、慢推、侧逆光轮廓
- 少用急切手持与快速剪辑
- 台词克制，用画面与音乐叙事

## 资产规范
- 角色妆造干净高级；场景去杂物
- 主色不超过 3 个；保留大量负空间
