## 背景

f2 波修了课程卡进度分母（剔 skipped），用户随即发现 XP 读数面板的数字
与课程对不上。查证结论：**计算按设计工作，呈现面三层失真**。

## 已核验事实（2026-11-17 对码 + 截图对数）

- **面板是全局跨课程聚合**：`xp_reading`（service/xp.rs:248-303，路由
  `/api/learning/xp/reading` 无 course 参数）——`total_nodes` = 全部现存
  且启用课程的**课时行数**（:270-278）；`settled_nodes` = 全部
  node-completed XP 事件去重（:279-291）；`remaining_est` = 未结算课时
  est 分钟总和（:292-303）；ETA = 近 7 学习日 XP 步伐推算（:305+）。
- **对数验证**：0/21 = 编程课 4 课时 + 用户新建课 ≈17 课时；430 分钟 =
  两课剩余 est 之和；191 天 = 步伐近零（近日 XP≈0）推出的巨大天数。
- **呈现缺陷三层**：
  1. 面板在「全部课程/全部标签」下拉正下方，**不受下拉控制**、无任何
     作用域标注——用户天然按单课解读（ReviewBanner:157 挂 XpPanel，
     XpPanel 不接收筛选）；
  2. 单位词混用：面板说「节点」（xpGaugeSettled），课程卡说「课时」，
     分母实际数的是课时行（字段名 total_nodes 名实偏）；
  3. 与 f2 新口径并排打架：课程卡分母已剔 skipped，面板分母仍含
     skipped 课时行——两尺同屏不同口径。
