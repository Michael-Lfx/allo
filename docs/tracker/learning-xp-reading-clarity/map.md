## 背景

f2 波修了课程卡进度分母（剔 skipped），用户随即发现 XP 读数面板的数字
与课程对不上。查证结论：**计算按设计工作，呈现面三层失真**。

## 已核验事实（2026-11-17 对码 + 对库验数；初诊「多课聚合歧义」被用户复核推翻）

- **真缺陷定性：f2 漏改消费面**。现存启用课程只有一门（编程课）：21 节
  课时（19 + 生长 2），其中 skipped 17、completed 0。课程卡 f2 分母 =
  21−17 = 4（截图 0/4 ✓）；XP 面板 total_nodes = 21（0/21 ✓，不剔
  skipped）、remaining_est = 490min（截图时 19 课 430min，此后生长
  +2 课 +60min）——**「剩余 430」里 ≈330 分钟是用户已跳过的内容**。
  剔 skipped 后分母 4、剩余 ≈100min，与课程卡立即对上。
- `xp_reading`（service/xp.rs:248-303）total_nodes/remaining_est 两查询
  缺 skipped 过滤 = 修法落点（LEFT JOIN progress 加
  `p.status != 'skipped'`，零 schema 变更）。
- 次要呈现缺陷：面板无作用域标注（多课场景仍会误读）；「节点」vs
  「课时」单位词；ETA 步伐近零直出 191 天。
