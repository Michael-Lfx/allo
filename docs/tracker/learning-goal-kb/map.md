# Map: 学习课程生成——目标中心化与知识库接回（2026-10-13）

<!-- wayfinder:map -->

## Destination

把"从知识库生成课程"从**库即课程的一次性采样快照**改造成**以用户目标为中心、可实时读库、
支持多库**的生成面：目标文本成为采样排序、大纲范围、课时检索的主索引；课时正文写作接回
知识库（检索 + 全文读取）而非冻结的 8KB 文件头；多知识库选择作为参数扩展落地；课程式
知识库（本身按课编排）不因目标筛选而倒退——这四个方向全部裁决完毕并可按票实施。

- **现状锚点**（评估会话核实）：
  - 知识服务在 learning crate 只有两处调用：`tutorial.rs:52`（教程播种）、
    `service/generate.rs:119`（建课采样）——**建课后知识库再无读取**；课时正文 grounding
    = 单文件 8KB 前缀（`sample.rs` 的 `read_prefix_lossy`）+ 邻居 1000 字（`lesson.rs:12`）。
  - 采样 = `rels.sort()` 字母序 `take(40)`（`sample.rs:52-56`），不看目标。
  - 传统建课请求**没有目标输入**；`proficiency_statement`/`learner_basis` 是学习图专属。
  - `KnowledgeService::search_bases(kb_ids, query, limit)`（`service.rs:3802`）已是跨库
    词频检索：路径/标题加权打分、文件级命中（`{kb_id, kb_name, rel_path, heading,
    snippet, score}`）、64MB 缓存、每库 20s 遍历预算（超时该库返空）、结果按分归并；
    agent 侧 `knowledge_retrieval.rs` 的 search→`encode_doc_handle`→read 全文已闭环。
  - **query_terms 只按空白切词**（`service.rs:5967`）——CJK 整句会当一个词条做子串匹配，
    长句检索必然空，此行为需在检索侧修正（t3）。
  - 教程课程走 `import_course` 资产包（`tutorial.rs:85`），不经 `GenerateCourseRequest`
    校验——本次输入面变更不触碰它。
- **铁律沿用**：课程边界（结构课程内隔离）、概念表跨课程；学习图课程不读库（t5 议题）。
- **常设偏好沿用**：每条生成管线配 `nomicore learning-smoke` 无头冒烟入口；LLM 观测走
  `ArchivingCompleter`。
- **工作方式**：t1 起为 task 票（规格已裁决，直接实施）；t5 为 grilling（边界裁决）。
  决议逐票写入 Resolution 并追加到下方索引。

## Decisions so far（评估会话输入，待各票 Resolution 追认）

- **目标输入形态（用户裁决 → t1）**：知识库流加**多行文本框**——简单时即课程名称（课程名
  本身是高度抽象的目标），复杂时是目标描述/长说明；不做形态判断，整体文本即目标；课程名
  默认即该文本，不引入 LLM 派名；UI 必填、后端 `Option` 宽容（缺省回退库名，兼容旧客户端）。
- **检索形式（评估会话定案 → t3）**：**复用 `search_bases` 的多词条关键词查询**，不新建
  检索系统；查询词必须**词条化**（中文空切分不成立，CJK 退化行为在 t3 修正）；建课采样排序
  用确定性打分（不引 LLM 随机性），课时写作查询 = 课时标题/purpose 词条；embedding 语义
  检索为 v2 增强，不立项。
- **不倒退纪律（课程式库，用户追问；防护 → t2/t3）**：相关度决定**读什么**，结构决定
  **按什么顺序读**；冲突时结构优先——采样清单保持路径字典序、连贯预算补章节内相邻文件、
  检索不替换课时主 source、采样快照保留完整目录树并披露低分未采文件。
- **多知识库形态（→ t4）**：遍历 `search_bases` 已天然多库；落库采用数组列（仿
  `cs_agents.knowledge_base_ids` 先例），预算按库分摊，去重键排序后拼接，引用带库归属。
- **排期**：本图 t1/t2 先行，二轮吸收实施（g1–g4/t1）随后 rebase。
- **t1 已落**：目标 = 知识库流多行文本框整体文本（UI 必填、后端 `Option` 宽容）；课程名默认
  即该文本（单行折叠 + 60 字截断）；落库复用 `learning_courses.learning_goal`（048 既有列，
  无新列）；目标贯通简报/scope 主题/蓝图提示词/课时上下文/agent 工具；无目标路径逐字回退
  现状。`learning-smoke`：本树无该无头入口，目标参数入口 = HTTP 建课端点 + agent 工具
  （t1 Resolution 记缺省行为）。
- **t2 已落**：词条化 = 确定性切片（标点/空白分段 + 中文相邻二元 + 停用词/单字过滤，纯函数
  模块，t3 直接复用——**判据已定：不引 LLM**）；打分数值对齐 `score_md`（路径 +4/标题 +3/
  正文词频封顶 5）；相关文件先占额度、连贯补入 ≤ 30% 且只用余量；输出路径字典序；单文件
  8KB → 24KB 且按命中段落 ± 上下文窗口选摘；披露走新列 `samples_meta_json`（含
  `goal_fallback` 标注——目标与库零交集时退回默认采样并如实披露，不失败、不冒充按目标采样）。
- **t3 已落**：课时写作接回知识库——traditional 课时生成实时读库：primary = 大纲主 source
  **全文**（`read_file`；超预算 24KB 按词条相关度选摘，截断标注），补充 = `search_bases`
  top-N 命中读全文（单片段 ≤8KB、合计 ≤40KB）；**快照摘录降级为兜底**（库不可达/文件被删
  照常生成 + 披露降级）。锚定纪律落地：检索永不替换主 source、主 source 自命中不重复作补充；
  不倒退纪律落地：相关度决定读什么（选入/丢弃按分），结构决定按什么顺序读（补充片段交付前
  回路径字典序）。查询词 = 课时标题+purpose 词条 + 目标词条集（随披露 `goal_terms` 持久化，
  建课后稳定复用；旧课程重切 `learning_goal` 兜底）。前置件同日修毕：`query_terms` 对 CJK
  段追加字符二元——中文整句查询从零召回变为可命中，纯英文/短词行为逐字不变。读数走
  `learning.lesson-generation` 的 grounding 帧（命中数/扩读数/降级态）+ 进程内日志，前端在
  生成期间披露降级。`SourceSpan.kb_id`、课时 source 多引用、`validate_blueprint` 语义按
  实施导航留给 t4；单节重写（`rewrite_lesson_section`）仍用快照摘录（票面只列三处提示词）。
- **t4 已落**：多知识库 = 数据面/输入面的参数扩展（迁移 073 增
  `learning_courses.source_kb_ids`，`source_kb_id` 列保留为主来源、老行回填单元素数组；
  `id_schema_contract` 的 SetNull 条目不动，读侧过滤已删库 id）。请求面：`knowledge_base_ids`
  列表优先（与单值同时给出时单值必须是列表成员），上限 5；去重键 = 库 id 排序拼接
  （`kb:{a}+{b}`，乱序提交命中同一槽位）。采样：库序按库名+id 字典序，配额等分 + 前向借用 +
  末尾回收（每库保底 4 文件/16KB），总量 40 文件/960KB 不变；**多库路径带 `{库名}/rel`
  命名空间**（重名 `~2` 消歧），单库保持裸路径逐字旧行为；披露增逐库 `bases[]` 归属映射
  （无目标的多库路径也产披露）。引用归属：`SourceSpan.kb_id` 由生成管线按命名空间标注，
  课时视图与 t3 实时读库按 `(kb_id, 库内相对路径)` 解析（检索覆盖全量来源库），已删库的
  路径解析成无归属、绝不落到幸存库。前端：建课对话框知识库多选（上限 5，首个 = 主来源）、
  「来源：库A、库B」进进度/详情/悬浮条、课时原文面板按归属回看。agent 工具 `base` 收库名
  数组（候选集仍限会话挂载集）。空库口径：多库按库跳过、全空才 400（单库保持原 400）。
