## Question

learnhub #105/#106/#107 建了完整的会话体系：SessionRecord 落盘（首写为终/不携判分底/
abandoned「有头无尾也是数据」）、五命令（start/swap_window/grade_answer 不落账/
complete 幂等步进/abandon）+ 脱敏投影（字段级缺席判分底）+ 统一三型会话页（逐节步进/
5 秒回忆门/提前收杆/结算卡）。

allo 的学习单位是**课时**（LessonStatus: InProgress/Completed/Skipped 二态 + 进度行），
作答走 activities/attempts，判分本就在服务端；没有「会话」这个粒度——一次学习行为的
起止、逐题作答序列、流失（abandon）信号都无记录。

需要裁决（这是产品形态级决策，不是移植细节）：

- **(a) 引入会话层**：SessionRecord 模型 + 最小命令面（start/complete/abandon 三件起步，
  swap/grade 后置）——获得：逐题作答历史（#110 作答历史抽屉的底座）、流失信号、
  「首写为终」的诚实数据、结算卡读数；代价：新表新命令 + 学习页改造（课时学习器包一层
  会话壳）。
- **(b) 只采纳数据面**：给现有作答路径补「会话 id 锚」+ 作答事件落盘（practice.answer
  的 elapsed_ms/response/session 字段形态），不建会话命令面与统一页——数据先攒着，
  产品面后置。
- **(c) 不采纳**：课时二态够用，会话体系整体后置（含复习中心聚合读数/检测记录读面——
  r3 报告标注这两项依赖会话模型）。

连带面：复习阶梯（#91/#92 R1/R2）、quiz 触发（#90 K 计数）、护栏债务刹车都建立在
「会话/作答事件流」上——选 (c) 则这些一并后置；选 (a)/(b) 则 #89 归因与 #90 quiz 的
「 allo 版」获得地基（是否做仍是独立决策）。

约束：allo 已有的题级卡/复习队列不动；adopt 时「判分底服务端持有」红线 allo 天然满足；
学习页改造须过主题/i18n 红线。

## Resolution

> **裁决方式注记（2026-10-14）**：用户指示「推进直到所有设计定案票结束」，按推荐判断
> 默认裁决（连续第五轮未逐票盘问）；票面标注可复议。

**速览**：采 **(b) 只采纳数据面**——作答事件补锚与字段现在做，会话命令面与统一页后置
（触发条件明确）。

1. **裁决：(b) 数据面先行**。理由：会话命令面/统一页（learnhub #106/#107）深植于其
   「教练 resolve → 今日安排」编排，allo 无此层（学习流 = 就绪集自选节点 → 课时内容 →
   活动），现在引入会话壳是空转；而 (c) 全不采纳会丢掉两组正在发生的数据——课时内逐题
   作答细节（elapsed/response）与流失信号。(b) = 数据先攒、产品面按需长出。
2. **数据面落地清单**：
   - 作答记录（activity attempts / 作答流水）补四字段（learnhub persistence v1.17 同款）：
     `elapsed_ms`、`response`（原始作答逐字）、`session`（会话锚，见下）、`forgot`
     （缺省 false）、`predicted`（可选）；
   - **会话锚的 allo 形态**：不建会话实体，先落「学习行为组锚」= `{course_id, lesson_id,
     started_at}` 的 ULID（作答批量提交时生成，一次学习行为一锚）；将来升会话实体时
     该锚即 session ULID（前向兼容）；
   - abandoned/流失信号：课时学习器关闭/切页时若已作答未完成 → 落一条 abandoned 标记
     行（零判分零结算——「有头无尾也是数据」）；
   - **首写为终**纪律：作答流水追加只增不改写。
3. **产品面后置（雾区升级为条件票）**：会话五命令、统一三型会话页、复习中心聚合读数、
   题目维护页作答历史抽屉、检测记录读面——**触发条件 = 复习中心/维护页任一进入实施**，
   届时以数据面为底起票。**检测/quiz 线（二轮 g1 三线之三）的载体同步后置**：allo 无
   检测会话概念，教新线与复习线先行（t1 落两线），检测线等载体。
4. **「想不起来」5 秒回忆门 / 提前收杆 / 换一项**：属会话页产品面，随第 3 条后置；
   allo 现有「跳过」语义不动。

**派生影响**（供合并切票）：作答记录表加列迁移；批量提交接口加锚生成；abandoned 标记
落点；t1 的复习线结算以「作答流水按日聚合」为工作量当量数据源（无会话实体也能算）。
