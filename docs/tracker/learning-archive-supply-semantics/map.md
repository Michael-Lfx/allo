## 裁决与政策

- **归档供给语义（全宽）**：知识供给面（教练已教账/生长门/跨课供给/生成
  上下文 teachers-forbidden/known_names）以「未删」为宽度，包含归档课
  ——ADR-0017 修正案（本波开图提交入册）。
- **两轴判据**：「现在能做什么」（可服务性计数）滤归档；「学过什么/该教
  什么」（知识供给）含归档；首现仲裁维持排除归档（archived 不夺首现）。
- 依赖不变量：供给面全宽以「无孤儿边」为前提——delete-hardening t2 的
  purge 单源已保证（软删/硬删都清 lesson_concepts，已核 course.rs:846）。
