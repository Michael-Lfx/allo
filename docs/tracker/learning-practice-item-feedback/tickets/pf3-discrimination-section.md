## Question

用户提议「专有的类型节」：判别模型类的教学内容应有专属的节形态——把
判别模型三件套（输入空间 → 类别轴 → 最小对对照）作为节的显式结构，
配 classify 判别题，而不是散在 concept/example 节的叙述里。节契约
（ADR-0002 分节契约：concept/example/demo/summary/practice）如何承载？

## 已核验事实（2026-11-18 对码 + 研究文档对读）

- 现节 kind 五种，末节恰好一个 practice（ADR-0002 分节契约，f 波前期
  已核实 :205 系统提示）；判别模型教学内容目前散在 concept 节叙述里，
  无专属结构位。
- 研究文档 §6 材料学：判别教学的材料语法 = 近邻正负例（只破一个条
  件）、双向独有的对比例组、性质/特征表述转换——这些是**可操作的写
  作语法**，不是 vibes。
- 分节契约是 ADR-0002 冻结形态，加节 kind = 契约面变更（渲染面/审计
  面/存量课兼容），成本高一档。

## Terms（方案草案，施工前过裁决）

- **R-a（v1，指导面）判别练习模板进 practice 节契约**：practice 节的
  生成指导追加「判别模型类内容优先产 classify 判别题 + 对比例组语法」
  ——节 kind 不变（仍 practice），活动面走 pf2 的 classify；正文叙述
  侧追加对比例组写作语法（上游原文锚点）：近邻正负例「只破一个条
  件」、对比例组按集合关系组织（包含时用共有+B独有对象）、负例「揭
  示边界，而非只给明显无关对象」、验证题「只增加可控差异，避免把大
  量新先修知识引入验证，使失败无法定位」（textbook-teaching 验证题类
  型清单：新对象分类/对照情境/条件变化/结果预测/推导补步/实际操
  作）。
- **R-b（v2，契约面，待独立裁决）新节 kind「判别」**：把判别练习升格
  为独立节 kind（判别模型呈现 + classify 活动固定配比）——ADR-0002
  契约面变更 + 渲染面（节标题/进度/审计）+ 存量课兼容面。v1 跑一段后
  若判别节形态成立再升级，**本票不施工 v2**。
- **R-c（词汇纪律）**：UI 面不透传书内术语（「判别模型」不上用户
  面——用户面用「分类判断/类别归属」类日常词；GLOSSARY 采纳需走三面
  词汇纪律，学习观文档 §8 词汇提示同款）。
- **R-d 不做**：节 kind 五种之外的扩充（v2 未裁决前）；教练/评审提示
  词联动（不在本票）。
