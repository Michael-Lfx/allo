# t5: 边界裁决：学习图课程是否接知识库

**Question:** 学习图课程（`course_kind=learning_graph`）当前**完全不读知识库**：建课只收
目标 + 程度/基础声明（`models.rs:91` 明确拒绝 kb_id），生长材料来自结构快照与教练上下文。
t2/t3 打通"目标感知采样 + 实时检索"后，图课程是否接入知识库作为结构生成与教练批的材料？

裁决要点：

1. **结构生成 grounding**：结构与地形生成调用是否把采样/检索材料作为输入？（注意铁律
   "结构对生长不供内容"——结构是参考地图；引入库材料会把结构从"纯 LLM 结构"变成
   "库投影结构"，语义上是新形态。）
2. **教练批 grounding**：教练生长的材料面是否允许按目标检索的库片段？边界：课程边界
   铁律（结构课程内隔离）不受影响，但"库 → 教练"是新增供给通道。
3. **课时内容**：图节点课时目前用 `proficiency_statement` 等结构读侧项目 grounding；
   是否改走 t3 的读库面（有库可读时）。
4. **若选做**：连贯预算条款（t2 的不倒退纪律）必须内置；快照/引用归属（t4）复用；
   与"描述流"的关系（图课程是否也需目标文本之外的库选择输入）。

**建议取向（待 grilling 确认）**：本票**不阻塞** t1–t4；若裁决"接"，作为独立实施波
（t6+）另起，避免与本图混合。

**Status:** open（可与 t1–t4 并行裁决）。
