## Question

本课 s4 单选题的**正确选项**判定轴 =「两套写法各自的回收路径与持有者」，
而节点 scope 逐字声明「不教回收细节，留待后续」。追根到正文面：s3 三
处提「回收」（mermaid Note ×2「归回收机制处理」、观察点 3「要交给回
收机制的问题」、收尾「此处不展开那套机制，下一节点起再谈」）——二次
裁决（2026-11-19）认定这些提及本身就不合理：

- 正文对**其它节点**的内容做担保（「下一节点起再谈」），而后续节点由
  教练后续独立生成、正文写作时其范围根本不存在——承诺不可验证；正文
  最多预告**同节点内**的下一节。
- 「回收机制」是名单外未立名概念（概念注册表零命中），正文拿它**承载
  功能意义**（归谁处理）——违反既有构件词边界条款「名单外领域名词不
  作讲解构件」。
- 零收益正账：孤儿事实在已教框架内已闭环（「值仍然在堆区，只是再也用
  不到」），提及代价 = 学习者悬空名词 + 出题链「正文教过」假依据（本
  次超纲题的直接弹药），收益 = 0。

正文面尽力了的初判不成立：正文面自己就是超纲弹药的生产者。

- **后续节点零内容**（learning_lessons：堆分配/垃圾回收/引用计数

## Terms（方案草案，施工前过裁决）

- **R-a 契约条款（两线同步，题面+正文双面）**：
  - 题面半：scope 声明点名的概念**不得成为任何题的考点轴**——不得出
    现在题干判定要求、选项正确性判定维度、判底解析的判定依据里；正文
    边界句可以提及名字说明边界，但题目不得测试它（「正文提及 ≠ 可考」）。
  - 正文半（新增，二次裁决落地）：
    1. **禁跨节点承诺**——正文不得预告其它节点教什么/何时教（「下一节
       点起再谈/后面会讲 X」类）；边界说明只许「本节点不展开 X」形式；
       同节点内下一节预告合法（manifest 同次生成可控）。
    2. **边界说明不立名**——未立名概念名词不得承载功能意义（「归回收
       机制处理」违规形态）；已教框架内能闭环的就闭环（「再也用不到」
       已完整），不引入悬空名词。
- **R-b 机械闸（主修）**：`excluded_terms` 扩扫 activities——扫描面
  prompt + options 全部选项；explanation 入不入扫面=裁决点（倾向不入
  或降 warning）。命中 → 新 finding kind `activity_scope_boundary_hit`
  （**danger 级**阻断发布 + 修复指引「换用本节点已教判据重写」）；正
  文版 `scope_boundary_hit` 的未豁免命中是否同步升 danger=裁决点（倾
  向升：功能性提及正是判死形态；否定性提及豁免保留，合法边界句不受伤）。
  **匹配粒度（必改）**：整词子串拦不住同根变体——但词干匹配须有适用
  界：**头名词域整体未立名**（注册表/已知概念名单零命中，如「回收」）
  才词干匹配；头名词已立名/已教（如「引用」合法使用、只排除「语法」
  形态）退回整词匹配，防「引用语法→引用」误伤。以本例为验收底线：
  「回收细节」须命中题面「回收路径」与正文「回收机制」，同时不得命中
  正文「返回指向该对象的引用」。
  **改写面裁决点**：正文闸生成期只在草稿审计跑；改写/手动编辑落库
  （persist_rewritten_section）不重跑——倾向：persist 后对被改节重跑
  一次 scope 词面扫描（零 LLM、复用同一词表，命中→warning+tracing 留
  痕；不阻断用户操作——手动编辑是用户主权面，AI 重写可走既有 degraded
  通道提示）。施工时定案。
- **R-c 豁免词表题面收窄**：否定性提及豁免在**题面**不适用或白名单收
  窄——题面无「写边界」的合法场景。正文面豁免照旧（边界句合法）。
- **R-d 局限如实留痕**：换说法的语义越界不设机制面（z03 同律），归真
  机走查；手动表单加题/手动编辑正文无 LLM 无从拦，sq5 删除+人审兜底。
