# ADR-0008: 可视化承诺的逃逸口治理

Status: Accepted

Date: 2026-09-16

## Context

同事反馈「以《通过ICT/SMC 交易从入门到实战》为输入完整生成课程后，一个图表
都没有」。排查结论分两层：

- **同事的环境跑的是 main（v1.3.6）的旧单篇管线**：课时提示词只有软性的
  「内容真正需要图示时才画」，没有 visual 声明、没有 mermaid 指引、没有质检
  门。模型本就回避画图，零图表是旧代码的预期行为。本分支的分节管线
  （ADR-0002）+ 承诺兑现门（`9cbfd0711`/`b5d51b3a7`）已修复这一层，等合入即可。
- **但分支上的承诺兑现制存在三个「合法逃逸口」**，模型（尤其厌恶画图的模型）
  可以在不违反任何门禁的情况下产出整课零图表的内容：
  1. `visual=无` 零成本逃逸——「无」是合法枚举值，审计对「无」的占比毫无监督；
  2. `ls_set_document` 单篇旧契约仍暴露在**生成**循环——一次写完整篇文档 +
     补题即可过门发布，单篇契约没有任何可视化要求；
  3. 降级兜底静默——fallback/单节重写里质检不过的节以 `visual=无` 纯文字
     保底落库，只有一条 best-effort WS 瞬时事件，课程里事后无法看出。

## Decision

**软监督而非硬配额（逃逸口 1）**：审计对「全部概念/例题节都声明 visual=无」
的清单出 `visual_none_heavy` **warning**（非阻断），发布帧与 completed 事件
携带 visual 声明分布。不做「无 占比硬上限」——纯理论课确实可能无可视化，
硬配额会逼模型画装饰性的假图，比没有图更糟。

**单篇契约退出生成面（逃逸口 2）**：`ls_set_document` 从生成循环的工具面移除，
只保留在修复循环（旧单篇草稿的续跑修复仍需要它）。生成必须走分节——可视化
承诺只在分节契约上有定义。`document_missing` 审计文案与模块注释同步改写。

**降级持久可见（逃逸口 3）**：`learning_lesson_sections` 新增 `degraded` 列
（迁移 053）。AI 重写降级时置位；重写成功兑现承诺或手动编辑（视为人工接管）
后清除。前端在节上显示持久 warning 与 AI 重写入口，替代原先的瞬时事件。
`visual` 列保留原声明不变——它仍是单节重写的承诺事实源（迁移 051）。

**不合入前不热修 main**：最小提示词热修仍是软约束，改变不了模型行为本质，
还会造成两套提示词语义分叉；迁移 050-053 依赖链太深，cherry-pick 不可行。

## Consequences

- 整课零可视化从「静默通过」变为「审计 warning 点名 + 发布帧可观测 + 降级节
  带 UI 标记」：问题可发现、可解释、可定位。
- 生成循环的工具面收窄是对所有生成会话的行为变更：新草稿不可能再产出单篇
  文档形状；单篇形状只来自历史草稿的续跑修复。
- 「无」仍是合法声明——warning 不拦发布，厌恶画图的模型仍可能产出零图表课程，
  但每次都会在审计报告里被点名，且降级产物有持久痕迹。
