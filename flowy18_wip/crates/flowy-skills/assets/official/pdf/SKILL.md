# PDF

Help the user inspect or modify PDF files in the current workspace.

1. Locate the requested PDF and confirm its path.
2. Preserve the original file unless the user explicitly asks to modify it.
3. Extract or update only the requested pages and fields.
4. Report any pages, forms, signatures, or embedded resources that could not be processed.
