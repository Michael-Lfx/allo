# p02: 内容臂前置上下文修复——同一事实只说一遍

**What to build:** 内容生成 user prompt 的前置段修复四处真机实证的上下文
缺陷：①前置事实双传收敛（前置路径内嵌节点要点摘要 vs 已建立先例块，
同一事实两种形状两处出现）；②前置路径/前置契约双头合并；③程度声明
空值行省略（含 L33「忠于程度声明」的空值指向）；④旧叫法行措辞方向化。

## 现状（2026-11-05 实码核实，基线 a672c7eb4；证据 = run-1793829277050
content user prompt 全文，提取件 absorb8-forensics/content-turn1-user.txt）

- **双传**：`service/lesson.rs` `graph_node_topology`（~`:1264-1340`）的
  prerequisite_path 条目自带「节点出生即带的标题+purpose + 已生成节的
  标题要点」（拓扑 doc 注释明载），渲染于 `lesson_content_loop.rs`
  `lesson_user_text` 前置路径块（真机 L11-19：前置节点行 + 本节练什么 +
  概念/例题节清单）；同函数构造的 `precedents`（n3/#180）经
  `lesson_draft.rs` `render_precedent_block`（~`:99`）再渲染
  「概念「对数收益率」← 节点「收益率与对数收益率」（概念：…；例题：…）」
  （真机 L22-23）——**节点与节清单重复两遍**。
- **双头**：前置路径块头（「…不要重复讲授」）后紧跟「前置契约：以下概念
  已由其他节点教到标注档位，不要重新讲授，只在必要时按该档位复述或引用。」
  + 档位标尺括注（真机 L11-13）——同一规则说两遍、两个头。
- **空值行**：`lesson_content_loop.rs` 图臂头两行 `学习目标：{}\n程度声明：{}`
  无条件渲染（~`:770-775`）；结构快照无程度声明时渲出「程度声明：\n」空行
  （真机 L4），而 L33 还有「内容忠于学习目标、程度声明与前置/后续节点段落」
  指向空值。
- **旧叫法措辞**：`lesson_draft.rs` `render_text`（~`:338-341`）
  「- 旧叫法（学习者可能在别处见过；正文不使用，必要时括注帮助辨认）：
  {canonical} 又叫 {aliases}」——`aliases` 数据源是**活跃**别名
  （~`:292` doc：正名 → 活跃别名，投影词表 R3）；语义自洽（本课单名纪律）
  但「X 又叫 Y + 正文不使用」的方向读法易误伤（真机首现概念恰为 X）。

## 实施要点

### A. 前置双传收敛

- [ ] 裁定唯一载体：**前置路径条目保留节点要点摘要**（衔接语义更完整、
  是 e1 期判据面），**已建立先例块瘦身为概念←节点映射**（去掉括注里的
  节清单，只留「概念「对数收益率」← 节点「收益率与对数收益率」」）——
  概念归属 + 用名纪律所需的最小事实，细节由前置路径承载。
- [ ] `render_precedent_block` 文档注释补「前置路径已带节要点，本块只做
  概念归属映射」；render 文本相应改。
- [ ] `LessonPrecedent` 结构与 `graph_node_topology` 构造点核对：若 sections
  清单仅服务 render，构造点瘦身；若另有消费（观测/审计），保留数据只裁
  渲染——**数据面不动、渲染面收敛**优先。

### B. 双头合并

- [ ] 前置路径块头合并为单一头（吸收「前置契约」句）：「前置路径（学习者
  到达本节点前应已掌握，按学习顺序；概念已由其他节点教到标注档位——不要
  重新讲授，只在必要时按该档位复述或引用。条目下的要点是各前置实际教过的
  内容——不要重复讲授）：」+ 档位标尺括注保留一次。`lesson_content_loop.rs`
  渲染处与单测同步（真机 L11-12 两头并一）。

### C. 空值行省略

- [ ] 图臂头两行渲染：`degree_statement` 为空时省略「程度声明：」行
  （`known_names` 行缺席省略同款先例）；`lesson_user_text` 头部抽纯函数
  或就地条件化 + 三态单测（有/无/全空）。
- [ ] L33 尾注措辞加空值分支：「内容忠于学习目标、（程度声明在场时）
  程度声明、前置/后续节点段落」——或改为动态拼装（省略空值项）。
- [ ] smoke content 臂判据核对：若断言「程度声明」字样在场需同步（旧档
  语义 = 缺席省略，不是值变化）。

### D. 旧叫法措辞方向化

- [ ] `render_text` 旧叫法行改为方向显式：「- 本课现用名（别处可能见过的
  旧叫法正文不使用，必要时括注一次帮助辨认）：{canonical}（旧称：{aliases}
  ）」——首现概念与旧叫法并读不再可能误读；`lesson_content_loop.rs`
  断言同步（`旧叫法` 字样断言在 ~`:1613`）。
- [ ] 数据面零改动（aliases 仍为活跃别名池投影）。

## Non-goals

- 不给前置/后续/禁止清单加下游 scope（absorb-8 map 雾区，触发条件未满足）。
- 不动前置路径条目的要点摘要内容本体（e1 判据面）。
- 不动概念面 faces 数据构造（projection 不动，只动 render）。
