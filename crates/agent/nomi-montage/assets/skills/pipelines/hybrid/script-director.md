# Stage Director: script (hybrid)

Produce `script` with the reflective, editorial pacing implied by
`hybrid_motion_still`. See `skills/creative/storytelling.md` for general
craft.

## Hybrid-specific guidance

- Write some scenes that are explicitly built around a single strong image
  or moment (these are candidates for held-still shots) and others that need
  to show change or action over time (these should become motion shots) —
  the script itself should make each scene's eventual `is_motion` choice
  feel obvious to whoever writes `scene_plan` next.
- Avoid writing every scene at the same narrative "speed" — part of what
  makes hybrid pacing work is that some scenes linger and others move.
