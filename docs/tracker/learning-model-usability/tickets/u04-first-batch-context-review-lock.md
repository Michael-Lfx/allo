# u04：消除「教练无稳定过门路径」的规则循环

## 问题与证据（审计①#3#4，证实）
- 空已教账 + 判据①要求提名定义里每个领域词都有出处；「手冲咖啡」课的入门定义不可能不用「手冲/冲煮/咖啡粉」。run-1793951137445：第 1 轮评审让改写，教练照改；第 2 轮评审把改写结果打回，新 advice 又重新引入第 1 轮点名的「冲煮」——反乒乓纪律只约束教练（mod.rs ~:815），评审不受约束。最终靠挂号表违约降级落库，语义门实际缺席。
- intent/scope：5 节点中 4 个把同一条「不碰 X / 后续批次」在两字段各写一遍（run-1793951137445），每轮重发多付 token，并进四源点名扫描加重评审负担（fragments 138）。

## 实施要点（均在开关 on 臂）
- [ ] **课程语境词**：由课程标题 + 学习目标机械切出的词条（复用 generation 的确定性切片器），渲染为「【课程语境词】…——可作定义的背景用语，不单独要求挂号；作为本节点教学对象（teaches）时照常挂号」，同时进入教练首批块与评审 user；并加入点名清单的已知面（这些词不再作为碎片下发）。
- [ ] **评审翻案锁**：有状态复审臂（review_history 非空）时，评审 user 追加「【前轮评审意见与教练修订】…」及条款「按前轮意见做出的修改，本身不得再判为问题；修改若引入与前轮无关的新硬伤照常报告」。
- [ ] **边界去重**：教练声明面条款补「『不教 X / 留待后续』这类边界只写在 scope；intent 只写这个点为何存在、承担什么角色」。
- [ ] 开关 `NOMI_LEARNING_ANTI_LOOP`（缺省 on 待 A/B），off 臂逐字节回归测试。

## 三件套
- **主指标**：首批过门所需轮次与是否经降级落库；评审跨轮翻案（新 advice 重新引入前轮禁词）次数；intent/scope 边界重复率；碎片清单行数。基线：run-1793951137445 = 3 轮 + 降级落库、翻案 1 次、重复 4/5、碎片 138。
- **护栏**：概念登记不出现新的漏挂号（语境词若被某节点 teaches 仍须挂号）；评审 reject 能力不被削弱（翻案锁只锁「按前轮意见的修改本身」）。
- **推翻条件**：on 臂落库批次出现明显缺挂号（findings 报缺失增多）或评审在第二轮完全放水（problems 归零但 findings 自认缺口）→ 默认 off。
