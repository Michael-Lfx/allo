## Question

挂号表（`term_provenance`）与碎片裁决（`fragments`）要求评审逐词落行、
逐条裁决。它们是**弱模型的辅助轮**：ADR-0033 的证据（程序形态 5 跑 4 拒
vs 原则形态全放）是 2026-10 的 flash 级模型实测。模型换代后辅助轮是否还
必要，**不能假设，只能测量**。若已不必要，评审的输出义务可卸；若仍必要，
问题对本代模型关闭，下一代重测。

## 已核验事实（2026-11-24）

- **两个表义务各有现成开关**（`learning_graph/mod.rs`）：`NOMI_LEARNING_
  REVIEW_PROVENANCE=off` 关挂号表义务（提示词回到 k07 原型）、
  `NOMI_LEARNING_REVIEW_FRAGMENTS=off` 关碎片义务；未设 = 开。均为进程级
  env——两臂须分两次进程跑，天然隔离。
- **回放臂已修好两个缺陷**（1face985a）：①服务端缓存——相同输入的第 2/3
  次调用直接返回上次答案，「N 跑」曾实为 1 跑；现每次采样在 system 末尾
  加采样编号。②计数游标跨夹具归零——非首夹具读数混入前序夹具。
- **回放臂的已知面偏薄**：只填 `taught_summary`（已教概念账）；真实评审
  输入另有花名册（~2.9k 字符）与登记表切片（~0.4k）。对本实验的偏差方向
  是**保守的**（材料更薄 → 不带表臂更难，不是更容易）。
- **样本**：今天真机生长留下一对**真实规模**的批（同一门课 31 节点、同
  一已知面）——
  - 批 A（应打回）：教练初稿 5 节点，评审打回——「迭代器协议」定义依赖
    「容器」「接口」「元素」「消费方」，均不在已教账；
  - 批 B（应放行）：点修后 4 节点，评审放行并已落库。
  原文与已知面存于仓库外 `allo-sb-notes/t1-batch-A-rejected.txt`、
  `t1-batch-B-accepted.txt`、`t1-known-surface.txt`。
- **卸表的收益上限已被真机数据修正**：评审输入 22,550 字符里点名清单
  2,821（12.5%）、待审批次 + 提名候选集合计 6,548（29%）——表义务全卸，
  输入约降两成。**思考量能降多少未知**——这才是本实验要量的。

## R（设计）

- **R-a 两臂**：on = 现行为（两开关未设）；off = 两开关均设 `off`。同
  一冻结二进制、同一模型、同一夹具。两臂分两次进程。
- **R-b 样本三夹具**：真实批 A（打回锚）、真实批 B（放行锚）、人造三角形
  折叠批（打回锚，对照——它是 ADR-0033 当年的证据形态）。已知面用真实
  的已教概念账原文。
- **R-c 每臂每夹具 5 次独立采样**（采样编号破缓存；以「思考 token 各次
  不同」为独立性核验）。
- **R-d 读数双轴**：①**方向命中**（打回锚 problems 非空 / 放行锚 pass 且
  非降级）；②**评审思考 token 与耗时**（on/off 对照）。
- **R-e 降级如实计**：降级（评审缺席）不算方向命中，单独报。超时调用
  不落档案，`llm_calls` 对超时是盲的——降级的解释以日志为准。

## 判据

- **off 臂泄漏率** = 打回锚在 off 臂被判放行的比例（两个打回锚合计 10 次
  采样）。
  - 泄漏 ≤ 1/10 且放行锚 ≥ 4/5 → 当代模型在原则形态下可靠，表义务可议卸
    （另票裁决；卸多少由 R-d ② 的思考量读数定）。
  - 泄漏 ≥ 3/10 → 表义务对本代模型仍必要，本方向关闭；下一代模型重测。
  - 介于其间 → 样本不足，如实记录，不加跑凑结论（5 次/臂已是非平凡的
    调用量），留待自然数据。
- **思考量读数**只作决策输入，不设阈值：若 off 臂方向达标但思考 token
  降幅 < 30%，卸表的收益不足以支付它带来的风险，倾向不卸。

## Acceptance

- 三夹具在回放臂内可装配（批 JSON 可解析、方向锚与已知面在场）——单测。
- 两臂各 15 次采样跑完（共 30 次）；每臂的思考 token 逐次不同（独立性）。
- 读数表进 Resolution：夹具 × 臂 × 5 次 = 方向、耗时、思考 token、降级。
- 结论按「判据」落字，含对回放臂已知面偏薄的说明。

## 回退条件

- 本实验零生产改动（只加夹具与读数），无生产回退面。
- 若采样编号被证明扰动判定（同一夹具同一臂 5 次结论分散且与 on/off 无
  关）→ 破缓存方法需换，实验作废重设计。
