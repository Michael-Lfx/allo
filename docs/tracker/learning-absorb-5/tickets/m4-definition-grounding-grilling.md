**Question:** learnhub 定义接地线的第二阶（机械判定「名词该不该先教」）要不要
进 allo、进多少？三层候选：只读定义审计（自指/互指/缺口碎片扫描 + 只读报告）、
词表资产（基础词表 + 课程词表两层）、提案者代理（缺口名词自动提名提案）。
本票盘问后定案切实施票。

## 背景与研究结论（learnhub docs/research/definition-grounding-survey.md）

- **六条路线**（§0）：A 定义词表（2000-3000 封闭集）、B 属加种差/定义闭包
  （ISO 704，终局）、C 词表覆盖软指标、D 词项度打分产候选、E NSM 65 元语
  （不实用）、F 知识空间理论（需学习者数据）。推荐 = B 骨架 + A 血肉 +
  D 候选 + C 软指标，约束生成而非输入分类。
- **Spike 0**：44 概念定义引用图零环（B 可行）、19 孤岛 = 有界补属清单；
  **高频词选词必错**（高频是元语言「运算/符号」，缺陷词是长尾「线段/内角」）；
  属词不能免费——需要小固定根类别集（6-12 个：数/量/图形/运算/关系/性质…）。
- **概念表结构评估**（§12）：**不给 ConceptRecord 加属字段**（违反 ADR-0010
  无关系字段纪律；`superseded_by` 是唯一被接受的同一性关系先例）；17 词根
  资产可落地 42/44 存量概念；改的是**定义契约 + 根资产 + 只读投影**不是表；
  自指/互指检查可立即机械门。
- **Spike 1**：门口判据派生词表铺砖——V3（+50 元词）25/44 精确命中三角形
  缺口；发现**单字吞复合**缺陷（内角被 内+角 吃掉）→ 单字只能作边界 token。
- **Spike 2**：独立裁决代理（无装箱上下文）69/69 覆盖零弃权（过度自信）——
  **只能作提案者，绝不自动落**，93.5% 两跑一致。
- **Spike 3/4**：哲学入门跨域夹具证明机械层域无关（预埋自指「怀疑论」与互指
  实体↔属性都抓到）；n-gram 候选 + 代理过滤全管线跑通。
- **落地形态（#173，e432987）**：①评审融合机械点名（validator 派生 naming
  list → ReviewInput.naming_list + fragment_enforce 开关：true=未处理碎片
  阻断 / false=只报 findings；评审逐碎片给 noise|名词|note 裁决，机器核全覆盖）
  ②词表资产 v0（`domain/concepts/lexicon.rs`：三层已知 = 登记表活跃名 ∪ 仓库
  base.yaml 148 词 ∪ 课程 lexicon-course.yaml{door,words,ignore}；铁律 = 课程
  只许豁免与加课程词，**不许 fork 仓库基础词表**）③只读审计命令
  （audit_definitions → 全登记表 × 三层词表 → 缺口碎片/自指/互指标记，
  概念页展示，零写入）。
- **#171**（518c902/3515b49）：`definition_audit.rs`——CJK 1-4 gram 枚举候选
  （宁滥勿缺，无分词无单字分类）、最长优先已知词掩码后的未覆盖极大 CJK 段
  （≤40/定义）、self_references（ISO 704）、mutual_cycles（A↔B）——纯字符串/
  图检查，跨域零失败。

## 盘问点（裁决产出物）

1. **范围切几层**：(a) 只读审计命令 + 自指/互指机械检查（小，纯函数移植 +
   smoke/read-only 面）；(b) + 词表资产 v0（base 词表内容域中立化是重点——
   learnhub 148 词是数学向？ allo 的基础词表选什么语料）；(c) + 提案者代理
   （依赖 completer 工具缝吗？——提案者是一次独立补全调用，**不需要**工具轮，
   learnhub lexicon-adjudicate bin 形态即可，但要定「提案落哪」（findings?
   新表? 人读报告?）。
2. **评审融合点名**（#173 第①件）：allo 评审是否接 naming_list +
   fragment_enforce？与 m3 的 provenance 表关系（碎片裁决行并入 provenance
   还是独立清单）——盘问定形状。
3. **根类别集**：要不要（评估 §12 的 6-12 根词是 B 路线骨架；allo 概念域
   跨课程通用，根集域中立化可行）。
4. **表面**：只读审计走哪——nomicore learning-smoke 新档（离线）vs HTTP 读
   端点 + 概念 Tab 展示（在线）vs 两者。
5. **单字吞复合**缺陷的移植纪律（单字只作边界 token）直接吸收，无需盘问。
