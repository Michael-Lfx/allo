# Wave 4：宿主打包与生产级可靠性加固 (Cross-Platform Packaging & Hardening)

> **对齐**：基线 Phase 4
> **前置**：Gate 3 通过（安全闭环达标）
> **出口门禁（Gate 4）**：Linux / Windows / macOS 三端安装并开机自启验证通过；72 小时挂机压测误唤醒率 ≤ 1 次 / 24 小时且无内存泄漏；USB 麦克风拔出后插回 2 秒内自动恢复唤醒监听

---

## 1. 目标与范围

把前三个波次的成果封装为可交付产品：三端宿主服务常驻、无屏 OOBE 配对全流程（含入网前置）、热插拔自愈看门狗、长周期压测。本波结束时方案达到生产交付状态。

## 6. 本波禁止事项（追加）

- 禁止为赶进度实现 AP 配网模式（基线明确 Post-MVP，本波只做 Ethernet + U 盘双前置）。
- 禁止把 72h 压测缩水为“跑了 8 小时没问题”（Gate 4 口径不可协商；CI 采样只是镜像不替代真机项）。
- 禁止配对 Web 服务随配对码过期提前关闭（服务寿命锚定 `ModelManager` 终态，ui-motion §4 契约）。
