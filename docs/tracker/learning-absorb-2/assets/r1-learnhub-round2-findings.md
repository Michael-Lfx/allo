## 1. #85 装箱/生长教义精修（17 提交）

### 1.1 三条 GLOSSARY 教义条目（用户定调）

**a35eb1a 道与术**：教学质量标尺对。道 = 对本质的理解（懂根本是什么、为什么成立、居于
何处、边界在哪）；术 = 可执行（按方法完成操作不问为什么）。可重建/可迁移/能诊断错误是道
的表现形式（识别面/证据面），不是道的定义；对着判据训练产不出道，只产出新的术。**标尺
跨三层共用**：节点线分配道位（认识/推导/说理型学习行为成点，一条线只有操作台阶时补
「为什么成立」位）；内容线给成色（derivation before drill）；题库/教练线检验（迁移/说理/
纠错题判真懂）。锚定 Skemp 关系性/工具性理解。（#85 六批长样本实证：30 节点 80% 操作动词、
零「为什么成立」位、悬空技巧与定义内嵌未教概念全绿放行。）

**d088c1c 概念不可学完**：同一概念从不同角度反复学习合法且是常态；概念无「真正学完」终态。
机制面本就开放：同一概念可被多个节点反复挂接重教——**不同档位（螺旋加深）与同档位不同
角度（多样变式）皆可**，无唯一性门。重访型学习行为与首教同为课程内容一等公民。对齐面：
掌握度本就是非终态聚合；课程完成是**目标有界**（门口判据达成）不是概念穷尽。（后续
89d15ff 追加同档位变式条文。）

**f1edaf7 概念投影**：一次学习行为所能证明的只是概念在某角度、某深度上的一个投影；完成
节点 = 为该节点 teaches 声明的投影积累证据，不等于学会概念本身——概念整体是投影的无界
并集。挂接档位 = 投影深度的声明面；结构面覆盖判定档位不计（ADR-0011 就不就绪；深度是否
够用由语义评审与内容层把守）。**别名是投影的自然命名面**（微商/变化率之于导数）；
v2.5 闭环：铸名门复用通道把名池新名落为被复用概念的活跃别名；装箱输入暴露活跃别名池，
模型负「选贴合角度的已有名 / 经提名复用引入新投影名」之责；内容面本点开讲用名随挂接
`ref` 锁定（引用名开讲、正名仅首现括注）。

### 1.2 教义进提示词（3edbe5a、89d15ff）

**装箱四问**（node-growth.md 任务段 ④）：教过 ≠ 学完——已教概念可从新角度重访（换语境/
更彻底抽象/解构/给证明/推广/关联支撑领域）；同一概念被多个学习点反复教完全正常（不同
深度，或同深度不同角度/变式），只有**同一角度同一深度**的重复没有价值。

档位行升格「投影深度声明」：teaches 写本次到达的理解深度；assumes 只挂真正前置并按本次
**实际依赖的深度**写档位。

**评审面有意不动**的设计自述：评审输入只有已教概念名清单、看不到既有节点内容，结构上
无法判断重访是否带来新角度——重访成色是装箱层判断，线级平衡归未来全轨迹层。「**判据
只放在能看到信息的层**」是本组最重要的范例之一。

### 1.3 别名投影命名面：契约 v2.5 + 引擎落地（b0e4b6d，facade +303）

**契约 §4.4 v2.5「复用即别名入池」**：各复用通道（归一化改挂/裁决复用/批内先铸改挂）在
提名名为全库名池新名时，将其落为被复用概念的活跃别名（colloquial，attestation = 提名
source）；名已在池则跳过，名字全库唯一不变。

**facade 实现思路**：`pass_naming_gate` 复用路径维护 `minted_names` 与既有 `name_pool`；
逐条改挂提名用 `aliased: HashSet` 去重（防同批重复落池）；名不在全库名池则读概念记录、
推入 `AliasRecord{name, lang(ASCII 判), kind:Colloquial, attestation:Some(nc.source),
display_priority:5, status:Active}`、写回。**复用判定仍全在定义侧——别名入池是登记后果
不是新判定**（机械读法零变化）。别名池可见：`graph_summary` 末尾附
`概念别名池(= 前正名,后为别名;任一名引用均解析到同一概念):导数=变化率/微商; …`。

**提示词条款**：引用已教概念时，从概念别名池里选**最贴合本学习点角度**的名字；若这个角度
值得命名而没有别名承载，可在 new_concepts 用该名字提名同一概念——铸名门会复用既有概念
并把名字保留为它的别名。测试 ×5，500 绿。

### 1.5 引擎机制：容量守卫 + 点修原地重试（116e805，facade +106）

真机实证（smoke85-spiral 批 2 三枪烧尽）：正确拆步把 5 条拆成 6 条 → 撞批容量整批打回 →
重装再拆 = **死锁**；点修轮在多问题清单压力下整批重掷（5 节点全换），守卫打回后回炉丢
评审上下文。

- **`assert_round_capacity`**：自检/点修两轮出口执法 `revised.nodes.len() > MAX(5)` 即
  `AttemptFail{guard:false, reason:"拆步/点修后批容量超限…按拆分后的形态重新装箱，每批
  至多 5 条——超出容量的条目留待后续批次，不要放弃已正确的拆分"}`。**把「拆得对但超容」
  从「整批违规」改判为「定向重装指令」**。
- **点修越权原地理地重试恰一次**：点修失败且 `guard==true`（未点名被改的机械比对打回）时
  带守卫原因再点修一次；第二次再越权才上抛。取舍：保留评审上下文 vs 回炉丢上下文。
- 提示词配对：selfcheck 加批容量红线（装不下时把点名清单靠后条目保持原样不拆，宁可少拆
  不可超限）；polish 加 `{{retry_feedback}}` 输入 + 「点修不是重装」负例（正解 = 复制上位
  全文只动点名节点；若修法需要动未点名节点才能成立，放弃那条修法）。

## 4. #79 铸名门名字面机械兜底（8dfea51，契约 v2.6）

**背景**：slug 面拒铸（v2.4）同族残余——裁决器裁「新铸」而 canonical 逐字撞既有概念
活跃别名时机械面无兜底；v2.5 复用即别名入池使名池随教学生长、撞面变宽，暴露面同步变大。

**实现**：`refuse_mint_collision(used_slugs, name_pool, nc)`——slug 面照旧 + 新增
`name_pool.iter().any(|n| n == &nc.name)`（canonical 逐字撞活跃别名 = 拒铸整批重试）。
**边界自述**：逐字相等是机械事实非「近邻」，不越 stage 2 裁决的界。测试 ×2（恒新铸探针
拒铸零半成品 / 互异新名零误拦）。

**契约 v2.6**：新铸撞名 = 拒铸整批重试（v2.4 改定 slug 面，v2.6 扩名字面）——结构上不可
新铸，整批重试换名；**可重试失败，不静默改挂（语义裁决权不受侵蚀）；不落坏档（登记表
唯一性不交模型守）**。
