## 已核验事实（2026-11-18 对码 + 对库取证）

- **取证（dev 库，activity 01a1e70e）**：matches[0]=「栈区：**随**本次调
  用建立、调用结束即失效」vs matches[2]=「栈区：**本次调用内建立**、调
  用结束即失效」——右列两个候选语义等价、字面差两字。attempt 留档：
  用户三行作答 = [「本次调用内建立」变体, 堆区✓, 「本次调用内建立」变
  体]，score=0/passed=0。判题解释自己写着「参数与引用的名字都在栈
  区」——**用户的答案在教学上是对的，错的是这道题**。
- **判分**（progress.rs evaluate Matching 臂）：逐位置精确串比对
  `got.as_str() == want.as_str()`，二元 0/1、无逐项结果。
- **生成契约缺口**（lesson_content_loop.rs:227/:1612）：「matching 的
  options 是左列、answer 是一一对应右列数组」——**右列候选无任何可区
  分性约束**；审计门无候选查重。
- 布局缺陷另票（learning-matching-input-layout l1）。

吸收挂起为未来独立波。
