# ADR-0012: 结构转活文档——挂载事实 + 七型修补 + findings 留痕

Status: Accepted

Date: 2026-10-15

## Context

学习图课程的知识结构（`learning_courses.structure_json` 快照，gd.* 契约，
ADR-0010）在生成时点定格：读侧投影（`GET graph/structure`）只能呈现
「生成时点的参考地图」。课程随着生长批次与学习者实际使用不断演化，快照与
现实的偏差没有任何机制显影——结构是死的。

learnhub #52 战役（ADR-0017 七裁决）把结构升级为「可增量维护的活文档」：
挂载事实（节点 ↔ 结构块的导航关系）+ 七型修补 ops + 显式维护回合 + findings
留痕，全部靠三重护栏（全量 validator 门 + 观测审计 + 出处）而非受理门机器。
三轮 r1 研究将可移植性定为 A 级强建议；三轮 g1 裁决（默认裁决，票面标注可
复议）：**全量进，两步实施**——先挂载（j08）后修补（j09），findings 从第一
轮生长就开始留痕。

约束：课程边界铁律不变——挂载同样严守「结构 ↔ 概念经节点两跳、挂载无判定
身份」（结构块不是概念，挂载不进调度、不进门禁）；gd.* 门复用不造第二套；
RoundRetry 与二轮 t1 早停同源。

## Decision

**七项裁决（learnhub ADR-0017 的 allo 适配）：**

1. **挂载是导航事实，无判定身份**：节点挂到结构块（或声明结构外）只为帮助
   学习者定位；不排顺序、不定深度、不承载概念关系（概念事实只住节点挂接
   表）。挂载无判定身份 ⇒ 误编只伤导航 ⇒ 失效降级（悬挂 slug 逐条降级为
   NotEvaluated，不使整体 Broken）本即合法语义。
2. **载体 = 单行 JSON + 审计表**：挂载一课一行
   （`learning_structure_mounts`：mounts_json + structure_hash + updated_at），
   与 `structure_json` 单字段快照先例同构；修补审计一回合一行
   （`learning_structure_repairs`：old/new hash + 逐 op 含理由 + 级联注记）
   ——learnhub「文件 + Git 出处」的 DB 等价物。回合内原子覆盖，无中间态。
3. **ops = 意图，引擎管自洽**：模型只输出七型修补意图（加/删/翻边 + 补/
   拆/改名/并块），纯函数引擎依序应用并代管全部引用面级联（改名跟改、拆
   块边退场、并块去重去自环）；应用后 gd.* 全量重过零放宽（st.ops.apply），
   任一违规拒整回合。**no_slug_churn**：rename 不携带 slug（slug 终身不变），
   新 slug 不得复用当前或已退场 slug。
4. **级联口径：不建逐 op 跟迁**——修补回合不动挂载；结构 hash 变（FNV-1a
   64 手写锚）即既有挂载整体显影待重评估（mounts_stale），下一回合全量重
   挂。逐 op 跟迁的复杂度远大于「重挂一遍」的成本，且挂载无判定身份。
5. **findings 是线索不是第二真相**：生长概念评审门扩可选 `findings[]`
   （数据缺陷观察，warn 级不打回）落留痕表；修补回合的输入源 = findings ∪
   挂载观察（结构外/空块/超载块 ≥5）——观察不构成编辑义务。
6. **两个防幻觉/防浪费语义**：ops 空 = 「评估过、本轮无修补动作」的合法结
   论（LLM 已跑、不写盘）；待挂集空 = skipped（零 LLM 零写）。
7. **触发 = 显式命令**（`POST .../graph/structure/mount` 与 `.../repair`），
   单课串行、可取消；不内联生长批、滞后无害。LLM 失败（无凭据/网络）如实
   上报，不与条款违约混报。

** миграций**：079（挂载表 + findings 留痕表）与 080（修补审计表）；契约文
档 §9/§10 新章（st.mount.* 六条款 / st.ops.* 五条款）与 validator/提示词三
互钉。

## Consequences

- 结构获得「变了会显影、可按证据修补」的活文档语义：挂载三态投影
  （Mounted/Outside/NotEvaluated）与 mount_index 成为结构图 Tab 的常驻读
  数；findings 从第一轮生长开始积累为修补线索。
- 修补回合的产出只动 `structure_json` 一个字段（唯一权威），读侧投影全部
  回放派生、零第二真相。
- 不做的事：渲染品重渲（allo 不产人读文档，learnhub 的确定性重渲 = no-op）；
  受理门机器（三重护栏已够）；挂载/修补的自动调度（只走显式命令）。
