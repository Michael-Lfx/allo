## Question

learnhub 已验证的可视化方案（**xyflow 弃用**——边渲染缺陷见其票 #27；dagre 算坐标 + 自绘
SVG 画边 + HTML button 画节点；echarts 仅力导图按需动态 import）移植到 allo（React 19 +
Arco + UnoCSS + 主题/i18n 红线），五图怎么裁剪：

| learnhub 五图 | allo 场景疑点 |
|---|---|
| 思维导图（主干两翼配平） | 与 spines 数据直接对应，疑似必做 |
| 矩阵（主干 × 阶段） | 便宜，疑似必做 |
| 关系图谱（force/layered 双布局 + 枢纽 Top10 + 过滤） | 块图 vs 概念网图，画哪个？ |
| 学习路线（子图 + 传递闭包自动补前导） | 「放弃多终点选择」后参考路线的读侧投影形态 |
| 线路图（地铁） | 可能砍 |

需要原型回答：

1. 首版做哪几张图、各自的节点/边语义（结构块图走 g2 的快照投影；概念网图走
   `learning_lesson_concepts` 投影——两套都要吗）；

3. 「投影非权威」标注收敛到详情层的形态；未收录端点虚线菱形占位要不要；
4. blocks 40–80 规模下的交互（缩放/按主干隐藏/按关系过滤）够不够用。

产出：粗糙可反应的原型（独立 HTML artifact 或隔离组件 stub，**不进生产树**——遵守仓库
零 mock 红线），链接回本票供用户反应后再定实施范围。

约束：g1 裁决影响图内容（终点去留）；本票只做原型不做实施。

## Resolution

**原型取消**（用户 2026-10-12：不要做原型了），改为直接裁决。三问全采推荐，另加一条
用户强调的铁律边界——

1. **首版三图**：思维导图（主干两翼配平总览）+ 关系图谱（dagre LR 分层，**边方向反转：
   assumes=门**）+ 学习路线（选主干子图 + 传递闭包自动补前导，虚线框「前导」角标）；
   矩阵（主干×阶段）便宜、顺带；地铁图砍。技术栈 dagre 算坐标 + 自绘 SVG 连线 +
   HTML button 节点（xyflow 已被 learnhub 验证弃用，仓库记忆同此）；**v1 不引 echarts**
   （力导布局后置，需要时按需动态加载）。
2. **数据源：结构块图**（structure_json 读侧投影：主干/块/三型边，纯函数运行时重算，
   生成后即有全图）；**概念网图形化留后续**——跨课程概念面由概念表 Tab 覆盖。
3. **宿主：工作区新增「结构图」Tab**（内部小 tab 切换三/四图）；顶条罗盘/终点 chips
   清空后由就绪导航与徽章吸收；对齐现有 WS 事件刷新模型（新增 structure_generated
   事件类）。
4. **边界铁律（用户 2026-10-12 强调，最高优先）**：**知识结构仅限课程内部生效、跨课程
   隔离；概念登记表跨课程；两层永不直接关联**。落到可视化：块图不渲染概念节点、不做
   块-概念名字匹配（learnhub 真机首测事故同款）；跨课程概念事实只出现在概念表 Tab。
   已固化进 CONTEXT.md 新词条 Structure，并同步退休 Endpoint/Compass、更新 Coverage
   Gauge/Stall/Growth 词条。

机械采纳（learnhub 已验证形态，不另问）：详情层非权威标注（「由课程内容自动整理，
仅供参考；学习顺序以教练实际安排为准」）；未收录端点虚线菱形占位（`◇` 前缀）；枢纽
Top10 琥珀描边；按主干隐藏、按关系过滤；页脚「投影非权威；层号=依赖深度，不是排期」；
双主题语义令牌 + i18n 双语红线。
