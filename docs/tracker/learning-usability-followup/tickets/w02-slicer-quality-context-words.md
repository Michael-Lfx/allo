# w02: 语境词与候选词不再产出无意义碎片

## 问题与证据（第二轮审计·教练路 F4/F6 + 评审路 N，两路独立同指，证实）
- 课程语境词 = 标题+目标过 `term_slices` 二元切片：真机块含「会手/冲咖/啡的/的萃/取状/态判」类无意义串，且 32 条上限截尾（run-1793980240191 原文）。
- 同款二元切片进点名清单已知面，跨词界残片（「态诊断」「水调」）制造幻影碎片——on 臂 106 行里混有掩码残片，模型被迫逐行裁决。
- 评审候选词块同病：含「记作/表示」类元语言碎屑，却被要求「逐字照抄」。
- 教练语境词只进首批块（F6）：非首批教练不知豁免面，措辞不对称保守。

## 实施要点（ANTI_LOOP on 行为精化，不新增开关；off 臂逐字节不变）
- [ ] 语境词切片改**最大 munch**：保留标题/目标中互不包含的最长 CJK 串（如 手冲咖啡/萃取状态/判读/调整），丢弃被更长语境词包含的内部二元串（冲咖/啡的/取状/态判 等）。
- [ ] 候选词块过滤元语言碎屑词表（记作/表示/称为/其中/定义/即 等停用词 + 纯虚词串）。
- [ ] 教练语境词块渲染扩到**每一批**（原仅首批），评审面不变。
- [ ] 新测：垃圾二元串不在块内/掩码池；最长串保留；元词过滤；非首批教练块在场；off 臂逐字节回归。

## 三件套
- **主指标**：语境词块/候选词块/点名清单中的无意义串计数（0 为目标）；碎片清单总行数不回升（合并+过滤后应 ≤106）。
- **护栏**：on 臂首批过门能力不回退（语境词豁免语义不变——作为 teaches 照常挂号）；评审候选词逐字照抄仍可行（过滤不删真词）；off 臂逐字节。
- **推翻条件**：on 臂碎片清单行数显著回升（>150）或首批出现新挂号打回 → 回退切片过滤、只保留 prompt 块去垃圾。
