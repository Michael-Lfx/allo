## 背景与取舍原则

只修「诊断时实测踩到的观测缺口」：让下次慢生长不再需要法证（日志行差值
+ DB 查询）才能定位。不改任何调用语义。

范围外裁决记录（2026-11-16 用户拍板）：

- 改进候选①（评审前机械预检「预设未挂号名词」）：改动大，**暂不做**。
- 改进候选②（评审调用降推理档）：现状已查清（评审走 thinking-ON 通道、
  reasoning_effort 从不设置、网关默认思维链），但「慢 = 推理还是排队」
  无 usage 数据可归因——**等 o2 的 usage 采集落地、拿一跑真机数据后再
  裁决**，不进本波。
