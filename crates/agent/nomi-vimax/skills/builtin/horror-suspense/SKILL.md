# 悬疑惊悚 Playbook

## When to apply
- Horror / thriller set pieces and psychological dread scenes
- Mystery reveals that need tension before information

## 结构
1. 日常裂缝（异常细节）
2. 空间与威胁规则建立
3. 信息封锁与误导
4. 压力高峰（追逐/对峙/揭示）
5. 余悸收束或反转尾巴

## 镜头语法
- 用画外空间与景深藏威胁
- 推镜慢、剪辑留白；惊吓前后给可读反应
- 关键道具/门/走廊轴线稳定

## 资产规范
- 光源有动机（台灯、走廊灯、手机光）
- 场景可藏可露，避免杂乱抢戏
