# 悬疑短剧 Playbook

## When to apply
- 悬疑、反转推理、心理惊悚的短剧单集
- 需要信息差，不需要血浆片

## 结构
1. 日常裂缝（一个异常细节）
2. 空间与威胁规则建立
3. 信息封锁或误导
4. 压力高峰（对峙 / 揭示）
5. 新的缺口收束（可连载）

## 镜头语法
- 画外空间与景深藏威胁，轴线稳定
- 推镜慢；惊吓前后给可读反应
- 门、走廊、道具是线索，不是装饰

## 红线
- 全黑、血浆堆砌、无铺垫的 jump scare
- 观众不知道相机在哪
- 用解说把谜底说完
