## 背景与取舍原则

修「已会声明 → 教练提示面」的单点断裂：声明并网是提示面软约束（m2 设计
即如此），SQL 修好后 coach/评审上下文即恢复已会读数。范围外（不做）：
teaches ∩ 已会声明 的机械门（提示面失效时的下一层执法，改动面 = 门与
评审判据，单独立票）；已生成的重复教学节点不回溯清理（用户可删课重开）。
