# 韦斯·安德森美学 Playbook

## 结构
1. 标题卡 / 章节感开场
2. 对称场景建立人物关系
3. 怪诞细节推动情节
4. 冷静旁观的情感落点

## 镜头语法
- 正中构图、水平移动、固定机位
- 角色走位像舞台调度
- 道具与服装成为叙事符号

## 资产规范
- 马卡龙或复古限定色板
- 场景高度人工、整洁、符号化
