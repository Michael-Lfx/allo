## Question

返工环是生长墙钟的第一因子：11-23 实测一轮 18m10s，其中 reject 环
（393s 矛盾重试 + 97s 重试 + 25s 点修 + 376s 二次评审）≈ +9 分钟；11-16
病历 19 分钟同族。allo 现状对「X 无出处」的唯一处置 = 打回让模型重掷
（掷骰子）；且**降级放行时零兜底**——上游 #234 修订点名这是"评审缺席时
唯一安全网在最需要时关闭"。上游 ADR-0042 已用 A/B 血泪换来结构性正解：
链接器机械分流 + 需要驱动生成，规格全部在案（含两次真机修订 #253/#257
的防坑注记）。

## 上游史（本票的设计边界，全部已对码）

- **#224/#225（L1 enforce A/B 回退）**：机器名词裁决**当阻断用**失败——
  "红是真缺口，修复动作空间缺失"（塞 teaches 违原子性/改写绕不开/入表
  提案下轮再犯）。教训铁律①：**检测面与处置面分离**。
- **#172（装箱侧自报表）**：ADR-0033 拒绝（填表方=被审方，自报可少报）。
- **ADR-0042 决定 3（链接器，已落地）**：评审判「X 无出处」→ 机械分流
  （零 LLM）：全图有节点教 X = 情形 A 调度错位 → 提示式重排，批照常评审
  （组织问题走既有梯子）；无节点教 X = 情形 B 出处缺口 → 调度定向源批
  （教 X，结构仅参考）→ 源批过完整门链落位 → **自动重试当前批**。
- **严格加法纪律**（#253/#257 两次真机修订的沉淀）：预算/深度是节奏限制
  不是落位闸门；停止 = 同尝试回退落位（Stopped + report-only findings
  点名缺口），**绝不把本可落位的 run 变成失败**。
- **#228 防噪收窄三件套**（现成规格）：候选只认覆盖**定义源**片段的名词
  行；主评审自判噪声/范围外的名词不作候选；引擎合成「未处置」问题不算。
- **#234 修订（Degraded 兜底）**：评审机械双败带病放行时，链接器照常从
  L1 定义源名词分流（`LinkTrigger::MainDegraded` 入账）——安全网不在最
  需要时关闭；保守放行语义零改动。

## 开工闸（灵活纪律——本票不承诺立即开工）

**闸门条件**：rs6/rs7/rs8 全部收口后，攒 ≥3 轮真机生长读数（rs1 档案 +
findings 查询），对照：
- 若打回率/死因重试频次降至尾部（返工环不再是主墙钟因子，如 rs7 小批
  已把单轮压进 3-6 分钟且打回 ≤1 次/3 轮）→ **本票降级留观**，停线；
- 若返工环仍是主因子（≥1 次/3 轮）或静默降级再现 → 按上游五票规格拆子
  票开工，开工前**重读上游最新实现**（#253/#257 修订后形态，非本票引用
  的 ADR 原文）。

## R（届时按拆票定，方向预声明）

- **R-a 机械分流零 LLM**：候选拔养严格按 #228 三件套收窄 + #234 Degraded
  臂；有候选才动作，无候选路径零足迹。
- **R-b 严格加法**：源批过完整门链（不降质量门槛）；预算/深度 = 节奏限
  制；停止 = 同尝试回退落位 + Stopped/findings 留痕点名缺口。
- **R-c 载体复用**：上游 #164 定向模板已退役改走 `PackingBasis::Source`
  接缝——allo 侧对应接缝开工时探查（生长引擎的定向反馈槽），提示词资产
  零改动的路径优先。
- **R-d 读数**：补源落位/停止/分流次数进生成报告与 findings；链接器事件
  与 rs1 档案、rs5 回放臂同读数面。

## Acceptance（届时按拆票细化，方向性预声明）

- 严格加法断言：链接器不把本可落位的 run 变成失败（对照既有回放臂/真机
  基线）。
- Degraded 兜底臂：降级放行 + 链接器分流留痕 + 缺口不静默。
- 方向锚回放不翻转；`cargo test -p nomifun-learning` 全量绿。

## 回退条件（负优化判定）

- 链接器把本可落位的 run 变成失败（违反严格加法）→ 回退整票。
- 分流补源批的评审通过率显著低于普通批（补源变成新的返工源）→ 收窄候
  选资格或改 report-only。
