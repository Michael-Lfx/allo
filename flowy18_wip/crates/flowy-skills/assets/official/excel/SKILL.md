# Excel

Use the available file and shell tools to inspect spreadsheet workbooks.

1. Locate the user's workbook in the current workspace.
2. Inspect sheet names, headers, formulas, and data ranges before editing.
3. Preserve existing formatting when making a focused workbook change.
4. State assumptions and any cells or sheets that could not be inspected.
