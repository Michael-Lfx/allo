## Question

learnhub 终态里**不存在终点概念**：用户只给目标声明，结构一次生成、仅作参考地图，顺序权威
归教练 + 账本。allo 现状里终点锚是一等公民：

- 建课向导第 2 步 = 多终点选择（AI 提议 → 用户增删改确认）；
- `learning_course_endpoints` 表（每条终点还是一行零正文标记课时）；
- 罗盘按终点分节；终点完成裁决（`EndpointVerdict`，覆盖读数作依据，永不自动置位）；
- 停摆臂之二 =「课程有终点且全部被标记完成」；终点保护条款在 `validate_batch` 里。

吸收「先生成知识结构」后，这套体系怎么办？候选：

- **(a) 完全删除**——对齐 learnhub 终态，顺序权威彻底归教练 + 账本；
- **(b) 降级为可选方向标记**——保留展示语义，退出一切判定面（不进门、不进停摆臂、不裁决）；
- **(c) 保留完成裁决、只砍建课选择步**——终点由结构生成或生长过程自然涌现。

需要一并裁决的连带面：新迁移策略与存量数据处理（别误判存量失败批次）；罗盘形态（分节结构
随终点去留）；行为摘要里终点相关条款；`propose-endpoints` 端点与向导 UI 的去留。

约束：工作区有未提交改动（growth governance 迭代），裁决落地前先落库；learnhub 曾用真机
代价否决过「保留结构化排期语义」的中间态，选择 (b)/(c) 时需说明为什么不重蹈覆辙。
