## 2. 输出及反馈策略

等待音复用Guide素材：25%数字增益，两段60ms之间50ms空隙，总长170ms。没有新增依赖、声学模型或生产音效文件；实际输出样本保存于 [R3-processing-cue.wav](R3-processing-cue.wav)。这个波形属于测试证据，不是默认录音。

低优先级反馈使用输出try_lock，不堆积；必要短音/回复请求登记输出意图，能够抢占等待音的消费等待。等待音让位不会增加声学generation，因此不取消真实回复。声音已开始后出现输入活动或阶段变化，清理其自有输出；控制停止仍沿原generation+flush。

等待音使用最近500ms安静及候选输入活动门禁，阈值RMS0.001只用来抑制可选提示，不改变Silero VAD或ASR识别门槛。现场噪声可使提示被跳过，不能把无提示当LLM已经退出。此阈值仍需实机校准。

诊断增加Skipped；非Pending回执只能更新当前request_id，防止旧声音的取消/完成盖掉新声音记录。事件包含身份、类型、状态及安全原因，不增加用户内容或凭据日志。宿主仍是公开产品快照的单一写入者，前端只读反馈。
