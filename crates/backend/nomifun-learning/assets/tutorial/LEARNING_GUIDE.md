# 学习模块使用指南

## 描述

学习模块把「知识库」变成「学习课程」，再用课时练习、知识诊断、复习队列和问题管理形成完整的学习闭环。本指南面向使用者，按「完成一件事」组织：如何生成课程、如何开始学习、如何做诊断、如何复习、如何管理问题。课程打开即自动加入，不需要单独的报名步骤；生成课程以任务形式运行，失败可一键重试。

**准备知识库 → 生成课程（任务化）→ 打开课程自动加入 → 学习课时（做题 + AI 批改）→ 完成课时 → 复习队列到期复习 → 问题管理追踪掌握**

- **课程**：由模块、课时、概念组成。课程可以从知识库自动生成（任务化流程），也可以直接导入课程包
- **课时**：每课时一篇学习文档（summary）+ 3-5 个活动。文档按「描述、例子、验证」三要素书写，每课时约 1000-1500 字
- **活动**：四种题型——单选题、判断题、填空题、反思题。客观题即时判分，填空与反思由 AI 批改并给出反馈
- **概念**：课程的最小粒度单位，课时和活动都绑定概念；概念之间有先修关系，用于推荐学习路径
- **知识诊断**：进入课程后可以先做摸底测试，系统按掌握度与先修顺序推荐学习路径
- **复习队列**：课时完成后，涉及的概念自动生成复习卡片，使用 FSRS 算法排期；到期卡片进入「今日复习」，评分后重排下次时间
- **问题管理**：集中查看所有客观题的队列状态（未加入/未掌握/待首次复习/已到期/未到期），也可以自动生成问题加入复习队列

### 课程生成的任务化流程

自动生成课程采用任务化流程：点击「生成课程」后创建**生成任务**，任务在「生成任务」页签的表格中展示，可随时查看进度与状态，不需要一直等待页面：

1. **创建任务**：选择模块数与每模块课时数（每模块 1-6 个），确认后任务开始运行
2. **任务表格**：每个任务一行，展示课程名、知识库、进度、状态（进行中/成功/失败）与所用模型；成功前可继续使用页面的其他功能
3. **失败重试**：任务失败后点击「重试」即可重新生成；必要时可以在重试前更换会话模型（如默认模型繁忙时）
4. **完成**：任务成功后课程出现在课程列表，点开即可学习

整个过程约 1-3 分钟：AI 先设计课程蓝图（概念、先修、模块课时骨架），再逐课时撰写深度文档与练习，最后组装校验。

## 例子

**例 1：从知识库生成一门课程**

1. 打开学习页面，在左侧知识库列表选中一个知识库（例如本教程知识库「Flowy 使用指南」）
2. 点击「生成课程」，选择 3 个模块、每模块 2 个课时，确认创建生成任务
3. 切换到「生成任务」页签，看到任务行：状态「进行中」，进度条随时间推进（约 1-3 分钟）
4. 若任务状态变为「失败」，点击该行的「重试」按钮重新生成；若默认模型不可用，重试前在设置中选择其他会话模型
5. 任务状态变为「成功」后，回到「课程」页签，新课程已出现在列表

**例 2：打开课程并完成第一个课时**

1. 点击课程卡片打开课程详情——这一步就已经自动加入课程，无需任何报名操作
2. 展开模块与课时，点击课时 1.1 开始学习：先阅读课时文档（描述/例子/验证三节），再逐题作答
3. 单选题、判断题直接点选并提交，立即看到对错与解析；填空题输入答案，AI 会判断是否可接受并给出反馈；反思题写下自己的想法，AI 批改后给出评价与建议
4. 答完所有活动后课时标记为完成，该课时涉及的概念自动进入复习队列

**例 3：做完知识诊断并开始复习**

1. 进入课程后点击「开始诊断」，在弹窗中依次作答客观题（约 10 道）
2. 诊断完成查看报告：已掌握/未掌握的概念分布，以及「建议下一步」——例如「前往课时 1.2」或「直接进入复习」
3. 回到课程页，看到顶部 banner 显示「今日复习」的到期卡片数；点击进入复习会话
4. 每张卡片作答后评分（生疏/模糊/想起/轻松），系统按 FSRS 算法安排下次复习时间

**例 4：在问题管理中追踪掌握情况**

1. 打开「问题管理」页签，查看所有客观题的状态列：未加入（课时未完成）、未掌握、待首次复习、已到期、未到期
2. 使用状态筛选快速定位「已到期」的问题，进入复习队列巩固
3. 点击「自动生成问题」，系统会补充新题目并加入复习队列，不受课时完成状态影响

## 迁移

- **把自己的笔记变成课程**：任何格式规整的 markdown 知识库都可以生成课程。笔记越结构化（一个文件一个主题、每篇含描述/例子/验证三要素），生成的课程越可用
- **不同学习目标**：功能同样适合内部文档培训（把文档转成带练习的课程）、备考（每篇笔记 + 自测题 + 间隔复习）、团队 onboarding（新成员按路径学习 + 诊断摸底）
- **配合 agent 使用**：把知识库挂载给 agent，写笔记时让它按文档规范起草（三要素必备），生成出的课程质量更高，复习闭环也更完整
- **原理取舍**：先修关系（概念依赖图）与 FSRS 间隔算法是系统推荐的依据——用户只需知道「按建议学、按评分复习」即可，不必理解算法细节

## 其他（常见问题）

- **生成任务失败**：先点「重试」；多次失败时检查会话模型配置（有没有可用的 provider 与模型），更换模型后重试
- **没有配置模型**：没有可用模型时不能生成课程，但仍可以直接导入课程包使用
- **复习卡片数量**：「今日复习」显示的是本次会话加载的卡片数（默认 30），不是全部到期卡片；可多次进入复习会话
- **复习卡片何时产生**：课时完成时该课时的客观题才进入复习队列；反思题不产生复习卡片
- **删除课程**：删除课程会同时删除该课程的复习记录与学习数据，操作前确认；删除后课程不会在列表中再出现
- **自动加入的课程**：打开课程详情即自动加入（enrollment 自动创建），再次打开不会重复加入，进度与复习数据都挂在同一个加入记录下
- **填空批改**：填空题允许多个可接受答案，AI 批改会判断语义是否等同，而不是逐字匹配；输入不完整或错别字时给出提示

## 验证

1. 判断题：打开课程详情后会自动加入课程，不需要单独的「加入课程」操作。（正确）
2. 单选题：生成课程失败后，正确的做法是？A. 放弃这门课 B. 点击重试，必要时更换会话模型 C. 删除知识库重建 D. 重启应用（答案：B）
3. 单选题：课时文档必须包含的三节是？A. 模块、课时、活动 B. 描述、例子、验证 C. 单选、判断、反思 D. 生成、学习、复习（答案：B）
4. 单选题：以下哪种题型由 AI 批改并给出反馈？A. 单选题 B. 判断题 C. 填空题 D. 都不需要（答案：C）
5. 判断题：反思题会生成复习卡片进入复习队列。（错误——只有客观题生成复习卡片）
6. 操作验证：打开一门课程，先查看「问题管理」中各问题的状态，再进入「今日复习」完成一轮评分，观察下次复习时间的排期变化
